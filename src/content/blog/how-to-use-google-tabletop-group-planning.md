Google Labs launched Tabletop on 11 November 2026. It is a shared space where groups build custom tools together in real time. You add links, files, and ideas, then prompt the AI to generate interactive plans, polls, brackets, and trackers.

Everyone joins through one invite link and edits at the same time, similar to a Google Doc. The experiment is currently available in the United States for adults 18 and older via a waitlist at labs.google/tabletop.

## What Tabletop Does

Tabletop turns a prompt into a usable mini-app inside a shared workspace. Common outputs include trip itineraries that pull in maps and reservations, dinner decision wheels, expense splitters, and live tournament brackets.

You can start from a blank space or choose a starter template. Once the tool exists, group members can vote, drag items, update numbers, or ask for changes without leaving the space. The AI updates the tool on the fly.

This differs from chat-only AI. The output lives as an interactive object that the whole group can open and modify together. Google compares the collaboration model to working in a shared document.

## Requirements and Access

You need a personal Google account. Work and school accounts are not supported at launch. Access is limited to users in the United States who are 18 or older.

Join the waitlist at [labs.google/tabletop](https://labs.google/tabletop). Google lets people off the waitlist in batches. Early users receive a limited number of invites (reported as five) that can be shared with others who do not need to join the waitlist themselves.

Once approved, open the Tabletop space in a browser. No separate app install is required. Keep the page open if multiple people will join at the same time.

## How to Create a Shared Space

1. Accept the waitlist invitation and open Tabletop.
2. Create a new space. Give it a clear name such as “Weekend Road Trip” or “Pickleball League.”
3. Add links, files, or notes. Paste a Google Maps route, upload a budget spreadsheet, or drop in event details.
4. Type a prompt starting with `@tabletop`. Example: “@tabletop Build an interactive itinerary for our three-day coastal drive with brunch stops and a shared expense tracker.”
5. Review the generated tool. Ask for adjustments: “Add a voting poll for dinner options” or “Change the bracket to best-of-three.”
6. Copy the invite link and send it in your group chat. Recipients open the link and join immediately.

Everyone sees the same live view. Changes appear for all members without a refresh. You can also start from a ready-made template for brackets, polls, or trip planners and customize it.

## Practical Examples

**Trip planning.** Drop hotel links and a route. Prompt for an itinerary that includes drive times, meal stops, and a running cost split. Members can update reservations or vote on alternatives inside the same space.

**Sports league.** Ask for a tournament bracket with random matchups. Add a live scoreboard. Players update results as games finish.

**Household tasks.** Request a chore chart that tracks completion and assigns points. Turn it into a light game with a shared reward at the end of the week.

**Decision making.** Generate a dinner-decider wheel or a swipeable voting board for movie night or logo options. Everyone votes in real time.

These tools stay editable. If plans change, prompt again: “Move the second night to a different hotel and update the total.”

## Tips for Better Results

Write specific prompts. Include the number of people, dates, constraints, and the exact output you want. “Create a four-person expense splitter for a $420 weekend trip with separate hotel and food categories” works better than “make a budget.”

Add source material first. Links and files give the AI concrete data to work with, which reduces generic results.

Invite people only after the core tool is ready. This keeps the first view useful instead of an empty space.

Verify numbers and links. Generative output can miss edge cases or outdated prices. Correct them directly or ask for a revision.

If you already use other Google AI features, note that Tabletop is a separate Labs experiment. It does not require Gemini Intelligence on a Pixel phone, though related tools such as [Pixel Solver in the Calculator app](/blog/how-to-use-pixel-solver-calculator-pixel-11/) show how Google is expanding guided AI into everyday tasks.

## Limitations to Know

Availability is US-only and waitlist-based at launch. New users are added gradually.

Work and school Google accounts cannot create or join spaces.

The feature is an experiment. Tools, invite limits, and supported actions may change. Google has not published which model powers Tabletop.

Complex or highly regulated workflows still need dedicated software. Tabletop focuses on lightweight group coordination such as trips, clubs, and household plans.

## Conclusion

Tabletop gives groups a single place to turn ideas into shared interactive tools. You add materials, prompt for the exact planner or tracker you need, and let everyone edit live.

Join the waitlist if you are in the United States and 18 or older. Start with a simple trip itinerary or dinner poll to see how the real-time collaboration works.
