Google rolled out in-chat file editing for Gemini on October 29, 2026. You can now generate a document, preview it in the conversation, and refine it without downloading or switching apps. PDF preview and editing works on both web and mobile. Google Docs, Sheets, slide decks, Markdown, TXT, and code files are available on the web for now.

This change closes a gap that forced users to leave the chat to fix a single sentence or chart. The workflow stays inside Gemini, which speeds up drafting reports, study guides, and quick spreadsheets.

## What the New Editing Tools Let You Do

After Gemini creates a file, three editing options appear. Expand the preview to full screen and type changes yourself. Highlight any text and ask a question about that section. Or prompt Gemini to revise the whole file or a specific part.

Google’s own example starts with photos of handwritten lecture notes. Gemini turns them into a PDF study guide. You then expand the preview, correct a definition by hand, highlight a diagram, and ask Gemini to rewrite the caption. The file updates in place.

These features are available to all users in every language where the Gemini app runs. Workspace customers, individual subscribers, and personal Google accounts all receive the same tools.

## How to Generate and Edit a File in Gemini

Open the Gemini app on the web at gemini.google.com or the mobile app. Sign in with your Google account.

1. Start a new chat and describe the file you need. For a study guide, upload photos of your notes and say: “Turn these handwritten notes into a clear PDF study guide with headings, key terms, and short summaries.”
2. Wait for Gemini to generate the file. The preview appears inline in the chat.
3. Tap or click the expand icon to open the file in full-screen mode. Edit text directly with your keyboard.
4. Highlight a sentence or table cell. A prompt bar appears. Type a request such as “make this definition shorter” or “turn this table into a line graph.”
5. Review the updated preview. Ask follow-up questions about the content without leaving the file.
6. Use the export button in the preview to download the file or send it to Google Drive.

On mobile, stick to PDFs for full editing. Other formats still require the web version.

## Platform Differences and Supported Formats

| Format | Web | Mobile |
|--------|-----|--------|
| PDF | Preview and edit | Preview and edit |
| Google Docs | Preview and edit | Web only |
| Google Sheets | Preview and edit | Web only |
| Slide decks | Preview and edit | Web only |
| Markdown / TXT | Preview and edit | Web only |
| Code | Preview and edit | Web only |

PDF support on phones makes the feature useful for students and people who draft on the go. For spreadsheets and multi-page Docs, switch to a browser.

## Tips for Better Results

Keep the first prompt specific. Include the audience, tone, and required sections. “Create a one-page PDF summary of these meeting notes for the engineering team” produces tighter output than “make a document.”

Upload source material when possible. Photos of notes, existing PDFs, or pasted text give Gemini concrete content to work from instead of inventing details.

Edit in small steps. After the first generation, fix one section at a time. Large rewrite requests sometimes lose earlier changes.

Check facts before you export. Gemini can still invent citations or misread handwriting. Highlight any questionable sentence and ask “is this accurate based on the notes?”

## Conclusion

In-chat editing removes the copy-paste loop that slowed Gemini workflows. Generate a file, preview it, fix it by hand or by prompt, and export. PDFs work everywhere; other formats are web-only for now. Start with a clear prompt and a source file, then refine in place. The tools are live for all users today.
