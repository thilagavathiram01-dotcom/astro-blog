Saved passwords only help if they are still secret. Google Password Checkup reviews passwords stored in your Google Account and sorts them into three groups: compromised, reused, and weak. Compromised username and password pairs are ones Google has found published online. Reused passwords appear on more than one site. Weak passwords use obvious phrases, simple keyboard patterns, or single words that are easy to guess.

You can start the check from Chrome, from another browser at passwords.google.com, or from Password Manager on Android. The scan uses the passwords already saved to your Google Account. If Chrome is signed in and allowed to use those passwords, new saves stay in the same list.

## What you need before you start

Sign in with the Google Account that stores the passwords you want to review. Password Checkup does not scan passwords kept only in another browser or in a third-party manager unless you have imported them into Google Password Manager.

On a computer, Chrome is the shortest path. In any other browser, open [passwords.google.com](https://passwords.google.com) and continue from there. On Android, open Settings and search for Password Manager, or open the same passwords site in Chrome. Google may ask you to confirm it is you before the scan runs.

Treat unexpected email or chat messages that claim your passwords leaked with care. Google Account Help says to open Password Checkup yourself at [passwords.google.com/checkup/start](https://passwords.google.com/checkup/start) so the page is the real one, then change unsafe passwords from that result.

## Run Password Checkup in Chrome

1. Open Chrome on your computer.
2. At the top right, select More, then Passwords and autofill, then Google Password Manager.
3. On the left, select Checkup.
4. Confirm it is you if Chrome asks.
5. Wait for the three result groups to load.

If the Passwords entry is missing, use More, then Passwords and autofill, then Google Password Manager. The Checkup control sits in that panel, not in a separate extension. Google folded the old Password Checkup extension into Password Manager years ago.

From a result row you can view the saved login, open the site, or delete the entry. Changing the password happens on the site itself. After you set a new password, accept Chrome's prompt to update the saved copy so the next checkup does not still flag the old one.

## Run it on the web or on Android

If you do not use Chrome on that computer:

1. Open any browser.
2. Go to [passwords.google.com](https://passwords.google.com).
3. Select Go to Password Checkup, then Check passwords.
4. Sign in if asked.

On Android, open Settings, search for Password Manager, open it, and tap Password Checkup. The phone list is the same Google Account vault, so a fix you make on the web shows up on the phone after sync. You can also open passwords.google.com in mobile Chrome and follow the web steps.

Keep the phone unlocked only while you review results. Do not screenshot compromised passwords and send them to chat apps. Open the site, change the password there, and let Password Manager offer to save the replacement.

## Read the three result groups

**Compromised.** Google Account Help says these username and password combinations are unsafe because they have been published online. Change them as soon as you can. This is the group to clear first, before reused or weak entries.

You can dismiss a compromised warning. Next to the password, open More and choose Dismiss warning. Dismissed items stay under Dismissed warnings, where More then Restore warning brings the flag back. Dismiss only when you already changed that password on the site and the warning is stale. A dismiss does not change the password on the website.

**Reused.** The same password on several accounts raises the cost of one leak. If one site is breached, every other login that shares that string is exposed. Google recommends a unique password for every account. Let Chrome create and save a strong password when the site allows it, instead of inventing a small set of variations.

**Weak.** Obvious phrases, keyboard walks, and single dictionary words are easy to guess. Replace them with a generated password stored in Password Manager. You do not need to remember each one if the manager fills them on signed-in Chrome and on Android.

Google may still ask you to change your Google Account password if that password looks unsafe, even when you never open Password Checkup. A suspicious or hijacked Google Account is a separate recovery path in Account Help, not something the checkup page alone fixes.

## Change a flagged password

1. Open the flagged site from the checkup row, or type the site address yourself. Avoid links in unsolicited messages.
2. Sign in with the current password. Use account recovery on that site if the password no longer works.
3. Open the site's password or security settings and set a new password. Prefer the strong password Chrome offers.
4. Save the new password when Google Password Manager asks.
5. Sign out other sessions on that site if the site offers that control.
6. Return to Checkup later and confirm the warning is gone.

Work through compromised entries before reused ones. A reused password that is also in a breach should be replaced everywhere it appears, not only on the site named in the first row.

If a site will not accept a generated password, use a long unique passphrase and store it in Password Manager. Do not reuse your Google Account password on other sites.

## Turn password alerts on or off

Google can notify you when it finds a saved password online. The check still runs if alerts are off. Account Help notes that alerts can continue for up to 48 hours after you turn the setting off.

To change it:

1. Go to [passwords.google.com](https://passwords.google.com).
2. At the top right, select Settings.
3. Turn Password alerts on or off.

You can also open the same controls at [passwords.google.com/options](https://passwords.google.com/options). Leave alerts on unless they are noisy for a vault you no longer use.

## Pair the checkup with account protections

Password Checkup only covers saved site passwords. It does not replace a review of your Google Account. After you clear compromised rows, open Security Checkup at [myaccount.google.com/security-checkup](https://myaccount.google.com/security-checkup). That page covers recent sign-in activity, recovery phone and email, and connected devices.

On Android, Advanced Protection is a stricter mode for people who face higher risk of targeted attacks. The setup steps are in our guide to [Android Advanced Protection](/blog/android-advanced-protection-setup/). Passkeys remove the password from many sign-ins. If you still rely on a password for your Google Account, follow [how to create a Google Account passkey on Android and PC](/blog/create-google-account-passkey-android-pc/).

A password manager transfer between apps is a different job. Checkup does not move credentials. It only reports on what is already in the Google Account.

## Tips that keep the list accurate

Sign in to Chrome and allow it to use passwords from your Google Account when asked. Otherwise a password you change in the browser may never reach the checkup list, and a password you change on the phone may not fill on the computer.

Delete saved logins for sites you no longer use. A dead account with a reused password still counts as reuse.

Do not paste flagged passwords into chatbots or email. The checkup page is enough to know which site to open.

Re-run Checkup after a large import, after you hear about a breach at a service you use, and after you replace a batch of reused passwords. Google continues to compare saved passwords with published breach data, so a clean result today can change later.

If a warning returns after you changed the password, confirm the site saved the new value and that Password Manager updated its copy. An old duplicate entry for the same site can keep the warning alive.

## Bottom line

Open Google Password Manager, run Checkup, and clear compromised passwords first. Then split reused passwords so each site has its own, and replace weak ones with generated values the manager can fill. Use Chrome's Checkup panel, passwords.google.com, or Password Manager on Android. Finish with Security Checkup so the Google Account around those passwords is in the same shape.
