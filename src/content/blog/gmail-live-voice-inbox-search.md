Gmail Live is the voice session that sits on top of your inbox. You speak a question, Gemini answers from mail it can see, and you can interrupt it the way you would interrupt a person. It is not the Ask Gemini side panel on the web, and it is not the Copy code chip that appears under two-factor emails.

Google launched the mobile experience for Gmail, Docs, and Keep on [3 September 2026](https://blog.google/products-and-platforms/products/workspace/voice-features-gmail-docs-keep/). Gmail Help still labels Live as beta. This guide follows that Help article and the product blog so you can start a session, check sources, and fix the usual microphone and volume problems.

## What Gmail Live is for

Gmail Help lists three jobs:

- **Quick answers** drawn from your mail
- **A back-and-forth conversation** instead of a single keyword search
- **Follow-ups and topic changes** without starting a new session

Google’s own example questions are the ones worth copying first:

- “What’s my flight’s gate number?”
- “What’s going on at my kid’s school this week?”

The Workspace blog uses the same examples and frames Live as conversational inbox search when you do not have time to scroll threads.

Treat every spoken answer as a pointer. Open the cited message before you leave for an airport or tell a school you will be there.

## What you need

Gmail Help is explicit:

- **English only** for now
- The **Gmail app on an Android phone or iPhone** — not an Android tablet, and not Gmail on the web
- Microphone permission for Gmail
- **Smart features in Google Workspace** and **Smart features in other Google products** turned on

Work or school accounts need an eligible Workspace plan with Gemini Beta. If the control is missing, an admin may have Beta features off for the organization.

Consumer Google AI Plus, Pro, and Ultra access was described in independent reporting when the 3 September rollout started. Plan names change. If you do not see Live, check the current Gmail app, language set to English, and smart-feature toggles before assuming a hidden setting exists.

You cannot change the Gmail Live voice. That limit is in Help, not a rumor.

## Start a session on Android

1. Open the **Gmail** app on your phone.
2. At the top, tap **Gmail Live**. On many builds that control sits in the search field next to Ask Gmail.
3. The first time, allow the microphone and accept the terms.
4. Start talking, or tap a suggested prompt.
5. Tap **End** when you are done.

Suggested prompts Google has shown in the full-screen UI include upcoming travel dates and updates on recent orders. Use those once so you can see how citations look, then ask something you already know the answer to.

On iPhone the path is the same: current Gmail app, English, Live control at the top, microphone permission.

## Mute without killing the session

Mute turns the microphone off and lets Gemini finish speaking. The session stays open.

- Tap **Mute** while Live is active.
- Tap **Unmute** when you want to talk again.

Use mute in a noisy room or when someone walks up. Ending the session is a different control and drops you back to the inbox.

## Check the emails behind an answer

Live is only useful if you can see the source message.

- Tap links inside the spoken-and-shown reply to open the exact emails used for details.
- Tap the **Sources** card at the bottom to see every cited message.
- Opening a source email **ends** the Live session. That is documented behavior, not a bug.
- Scroll to the bottom of the source menu and tap **View search page** if you want a normal Gmail search layout instead of the voice UI.

If a gate number, order status, or school date looks wrong, believe the original email. Models invent confident sentences.

## How Live differs from the rest of Gmail AI

Keep the surfaces separate so you do not hunt for a button that belongs on another screen.

| Surface | Where it lives | Best for |
| --- | --- | --- |
| **Gmail Live** | Mobile app voice session | Hands-free questions about mail you already received |
| **Ask Gemini panel** | Gmail on the web (and the Gemini button on mobile) | Summaries, drafts, calendar prompts, confirmed inbox actions |
| **AI Overviews in search** | Search box after you type a question | One-shot natural-language lookup with a short answer above results |
| **Copy code** | Inbox row under some 2FA emails | One tap to copy a six-digit code — no Gemini plan required |

Live does not replace Help me write in compose. It does not archive or delete mail. Inbox actions that change labels still belong in the Gemini panel, where Gmail shows a confirmation card.

## Conversation history

Gmail Help says Live transcripts are stored with your Gemini in Workspace conversation history. Review or delete them from a browser, not from the phone session itself.

Open Gmail on the web and use Google’s history controls for Gemini in Workspace if you asked about travel, school, or health mail you would rather not leave sitting in a transcript list.

## Fix the common failures

**No sound.** If device volume is at 0%, Gmail shows a warning. Tap **Turn volume up** or use the hardware buttons.

**Session never starts.** You likely denied the microphone earlier. Use **Settings** on the error screen, then allow the mic for Gmail.

**Drop mid-sentence.** A lost network ends the session. Check Wi-Fi or mobile data and tap **Try again**.

**No Live control.** Confirm English, a phone (not a tablet), a current Gmail build, smart features on, and — for work accounts — Gemini Beta from an admin. Consumer plan eligibility is still rolling; missing UI is usually access, not a broken install.

## A short first session that actually tests the product

1. Ask for a flight or package you can open in the same inbox.
2. Tap **Sources** and open the message. Notice that Live ends.
3. Start Live again and ask a follow-up about the same trip without restating the airline.
4. Mute, let it finish a sentence, unmute, and change the topic to school or an order.
5. End the session and delete the transcript from web history if the topic is sensitive.

That five-step loop covers start, citations, follow-ups, mute, and history — the whole Help article in practice.

## Docs Live and Keep Live sit next door

The same 3 September Workspace post shipped **Docs Live** (voice drafting and structure, with optional Gmail, Drive, Chat, and web context) and **Keep Live** on Android (add items to an existing list by speaking). Those are separate apps and separate permissions. Do not expect a Gmail Live session to append a grocery list or rewrite a Doc.

If you only need inbox facts on a walk, stay in Gmail Live. If you need a first draft, open Docs.

## Conclusion

Gmail Live is a phone-only, English, beta voice layer over mail you already have. Start it from the top of the Gmail app, ask a question you can verify, open the Sources card, and mute instead of ending the session when you just need Gemini to stop listening.

It will not replace typed search operators, the Ask Gemini panel, or reading the original thread. Used that way — as a spoken index with citations — it is faster than scrolling when your hands are full.
