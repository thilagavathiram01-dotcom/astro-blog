Switching AI assistants no longer means starting from zero. Google’s Gemini now lets you bring preferences and full chat history from other tools like ChatGPT or Claude. The process uses a short prompt for memory and a ZIP upload for conversations.

This guide walks through both methods using only official steps from Google. You stay in control of what moves over. No third-party tools are required.

## What Transfers and What Does Not

Gemini accepts two separate imports. The memory path brings a summary of your preferences, tone, and key facts. The chat path brings the text of past conversations so you can search and continue them.

Only the text of chats moves. Images, files, and project attachments stay behind. You can upload new files into Gemini later. Imported chats appear in the sidebar with a special icon.

Personal Google accounts aged 18 and older can use the feature when personalisation is turned on. Work, school, and supervised accounts cannot. Availability varies by region. The feature is not offered in the EEA, Switzerland, or the United Kingdom.

## Import Your Memory and Preferences

Memory import is the fastest way to give Gemini context about how you like to work.

1. Open Gemini in a browser at gemini.google.com and sign in with a personal Google Account.
2. Go to Settings and select Import memory to Gemini. You can also go directly to gemini.google/import-memory/.
3. Copy the ready-made prompt that appears.
4. Paste that prompt into a new chat in your current AI app (ChatGPT, Claude, or another supported tool).
5. Wait for the response. It summarises preferences, style, recurring instructions, and useful facts.
6. Copy the full response.
7. Return to the Gemini import page, paste the text into the box, and click Add memory.

Gemini stores the summary and uses it in future chats. You can repeat the process later if you want to update preferences.

## Import Full Chat History with a ZIP File

For the actual conversations, export a ZIP from your old provider and upload it.

For ChatGPT:
- Click your profile icon, then Settings, then Data controls.
- Next to Export data, click Export and confirm.
- OpenAI emails a download link. Processing can take minutes or up to a day.
- Download the ZIP. Do not extract it.

For Claude:
- Open Settings, then Privacy.
- Choose Export data, select the date range if offered, and confirm.
- Download the ZIP when the email arrives.

Back in Gemini:
1. Return to Settings > Import memory to Gemini.
2. Under Import chats, click Add.
3. Select the ZIP file (up to 5 GB).
4. Wait for processing. Large files can take time.

You can upload up to five ZIP files per day. Imported chats show in the left menu under Chats with an import icon. Search works on them the same way as native chats. Delete single threads or an entire import batch from Settings.

## Limits, Requirements, and Troubleshooting

Google sets clear boundaries:

- ZIP files only, maximum 5 GB each.
- Up to five uploads per day.
- Personal accounts only, age 18+.
- Personalisation must be enabled in Gemini.
- Not available in EEA, Switzerland, or UK.
- Not supported in Gemini inside Google Messages, Chrome, or Android XR.

If an upload fails or looks incomplete, delete that import entry and try again. Processing time grows with file size. Keep the original ZIP until you confirm everything arrived.

Compatibility depends on the export format of the other provider. ChatGPT and Claude are explicitly supported. Check the import page for the latest list.

## Practical Tips Before You Switch

Review the export before uploading. Remove any sensitive threads you do not want in Gemini. The memory summary is a good place to add or correct details the old assistant got wrong.

After import, test a few old topics. Ask Gemini to continue a specific conversation or recall a preference. This confirms the data landed correctly.

If you also use Gemini’s newer models, the imported context works across them. See our guide on [How to Use Gemini 4 Neon](/blog/how-to-use-gemini-4-neon/) for setup details on the latest release.

Keep the old account active for a short period. You can re-export if something is missing. Once you are confident, you can decide whether to keep or close the previous service.

## Conclusion

The import tools remove the biggest friction of changing AI assistants. A single prompt brings preferences. A ZIP brings the conversation archive. Both stay under your control and follow Google’s documented limits.

Start with the memory summary if you mainly want style and facts. Add the full history when you need searchable past threads. Check regional availability and account type first so the options appear in Settings.
