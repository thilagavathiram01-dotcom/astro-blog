Group chats are good at talking and bad at keeping a list. Grocery items, packing checklists, and trip ideas end up as twenty separate texts that nobody can tick off.

The September 2026 Android Drop puts **Google Keep** inside **Google Messages**. You can open a note from the plus menu, share it into the thread as a live preview, and let people in that chat edit the same list without switching apps.

This guide covers what rolled out, how to turn the shortcut on, how sharing works, and where Chat theme fits alongside it.

## What Google shipped

Google announced the Keep shortcut as part of the [September Android Drop](https://blog.google/products-and-platforms/platforms/android/android-drop-september-2026/). Messages coverage from 9to5Google and Android Authority matches the same flow:

- A **Keep Notes** tile in the conversation **plus** menu
- A contextual **Create list** suggestion in some threads
- A sheet of your existing notes plus **Create a note**
- A **Send** action that drops a **live preview** into the chat
- Tapping that bubble opens the note again so items can be checked off

The note is stored in the **Google Account signed into Messages**. Recipients who can open the shared note can view, edit, and add items. Chat theme (per-conversation wallpaper and bubble colors) rolled out around the same time; it is separate and only visible on your device.

## Before you start

1. Update **Google Messages** from Play Store (the Keep tile is a server-side rollout on top of a recent app build).
2. Update **Google Keep** if you also want the same list on wearables or the web.
3. Confirm Messages is using the same Google Account you want the note saved under.
4. Use an **RCS / Messages** conversation when you can. SMS-only threads will not give you the same live preview experience.

If the Keep tile is missing after an update, wait for the server flag. Reordering plus-menu pills does not invent a feature that has not reached the account yet.

## Step 1 — Open Keep from a chat

1. Open **Google Messages** and enter a 1:1 or group conversation.
2. Tap the **+** button next to the compose field.
3. Choose **Keep Notes** (some builds label it **Google Keep**).
4. If you see a **Create list** chip above the keyboard instead, tap that. It opens the same sheet.

You can long-press plus-menu tiles to reorder them so Keep sits next to Gallery.

## Step 2 — Pick a note or start a new one

The sheet shows notes already in Keep for that account.

- Tap an existing list (groceries, packing, itinerary).
- Or tap **Create a note**. The in-Messages editor is a slim Keep composer: title, checklist toggle, and basic formatting.
- Keep the title short. The chat bubble uses it as the preview heading.

Write the first few items in Messages if the list is new. You can finish the rest later from Keep on any device.

## Step 3 — Send the live preview

1. Review the note in the sheet.
2. Tap **Send** (bottom-right on current builds).
3. The thread shows a Keep card instead of a dump of plain text.

Tap the card later to reopen the note, check items off, or add a line. That is the point of the integration: the list stays one object, not a stack of “also milk” replies.

## Step 4 — Let the group edit it

People in the conversation can open the shared note and contribute. Use that for:

- A **grocery run** where two people shop different aisles
- A **weekend packing** list for a group trip
- A **potluck** where each person claims a dish
- A **repair punch list** for roommates

Do not drop a private work note into a family group. Sharing follows the chat membership. If someone should not see the list, create a new note instead of reusing one from a restricted Keep label.

## Chat theme is optional dressing

The same Drop lets each conversation use its own **Chat theme**: curated wallpaper packs (Animals, Landscapes, Space) or a photo from your gallery. Message bubbles pick up colors from that image, or you set a color manually.

Themes stay on **your** phone. A beach background on the vacation group does not appear on anyone else’s device. Use theme to find the thread faster; use Keep to keep the plan in one place.

## If Keep does not appear

- Update Messages, force-stop the app, and reopen the plus menu.
- Confirm you are not in an archived or spam conversation.
- Check that Keep is installed and you can create a note in the Keep app itself.
- Server-side rollouts can lag a few days behind the Play Store version. 9to5Google reported wide availability after September 9, 2026, but flags still land unevenly.

You can still create the list in Keep and share a Keep link the old way. The new tile is faster; it is not the only path.

RCS still matters for edit, unsend, and rich cards. If a contact is on SMS only, keep expectations low and send a Keep link they can open in a browser.

## A simple habit that works

When a group chat turns into planning:

1. Create the Keep list from **+** in that thread.
2. Pin the Messages conversation if the trip is this week.
3. Check items off from the chat card while you shop.
4. Open the same note in Keep when you need a bigger keyboard.

That is the whole feature. It does not replace Keep labels, reminders, or Gemini in Keep. It stops a plan from drowning in the scrollback.
