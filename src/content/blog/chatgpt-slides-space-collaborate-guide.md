ChatGPT now builds editable presentations you can revise and share without leaving the app. OpenAI added ChatGPT Slides on October 16, 2026. Eligible users create a deck in Space, edit text and charts directly, invite teammates for real-time collaboration, and export to PowerPoint, PDF, or Google Slides.

This guide covers availability, creation methods, editing, sharing, and export. All steps come from OpenAI’s Help Center article “Creating and collaborating on slides in ChatGPT.”

## Who can use ChatGPT Slides

Slides is rolling out to eligible ChatGPT Pro, Business, and Enterprise users who have Space access. Free, Go, and Plus plans do not include it at launch. The feature appears on web and the desktop app. If you do not see it, your account may still be waiting for the rollout.

On some Windows devices without the required MXC component, local creation falls back to .pptx files. Windows 10 does not support that component. Windows 11 users may need an update. Use the web version for full collaborative Slides.

## Create a presentation three ways

### Ask ChatGPT in Work

1. Open Work in ChatGPT.
2. Ask for a slide, presentation, or deck.
3. Describe the topic, audience, and material it should cover.
4. Attach source files or continue from an existing conversation.

ChatGPT creates an editable presentation you can open in Space. If you prompt it to deliver a file directly, it can return a PowerPoint or Google Slides version.

Example prompt:

> Create a six-slide project update from these notes. Cover progress, risks, and next steps. Use a clean professional layout.

### Start in Space

1. Open Space.
2. Select Create > Slide.
3. Start with a blank slide or choose a template.

### Use a template

Share an example deck with ChatGPT so it matches the style and layout. You can also create your own templates with template-creator and share them through team Plugins.

Example:

> Create a six-slide project update from these notes. Cover progress, risks, and next steps. Use the my project update template to guide the style and layout.

## Edit your slides

You can edit text, images, shapes, tables, and charts directly in the presentation.

On the web, the font picker shows fonts available in your browser. On desktop, ChatGPT can use system fonts installed on your computer.

To change a specific element with ChatGPT:

1. Select the element.
2. Choose Request edits.
3. Describe the change.

You can also use the prompt bar to request changes to the whole deck. Ask ChatGPT to shorten a slide, update a chart from new data, or revise the layout.

Always review the text, figures, and layout before sharing or presenting.

## Share and collaborate

Share the presentation with teammates so you can work on the same deck. People with edit access can edit the slides at the same time.

Use shared comments to discuss changes and @mention collaborators. To request edits from the AI, @mention ChatGPT. Comment-only access is not available at launch.

Sharing a page does not give others access to your private chats or ChatGPT Memory. Information written on the page is visible to everyone who can view it.

## Present or export your deck

You can present directly from ChatGPT.

On the web, export options include:

- PowerPoint (.pptx) to continue editing
- PDF for a fixed viewing copy
- Google Slides to continue working in Google Workspace

Open the exported file and check content and formatting before you use it. Format changes do not always preserve every detail perfectly.

In the desktop app, open the presentation in PowerPoint or Keynote if those apps are installed. On macOS you can also show the file in Finder.

## Practical tips

Be specific about audience, length, and structure in your first prompt. Attach source notes or data so ChatGPT works from real material instead of inventing content.

Review every number, claim, and layout choice. ChatGPT can make mistakes when editing or generating content.

If you already use reusable workflows, see the guide on [creating and using ChatGPT Skills](/blog/chatgpt-skills-reusable-workflows/) for related automation patterns.

Start small. Generate a short deck, refine one or two slides with Request edits, then share it with one teammate before expanding collaboration.

## Conclusion

ChatGPT Slides moves presentation creation inside the same workspace where you already draft content. Eligible Pro, Business, and Enterprise users can generate an editable deck from notes or a conversation, revise it with ChatGPT or teammates in real time, and export to common formats. Check the OpenAI Help Center for the latest availability on your account.
