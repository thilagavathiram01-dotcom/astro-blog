Google rolled out Android 17 QPR3 Beta 2 on October 20, 2026, for supported Pixel devices. The build DP11.261002.005 focuses on stability fixes after Beta 1 and adds two practical UI controls.

If you already run the Android 17 beta program, the update arrives as an OTA. New testers can enroll through the official Android Beta program site. This release sits ahead of the expected March 2027 stable launch and does not introduce major API changes for developers.

## Check Device Eligibility

Android 17 QPR3 Beta 2 supports Pixel 6a and newer models, including the Pixel 7 series, 8 series, 9 series, 10 series, and 11 series, plus compatible Pixel Tablet devices. Pixel 6 and Pixel 6 Pro are not eligible for this QPR3 track.

Backup important data before installing. Beta software can contain remaining issues even after the latest fixes. Factory reset is not required if you stay within the beta program, but a clean install remains the safest path if you hit persistent problems.

## Install the Beta 2 Update

1. Open Settings > System > System update on your Pixel.
2. Tap Check for update. The OTA for build DP11.261002.005 should appear if your device is enrolled.
3. Download and install. The process restarts the phone once complete.
4. After reboot, go to Settings > About phone and confirm the build number ends in DP11.261002.005.

New users can enroll at the Android Beta program page, select their Pixel, and accept the terms. The first download may take longer. Once enrolled, subsequent betas arrive automatically.

## New Features in Beta 2

### Lock Quick Settings Connectivity

A new toggle requires the device to be unlocked before you can change Wi-Fi, Bluetooth, Airplane mode, or mobile data tiles. Find it under Settings > Display & touch > Lock screen. The option first appeared in Android Canary 2609 and now lands in the public beta.

Enable it if you want to prevent accidental changes when the phone is locked. It adds a small extra step for quick adjustments but improves security on shared or unattended devices.

### Wallpaper and Style Carousel

The Wallpaper & style app gains an interactive carousel. It groups Theme packs, Custom icons, Shape effects, Animate, and Weather effects into one place. Swipe through the options instead of jumping between separate menus.

The change is a quality-of-life improvement for people who frequently switch wallpapers or icon styles.

## Key Bug Fixes

Google lists more than 20 fixes in the official release notes. The most visible ones include:

- Intermittent crashes and reboots during normal use (multiple issue reports).
- Internet Quick Settings tile showing persistent text when mobile data is active without Wi-Fi.
- Unexpected shutdowns during WhatsApp video calls.
- Lock screen in-progress notifications overlapping other UI elements and causing animation stutter.
- Screen recording freezing after rotation.
- System UI and apps rendering at abnormally small scale regardless of display size settings.
- High idle battery drain from motion sensors staying active after Face Unlock or camera use.
- Bluetooth pairing timeouts and misaligned Quick Settings Bluetooth subtitle.

Additional fixes cover cellular connectivity on specific networks, Terminal app Linux environment launch failures, and app drawer closing when switching keyboard language. Full details appear on the Android Developers release notes page.

## Tips for Daily Use

Monitor battery and heat after the update. Most testers report better stability than Beta 1, but individual apps may still behave differently. Clear cache for problematic apps if needed.

If you previously installed [Android 17 QPR3 Beta 1](/blog/android-17-qpr3-beta-1-pixel-install/), this update should apply on top without data loss. Report remaining bugs through the beta feedback app or the Android Issue Tracker.

Developers should retest apps that interact with Quick Settings, lock screen notifications, or screen recording. No new SDK requirements appear in this QPR.

## Conclusion

Android 17 QPR3 Beta 2 delivers the stability improvements many Pixel beta users wanted after the first QPR3 build. The lockable connectivity tiles and wallpaper carousel add useful controls while the long fix list addresses crashes, battery drain, and UI glitches.

Install only if you accept beta risks. The March 2027 stable release remains months away, so later betas will continue refining the experience.
