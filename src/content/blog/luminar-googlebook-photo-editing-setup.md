Googlebook started reaching stores on October 4, 2026 in the United States, and a day later in Canada, the U.K., Ireland, France, Germany, and Australia. One of the first third-party editors rebuilt for the laptop is Luminar from Skylum. If you already edit on Android, the same account can open the app on the larger screen.

This guide covers install, sign-in, the laptop controls Skylum says meet Google’s Tier 1 bar, and the launch tools that are new on Googlebook: Generative Erase, HDR Merge, and batch editing.

## What Luminar adds on Googlebook

Luminar is already listed on Google Play as an AI photo editor for Android and ChromeOS, published by Skylum Software. The Play listing says the app is optimized for Android 11 and newer, and for ChromeOS devices with Android Runtime support. Version notes for 4.4.1 describe a build made for Chromebooks, tablets, and big screens.

On October 5, 2026, Skylum said the Googlebook build goes further. In a press release reported by 9to5Google, the company said Luminar for Googlebook is adapted for large screens and meets Google’s Tier 1 quality standards. The laptop-specific list includes resizable windows, full mouse and keyboard support, shortcuts, hover states, multitasking, drag and drop, and file handling. Those controls were not available on phones and tablets before this build.

Skylum also listed three tools that usually sit in desktop editors: Generative Erase, HDR Merge, and batch editing. The same Skylum account works on an Android phone and a Googlebook. A temporary offer gives 12 months of access free, with a later one-time purchase for premium features. Check the in-app offer and [Skylum pricing](https://skylum.com/luminar/pricing) before you assume a feature is included.

If you are still choosing a model, start with the [Googlebook launch checklist](/blog/choose-googlebook-october-4-launch/) so the laptop is signed in before you install editors.

## Install Luminar from the Play Store

Googlebook runs Android apps, so you do not need a separate desktop installer.

1. Open the Play Store on the Googlebook.
2. Search for Luminar by Skylum Software, or open the listing for package `com.skylum.luminar`.
3. Confirm the developer name is Skylum Software before you install.
4. Tap Install and wait for the download to finish.
5. Open Luminar and sign in with the Skylum account you already use on your phone, if you have one.

The Play listing notes in-app purchases. Free access for 12 months is a limited offer reported with the Googlebook launch, not a permanent free tier. If the offer does not appear, the listing may still be rolling out in your country.

Luminar can work without an internet connection after install, according to the Play listing. Sign-in, offer redemption, and some generative tools still need a network the first time you use them.

## Move photos onto the laptop

You have three practical ways to get files into the editor.

**From your phone.** If both devices use the same Google account, Google Photos is the simplest path. Download the originals you want to edit, then open them in Luminar. Do not edit the compressed preview if you shot RAW.

**Drag and drop.** Skylum says the Googlebook build supports drag and drop and file handling. Open the Files app or a folder of exported images, then drop a file onto the Luminar window. That is the main reason to edit here instead of on a phone.

**Continue On, if it is available.** Skylum’s release notes the Android 17 handoff feature with a qualifier: if Continue On is available at launch, you can start an edit on the phone and finish it on the laptop. Treat that as optional. If the handoff chip does not appear, export the file and open it on the Googlebook. A broader look at moving work between phone and laptop is in the [Continue On and Cast guide](/blog/googlebook-continue-on-cast-apps/).

## Use the laptop controls

Phone editing is thumb-first. The Googlebook build is meant to behave like a desktop app.

- Resize the window and snap it beside Files or Google Photos so you can compare the original.
- Use the mouse for masks and hover states. Skylum lists hover as a Tier 1 behavior, which matters when tooltips explain a slider.
- Learn the shortcuts the app shows in menus. Skylum did not publish a public shortcut card with the launch note, so read them inside the app rather than memorizing a third-party list.
- Keep a second window open for export. Multitasking is part of the Tier 1 claim, so you should not have to quit Luminar to rename a file.

If a control still looks like the phone layout, update Play services and the Luminar app, then relaunch. The 4.4.1 notes specifically call out big screens.

## Edit with the launch tools

Skylum named three features for the Googlebook launch. The exact button labels can differ by app version, so use the in-app search if a name does not match.

### Generative Erase

Generative Erase is the object-removal tool. Use it for signs, stray people, or sensor spots, not for rebuilding a whole scene.

1. Open a single photo, not a batch.
2. Find Generative Erase, GenErase, or Erase in the tool list.
3. Paint only the object you want gone.
4. Run the fill, then zoom to 100 percent and check edges.
5. If the fill repeats a pattern, undo and paint a smaller area.

### HDR Merge

HDR Merge combines bracketed exposures. Shoot the brackets on a tripod, or use a burst only if nothing in the frame moved.

1. Export the bracket set as separate files, not a single phone HDR preview.
2. Open HDR Merge and add the dark, middle, and bright frames.
3. Align the set if the app offers alignment.
4. Review ghosts around leaves, people, and water before you accept the merge.
5. Save the merged file, then apply color edits on that result.

### Batch editing

Batch editing is the reason the laptop build matters. A phone can apply a preset one image at a time. A windowed app can run the same look across a set.

1. Build the look on one keeper image: exposure, white balance, then a light structure or film setting.
2. Save that look as a preset if the app offers it. The Luminar mobile tutorial uses the same idea: finish one frame, then save a preset for the rest of the set.
3. Select the batch and apply the preset.
4. Spot-check the brightest and darkest files. A preset that looks right at noon can clip a sunset.

## Tips before you rely on it

- Download originals. Google Photos “storage saver” copies are a poor source for HDR Merge.
- Keep generative fills small. Large erasures are easier to spot on a laptop display than on a phone.
- Confirm the 12-month offer in the app. Do not plan a paid workflow around a launch promo that may be region-limited.
- Continue On is conditional in Skylum’s own note. Have an export path ready.
- Luminar on Googlebook does not replace the Adobe Photoshop months included with a Googlebook purchase. Use Photoshop when you need layers and desktop file formats. Use Luminar when you want the same Skylum account on the phone and the laptop.

## Conclusion

Luminar on Googlebook is a Play Store install, not a new desktop download. Sign in with your Skylum account, drag files into a resizable window, and use Generative Erase, HDR Merge, and batch editing when the build shows them. Treat the free year and Continue On as launch details you should confirm on your device.

Googlebook owners in the first wave can try this the same week the laptop hits shelves. Update the app if the window still behaves like a phone layout.
