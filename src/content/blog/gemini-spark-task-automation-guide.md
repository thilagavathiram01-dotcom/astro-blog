Gemini Spark turns the Gemini app from a chat window into a personal agent that can finish multi-step work while you do something else. On eligible Google AI Pro or Ultra accounts it connects to Gmail, Drive, Docs, and other apps, then keeps running even after you close the laptop.

Google rolled the feature out through 2026 and recently folded the Spark interface into the main Gemini experience as Task mode on some platforms. The core building blocks stay the same: tasks, skills, and schedules.

This guide uses official Gemini Apps Help steps so you can start a first task, monitor it, and keep control of what it touches.

## What you need before you start

You must meet every requirement or the Spark / Task entry will not appear:

- Age 18 or older.
- Personal Google Account (work and school accounts are excluded for now).
- Google AI Pro or Ultra subscription.
- Keep Activity turned on in Gemini settings.
- Supported region (currently unavailable in the European Economic Area, Switzerland, the United Kingdom, and Nigeria).

Open gemini.google.com or the Gemini mobile app and sign in with the correct account. If the sidebar or menu still shows only Chat, confirm the subscription and region before you continue.

For the September 2026 navigation changes that moved Scheduled and Customize items, see the [Gemini app side panel and settings guide](/blog/gemini-app-side-panel-settings-2026/).

## Switch to Spark or Task mode

On the web:

1. Go to gemini.google.com.
2. Open the sidebar.
3. Click Switch to Spark (or the Task button if your account already shows the redesigned prompt area).
4. The workspace changes to a task dashboard with areas for active work, schedules, and skills.

On Android or the Mac Gemini app the label may read Task instead of Spark. Google’s October 2026 redesign places Chat and Task buttons directly above the prompt box on some accounts, and moves the old Spark drawer entry into a unified history that filters by All, Ready, Needs attention, and In progress.

Once you are inside, the three primitives are:

- **Task**: one concrete outcome you want finished.
- **Skill**: reusable instructions you can call with / or @.
- **Schedule**: a time or event trigger that starts a task automatically.

## Create and monitor your first task

Describe a clear, verifiable outcome rather than a vague request.

1. In the Spark or Task text box, type the goal. Example: “Summarize unread newsletters in Gmail from the last three days, list the senders, and draft an unsubscribe reply for each that offers one.”
2. Optionally attach a file, a Drive item, or a Notebook.
3. Type / followed by a skill name if you already created one that matches.
4. Click or tap Submit.

Gemini builds a plan and may ask clarifying questions. Review the steps it lists before you confirm any action that touches an external site or sends a message.

To watch progress:

1. Open the task thread.
2. Tap the progress chip at the top for the work panel.
3. Check completed steps, files it read or wrote, and any request for you to take over a browser session.
4. If the plan drifts, type a correction in the same thread.

You can run up to 15 tasks at once. A schedule will not start if that limit is already reached. Pause or delete finished work so new jobs can enter the queue.

## Connect apps and add skills

Spark only reaches the apps you enable.

1. Open Settings (or Task settings after the redesign).
2. Go to Connected Apps or Apps.
3. Turn on Gmail, Calendar, Drive, Docs, Sheets, or other supported services.
4. Approve only the permissions the task needs.

Skills let you store long instructions once. Google is replacing the older Gems system with skills; personal accounts begin automatic migration in November 2026.

To create a skill:

1. Open the Skills page from Settings or the Spark sidebar.
2. Choose Create with Gemini or Create manually.
3. Give it a short name (hyphens only), a description that starts with “Use when…”, and the step-by-step instructions.
4. Optionally upload a reference PDF or text file.
5. Activate it.

In a task prompt type /skill-name or let Gemini pick an active skill automatically when the request matches the description.

## Schedule recurring work and stay in control

Schedules differ from the older scheduled actions inside normal Gemini chats. Attach a schedule to a task so it runs at a fixed time or after an event such as a new email.

Example schedule: “Every weekday at 8:00 AM, run the newsletter-summary task and save the result as a new Doc in my Daily Brief folder.”

Monitor the Schedules page (or the Scheduled filter in the redesigned history). Pause any job you no longer need. Gemini is designed to ask before high-stakes actions such as spending money or sending email; still review the first few runs yourself.

If Spark needs you to sign in to a website or finish a form, it hands the browser session back. Complete the step, then return control so it can continue.

To turn the feature off completely:

1. Open Settings & help, then Gemini Spark Settings (or Task settings).
2. Choose Turn off.
3. Existing tasks and files remain; schedules pause until you turn it back on.

Remote browser data is cleared when you disable it. Local Chrome data is not.

## Tips that keep results useful

- Write the outcome first, then the sources, then any constraints. Vague prompts produce vague plans.
- Test a task once manually before you attach a daily schedule.
- Keep the number of active connected apps small. Each extra permission expands what the agent can reach.
- Review Gemini Apps Activity after the first week so you can delete threads that contain sensitive drafts.
- If a task stalls, check the work panel for a permission or sign-in request rather than starting a second identical task.
- Free-tier users cannot access Spark; the entry point only appears after a Pro or Ultra upgrade.

## Conclusion

Gemini Spark (or the Task mode that replaced its drawer entry on some accounts) is the practical way to move multi-step Google Workspace work out of the chat window and into the background. Start with one narrow task, connect only the apps it needs, add a skill once the steps are stable, then schedule it.

Check the official help pages if the UI labels on your account differ from the steps above; the underlying requirements and limits stay the same.
