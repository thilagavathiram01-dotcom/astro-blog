Google rolled out a practical update to the Gemini app on 29 October 2026. You can now generate, preview, and edit documents, PDFs, presentations, spreadsheets, and code without leaving the chat.

This removes the old cycle of downloading a file, opening it in another app, making changes, and uploading it again. The feature is available to all users in every language where the Gemini app works.

## What Changed in Gemini File Handling

Previously, Gemini could create downloadable files. Now it keeps those files inside the conversation so you can review and revise them on the spot.

Three editing methods are available:

- Expand the file to full screen and type changes yourself.
- Highlight text or elements and ask Gemini a question about that section.
- Tell Gemini to refine the whole file or specific parts.

PDF preview and editing work on both the web version and the mobile app. Google Docs, Google Sheets, slide decks, Markdown files, TXT files, and code are supported on the web only for now.

You can also upload the finished files to Google Drive. The update builds on the file generation capability Google introduced earlier in 2026.

## Step-by-Step: Turn Handwritten Notes into an Editable PDF

Google’s own example shows how this works for students. Follow these steps on the Gemini app.

1. Open the Gemini app on web or mobile.
2. Upload photos of your handwritten lecture notes.
3. Prompt Gemini: “Create an in-depth study guide as a PDF using my lecture notes. Include visuals, graphs, and equations.”
4. Wait for Gemini to generate the PDF. A preview appears in the chat.
5. Expand the preview to full screen if you want to type corrections directly.
6. Highlight any section and ask Gemini to rewrite it, add a diagram, or clarify a concept.
7. Ask follow-up questions about the content while the file stays open.
8. Download the final PDF or upload it to Drive.

This workflow keeps everything in one place. You no longer need to export, edit externally, and re-import.

## Editing Spreadsheets and Slide Decks on the Web

On the web version you can generate structured trackers or presentation outlines. Preview the layout in chat, then expand to full screen for manual edits or ask Gemini to adjust tone, structure, or visuals.

For example, highlight a table and prompt: “Show this as a graph instead.” Gemini updates the file in place. Once satisfied, open the result directly in Google Sheets or Google Slides, or download it.

The same pattern works for Markdown drafts, plain text, and code files. Generate the file, review the preview, refine with highlights or full-screen edits, then export.

## Tips for Better Results

- Be specific in the initial prompt. Mention the desired format, length, and any required elements such as charts or equations.
- Upload clear images if you start from handwritten notes. Gemini handles typical handwriting, but very messy scans may need manual cleanup.
- Use highlighting for targeted changes rather than regenerating the entire file.
- Check platform limits. Mobile users should start with PDFs. Switch to the web version for Docs, Sheets, or slides.
- Always review the output. Gemini can introduce errors, especially with complex equations or precise data.
- Save a local copy after final edits. Files live in the chat, so download or move them to Drive for long-term storage.

## Conclusion

The October 2026 update turns the Gemini app into a lightweight editor for common file types. PDF work is possible on phones, while fuller document, spreadsheet, and slide support lives on the web. The three editing methods—full-screen typing, highlighting, and prompted refinements—cover most everyday revision tasks without switching apps.

Try it with a small real task first, such as a one-page summary or a simple tracker. Once the flow feels natural, scale it to longer reports or presentations. The feature is live for all Gemini users, so no special plan is required.
