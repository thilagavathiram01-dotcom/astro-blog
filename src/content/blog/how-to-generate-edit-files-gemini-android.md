Google rolled out the ability to generate, preview, and edit files directly inside the Gemini app. On Android phones the feature is live for every user, with one practical limit: full preview and editing of PDFs works on mobile, while most other formats stay on the web for now.

This guide shows exactly what you can do on your phone, how to start, and where the boundaries sit so you do not waste time on unsupported file types.

## What the update actually adds

As of 29 October 2026, Gemini can create and refine files inside the chat window. You expand a generated file to full screen, type changes yourself, highlight a section and ask Gemini to rewrite it, or request further adjustments in plain language.

Official details from the Google blog:

- PDF preview and editing works on both web and mobile.
- Google Docs, Google Sheets, slide decks, Markdown, plain text, and code are supported on the web only.
- The feature is available to all users in every language where the Gemini app runs.

On Android that means you can turn handwritten notes into a study guide PDF, clean it up, and export it without leaving the phone. For a full slide deck or spreadsheet you still open Gemini on a computer.

## Prerequisites

Make sure these are in place before you try the steps:

1. Install or update the Gemini app from the Play Store.
2. Sign in with your Google account.
3. Confirm you have a stable internet connection. File generation uses cloud models.

No special hardware or paid plan is required. The capability is open to free accounts as well.

## Step-by-step: create and edit a PDF on Android

1. Open the Gemini app.
2. Start a new chat or continue an existing one.
3. Type a clear request. Example: “Turn these handwritten lecture notes into a clean PDF study guide. Summarise key points and add a short quiz at the end.” Attach a photo of the notes if you have one.
4. Wait for Gemini to generate the file. A preview card appears in the chat.
5. Tap the preview to expand it to full screen.
6. Edit directly by tapping and typing, or highlight any text and ask Gemini to rewrite, shorten, or expand that section.
7. When the result looks right, download the PDF or share it from the full-screen view.

You can keep asking follow-up questions in the same chat. Gemini remembers the file context and can revise specific parts without regenerating the whole document.

## What works and what does not on mobile

| Action | Android support |
| --- | --- |
| Generate a PDF | Yes |
| Preview PDF full screen | Yes |
| Type edits inside PDF | Yes |
| Highlight and ask Gemini to edit | Yes |
| Generate Google Docs / Sheets / Slides | Generate only; edit on web |
| Markdown or code files | Generate only; edit on web |

If you need a presentation or spreadsheet, generate it on the phone, then open the same chat on gemini.google.com in a browser to finish the edits.

## Tips for better results

- Be specific in the first prompt. Include length, tone, and the sections you want.
- Upload reference material (photos of notes, existing PDFs, or text) so Gemini has real content to work from.
- Use the highlight tool for small changes instead of rewriting the whole file.
- Check numbers, names, and dates yourself. Gemini can still invent details.
- For long documents, break the request into stages: outline first, then expand each section.

## Limitations and privacy

Everything you upload or generate is processed by Gemini. Do not send confidential documents if your organisation restricts AI tools. Google states the feature is available to all users; there is no extra opt-in for file generation itself.

File size and page limits are not published in the announcement. Very large uploads may fail or be truncated. Start with short notes and expand.

## Conclusion

You can now create and refine PDFs inside the Gemini app on any Android phone that runs the latest version. The workflow is simple: ask, preview, edit in place, and export. For Docs, Sheets, and slide decks the same generation works, but finishing the file still happens on the web.

Update the Gemini app, try one short PDF from a photo of your notes, and you will see exactly where the mobile experience ends and the browser version takes over.
