Gemini Canvas turns the chat into a side-by-side workspace. You draft a document, build a small app, or turn notes into a quiz without switching tabs.

Google added Canvas to the Gemini app in March 2025. It now sits next to your prompt on gemini.google.com and in the mobile app. Free users get full access. Google AI Pro and Ultra accounts unlock Gemini 3 with a larger context window for bigger projects.

You stay signed in with a personal Google Account. Canvas works in every language the Gemini app supports.

## Start a new chat with Canvas

Open gemini.google.com and sign in.

Below the text box, click the plus icon or the Canvas button. Select Canvas. A chip appears in the prompt area to confirm the mode is active.

Type your request. Name the format if you want a specific result: “Create a slide presentation about quarterly sales” or “Build a simple quiz on the water cycle.”

Click Submit. The Canvas panel opens on the right. Your chat stays on the left. Changes save automatically.

On the Gemini mobile app, tap the plus icon below the prompt, then tap Canvas. The same workflow follows.

## Create and edit documents

Ask for a report, study guide, or proposal. Gemini writes the first draft in the Canvas panel.

Edit the text directly. Highlight a paragraph, then type a short instruction in the prompt box and press Enter. Only the selected section updates.

Use the quick tools at the top of the panel. Change length shortens or expands the whole document. Change tone shifts the writing from casual to formal.

Add formatting with the toolbar: headings, bold, lists, and links. For math or technical content, insert LaTeX equations that stay editable.

When the draft is ready, click Share & export. Export to Google Docs opens the text in a new document. You can also copy the contents or download as PDF.

## Build apps and code

Describe a small web app or game. “Create a tic-tac-toe game I can play against the computer” produces a working preview next to the chat.

Switch to Code view at the top right of the panel to see and edit the HTML, CSS, and JavaScript. Show console surfaces errors and logs. Show recent changes highlights what Gemini altered in the last turn.

Select a section of the preview with Select & ask, then request a change: “Make the X a blue spaceship and the O a green alien.” The update applies immediately.

Python scripts export to Google Colab with one click. Apps can include Gemini-powered features such as text generation if you are 18 or older.

Share the finished app with a public link. Review the app info before you create the link. Anyone with the link can view and copy the Canvas for their own use.

## Turn content into quizzes, slides, and more

Once a document sits in Canvas, click Create at the top right.

Choose Quiz to generate questions from the material. Infographic builds a visual summary. Web page converts the text into a simple site. Audio Overview produces a short podcast-style discussion.

For slides, describe the deck in the prompt. Gemini lays out the slides. Export to Google Slides or download as PDF.

Deep Research reports open in Canvas by default. From there the same Create menu turns the report into any of the formats above.

## Tips for better results

Start with a clear goal and audience. “Write a one-page study guide on photosynthesis for high-school students, then add a five-question quiz” produces tighter output than a vague request.

Upload source files when you have them. Notes, PDFs, or images give Gemini concrete material to work from.

Iterate in small steps. Ask for one change at a time so you can verify each update.

Watch usage. Canvas counts against your free-tier limits. Start a new chat if a long session slows down.

Users under 18 cannot create quizzes or share certain content. The Create menu hides those options for them.
