Google added a practical update to the Gemini app on 29 October 2026. You can now generate a file, see a live preview in the chat, and edit it without switching apps. PDF preview and editing works on both the web and the mobile app. Other formats stay web-only for now. The feature is available to all users in every language where the Gemini app runs.

This removes the old workflow of asking for a file, downloading it, opening it elsewhere, then coming back for the next change. Students, professionals, and anyone who drafts reports or study materials can stay inside one conversation.

## What the October 2026 update adds

Gemini already generated downloadable files. The new capability adds in-chat preview and three ways to change the result:

- Expand the preview to full screen and type edits yourself.
- Highlight text or a visual and ask a question about it.
- Highlight a section and ask Gemini to refine the text or visuals.

Google’s own example uses handwritten lecture notes. Upload photos of the notes, ask for a PDF study guide, then edit the result manually or by highlighting parts for Gemini to adjust. You can also ask follow-up questions about the content. The same idea works for other file types on the web.

PDF preview and editing is supported on both web and mobile. Google Docs, Google Sheets, slide decks, Markdown files, TXT files, and code are supported on the web only.

These capabilities are available to all users in all languages where the Gemini app is available. No paid plan is required for basic access.

After you finish, you can typically export the file or open it in the matching Google app (Docs, Sheets, or Slides) and save it to Drive. Exact export options can vary by format.

## Step-by-step: create and edit a file

1. Open the Gemini app. Use gemini.google.com for the widest set of formats, or the mobile app if you only need a PDF.

2. Upload source material if you have any. Tap the plus or attachment icon and add photos of handwritten notes, a report, or other files. This step is optional but improves results for study guides and summaries.

3. Write a clear prompt that names the format. Examples:
   - “Create a detailed PDF study guide from these lecture notes. Include key terms, a summary table, and practice questions.”
   - “Build a Google Sheet tracker for project tasks with columns for owner, deadline, and status.”
   - “Draft a short slide deck outline for a team update, then generate the slides.”

4. Wait for the preview to appear in the chat. Open it. On web you can expand to full screen for any supported format. On mobile this works for PDFs.

5. Edit in one of three ways:
   - Type changes directly in the full-screen view.
   - Select a paragraph, table, or visual, then ask a question such as “Explain this section in simpler language.”
   - Select the same content and request a change: “Turn this table into a graph” or “Shorten this paragraph and keep the main numbers.”

6. Review the result. Ask further questions in the same chat if something is unclear. Export or save to Drive when you are satisfied.

## Practical tips for better results

Start with a specific prompt. Name the audience, length, and required sections. “Make a PDF” produces a generic file. “Create a 4-page PDF study guide for a first-year statistics class that includes a glossary, one worked example, and five practice questions” produces something usable.

Use highlight-to-refine for small fixes instead of regenerating the whole file. This keeps context and usually finishes faster.

Check facts and numbers yourself. Gemini can misread handwriting or invent details. The study-guide example works best when you verify key terms and formulas.

On mobile, stick to PDFs for now. Switch to the web version if you need Docs, Sheets, or slides.

If you already use Gemini for notebook-style study tools, this feature pairs well with them. Upload the same notes and ask for an editable study guide in one chat. See our earlier guide on turning handwritten notes into a study guide for more prompt ideas.

## Limits to keep in mind

Google has not published detailed size limits for this specific editing flow. Standard Gemini file upload limits still apply. Availability follows the regions and languages where the Gemini app itself is offered.

Editing applies to files Gemini generates in the conversation. Uploading an existing third-party file and expecting full in-chat editing is not confirmed in the official announcement—test it if you need that workflow.

## Conclusion

The October 29 update makes Gemini more useful for everyday document work. You generate the file, preview it, and refine it in the same place. PDFs work on phone and web; other formats need the browser for now. Try it with a small real task—lecture notes, a meeting summary, or a simple tracker—and adjust the prompt based on what you see.
