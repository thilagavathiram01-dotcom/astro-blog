Google’s Create My Widget turns plain language into a working home screen widget. You describe what you want, and Gemini builds a resizable widget you can place immediately on Pixel and Galaxy phones.

This guide shows the exact steps to install the app, generate a widget, refine it, and add it to your home screen. The feature arrived as part of Gemini Intelligence and is available now through a dedicated Play Store app.

![Android smartphone home screen with apps and widgets](https://images.unsplash.com/photo-1512941937669-90a1b58e7e9c?auto=format&fit=crop&w=800&q=80)

## What Create My Widget Does

Create My Widget is a standalone Google app (package name com.google.android.apps.yourwidget). It uses Gemini to generate custom widgets from a text prompt. Categories include Combo, Weather Alerts, My World Clock, Daily Brief, Important Dates, and Markets.

You can start from a template or type your own description. Gemini pulls from Google Search and supported Google apps such as Calendar and Gmail where relevant. The result is a Material 3 Expressive widget you can resize and edit before placing it.

The app is currently limited to recent Google Pixel and Samsung Galaxy devices. Broader Android support is expected later. Googlebook laptops are also scheduled to receive the feature.

## Requirements Before You Start

Confirm these items:

- A compatible Pixel or Galaxy phone running a recent Android version.
- The Gemini app installed and signed in with a Google account.
- Internet connection for Gemini generation.
- Play Store access to install Create My Widget.

If the app shows as incompatible, your device may not meet the current rollout criteria. Check again after system updates.

## Step-by-Step: Create Your First Widget

### 1. Install the Create My Widget App

Open the Play Store and search for “Create My Widget” by Google LLC. Install the app. The listing confirms generative widgets using natural language.

### 2. Open the App and Choose a Starting Point

Launch Create My Widget. You will see category carousels with suggested widgets and a prompt box at the bottom labeled for describing your widget.

Tap a category such as Weather Alerts or Daily Brief for templates, or skip straight to the prompt.

### 3. Describe the Widget You Want

Type a clear request. Examples that match Google’s demos:

- “Suggest three high-protein meal prep recipes every week.”
- “Show only wind speed and rain chance for cycling.”
- “Countdown to my first marathon.”
- “Upcoming calendar events with the weather at each location.”

Gemini processes the prompt and returns one or more widget suggestions.

### 4. Review and Edit

Select a suggestion. Use the Edit option to adjust size, content, or appearance. Material 3 Expressive shapes are available for simpler designs. Follow-up prompts can refine the output further.

### 5. Add to Home Screen

When satisfied, add the widget. It appears on your home screen like any other widget. Long-press to move or resize it.

You can create additional widgets the same way. Multiple custom widgets can coexist on the home screen.

## Tips for Better Results

Be specific. “Weather” produces a generic result. “UV index, wind speed, and rain chance for my current location” produces a focused widget.

Combine data sources where supported. A Daily Brief can include recipes, facts, or affirmations. A Markets widget can track stocks or exchange rates.

Test updates. Many widgets refresh automatically. Open the app later if you want to regenerate or replace one.

If the first version is not perfect, edit it or start a new prompt. Gemini supports iteration.

Limitations exist. The tool cannot pull arbitrary third-party app data such as a custom Tinder widget. Stick to Google services and public web information for best reliability.

Create My Widget removes the need to wait for a developer to build the exact home screen view you need. Describe it, refine it, and place it. On supported Pixel and Galaxy devices the process takes minutes.
