Google rolled out in-chat file editing for the Gemini app on October 29, 2026. You can now generate, preview, and refine documents, PDFs, presentations, spreadsheets, code, and more without leaving the conversation.

This changes how people work with AI-generated files. Previously, you created a file, downloaded it, edited elsewhere, and re-uploaded. Now the entire loop stays inside Gemini.

The feature is available to all users in every language where the Gemini app works. PDF preview and editing works on both web and mobile. Other formats stay web-only for now.

## What you can edit and where

Gemini supports these formats for in-chat generation, preview, and editing:

- PDF (web and mobile)
- Google Docs (web only)
- Google Sheets (web only)
- Slide decks (web only)
- Markdown and TXT files (web only)
- Code files (web only)

You generate the file from a prompt or from uploaded content such as handwritten notes. Once created, the file opens as a preview inside the chat. You can expand it to full screen, type changes yourself, highlight sections, or ask Gemini to revise specific parts.

## Step-by-step: create and edit a PDF study guide

1. Open the Gemini app on the web or mobile. Upload photos of your handwritten lecture notes or type a detailed prompt such as “Turn these notes into a clear PDF study guide with headings, bullet points, and a summary table.”

2. Gemini generates the PDF. It appears as a preview in the chat. Tap or click to expand it to full screen if you want a larger view.

3. Edit manually. Type corrections directly into the full-screen editor. Change wording, fix formatting, or add missing details.

4. Highlight a section. Select text or a table, then ask Gemini to revise it. Example: highlight a table and type “show this as a graph instead.” Gemini updates the visual in place.

5. Ask follow-up questions about the content. The conversation stays tied to the file, so Gemini can refine further based on your feedback.

6. Download or open in Drive when finished. The edited version is ready to share or continue working on outside Gemini.

This workflow matches Google’s official demo of turning lecture notes into an editable PDF study guide.

## Editing Google Docs, Sheets, and slides on the web

On gemini.google.com you can generate a Google Doc, Sheet, or slide deck the same way. The file opens in an editable preview. Expand to full screen to type changes or highlight sections for Gemini to rewrite.

For a resume, prompt: “Create a one-page Google Doc resume for a software engineer based on this experience list.” Once generated, expand it, adjust bullet points yourself, or highlight a section and ask Gemini to make the language more concise.

Sheets work for trackers and tables. Ask for a project tracker, then highlight columns and request a chart or formula adjustments. Slide decks let you generate an outline, preview layouts, and refine content before exporting to Google Slides or PPTX.

Markdown and plain text files are useful for notes or code documentation. Code files support syntax-aware previews so you can review and tweak generated snippets before copying them out.

## Tips for better results

Be specific in the first prompt. Include the desired format, length, and style. Upload source material when possible so Gemini grounds the output in your content.

Use highlighting for targeted edits. Broad requests like “rewrite the whole document” can drift. Selecting a paragraph or table keeps changes focused.

Check mobile limitations. If you need to edit a Google Doc or Sheet, switch to the web version. PDFs work fully on the phone, which makes them practical for on-the-go study guides or reports.

Save versions. After major edits, download or open in Drive so you have a backup. The chat history retains the conversation but a separate copy is safer for important work.

Test with small files first. Complex multi-page documents with many images or formulas may take longer to generate and refine.

## Conclusion

In-chat file editing removes the export-edit-reimport loop for everyday documents and PDFs. All Gemini users can generate, preview, and refine files directly in the conversation starting October 29, 2026. PDFs work on mobile and web; Docs, Sheets, slides, Markdown, TXT, and code remain web-only for now.

Try it with a simple study guide or resume. Expand the preview, make a manual change, then highlight a section and ask Gemini to improve it. The feature is available now across supported languages.
