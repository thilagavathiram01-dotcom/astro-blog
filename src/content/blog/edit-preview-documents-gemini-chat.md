You no longer need to generate a file in Gemini, download it, open another app, and then return to chat for changes. On October 29, 2026, Google added in-chat preview and editing for documents, PDFs, presentations, spreadsheets, and code.

You can ask Gemini to create a PDF study guide from handwritten notes, then expand the preview to full screen, type edits directly, or highlight sections for Gemini to revise. The feature is available to all Gemini users in supported languages.

This guide shows the exact workflow based on Google’s announcement and Workspace updates.

## Supported formats and where they work

PDF preview and editing work on both the web version and the mobile Gemini app. Google Docs, Google Sheets, slide decks, Markdown files, TXT files, and code are supported on the web only.

You can generate Workspace files, PDFs, .docx, .xlsx, and more. After editing you can download the file or open it in the corresponding Google app or Drive.

## Step 1: Generate the file in chat

Open Gemini at gemini.google.com or in the mobile app and start a new conversation. Describe the file you need and name the format.

Examples:
- “Create a one-page PDF study guide from these handwritten lecture notes. Use one heading per topic and three bullet points under each.”
- “Build a Google Sheet tracker for weekly expenses with columns for date, category, amount, and notes.”
- “Draft a five-slide presentation outline for a team update, then generate the slides.”

Attach source material such as photos of notes or existing files when helpful. Gemini creates the file and opens a preview inside the chat.

## Step 2: Preview and make manual edits

Review the preview before you change anything. Check headings, numbers, and layout. Expand the preview to full screen on web to type edits directly into the document, spreadsheet, or slides.

For PDFs on mobile, the same expand-and-edit flow works. Highlight specific text or a table cell, then ask Gemini a question or request a rewrite for that section only. The rest of the file stays unchanged.

You can also ask Gemini to refine the entire file: “Make the tone more concise” or “Show this data as a bar chart instead of a table.”

## Step 3: Iterate and export

Continue the conversation for larger changes. Request new sections, adjust formatting, or add charts. The preview updates in place.

When finished, download the file or open it in Google Docs, Sheets, or Slides. Uploading to Drive is also supported. Shared links follow normal Gemini sharing rules.

## Practical examples

Turn lecture notes into a study guide: Photograph handwritten pages, upload them, and request a structured PDF. Then highlight any unclear section and ask Gemini to rewrite it for clarity.

Build a project tracker: Ask for a Google Sheet with status, owner, and due-date columns. Preview the table, correct a formula or category list by typing, then open the sheet in Google Sheets for further collaboration.

Create a presentation: Generate an outline first, then request slides. Adjust wording or layout in the preview before exporting to PowerPoint or Google Slides.

## Tips for cleaner results

Specify structure in the first prompt: number of sections, heading style, or column names. Clear structure reduces later edits.

Use highlight-and-ask for precise changes. This keeps the rest of the document intact.

Review numbers and proper nouns carefully. Gemini can misread handwriting or invent details when the source is ambiguous.

For spreadsheets, ask for sample formulas or data validation rules in the initial request.

## Limitations to know

Non-PDF formats are web-only for editing. Mobile users can generate them but must switch to a browser for full editing.

Complex layouts, heavy branding, or advanced macros still need a full desktop application after export.

The feature builds on earlier file-generation capabilities introduced in April 2026. The October update added the in-chat preview and direct editing layer.

## Conclusion

Gemini now lets you generate, preview, and edit documents, PDFs, spreadsheets, and slides without leaving the chat. Expand to full screen to type changes, highlight sections for targeted rewrites, or ask Gemini to refine the whole file.

The workflow is available today for all users. Start with a simple PDF or sheet, test the editing tools, and keep the conversation going until the file matches what you need.
