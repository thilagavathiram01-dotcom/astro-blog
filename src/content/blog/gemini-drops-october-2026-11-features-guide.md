Google released the October 2026 Gemini Drops on October 30, bundling 11 updates for the Gemini app. The list includes the frontier model Gemini 4 Argon, native desktop apps with Antigravity on macOS, Skills that replace Gems, inline file creation and editing, and Lyria 3.5 music generation.

These features target Android, iOS, web, and desktop users who already use Gemini for research, coding, and daily tasks. Availability varies by plan, region, and language. Google AI Pro and Ultra subscribers get the full set first.

This guide breaks down each feature, shows practical steps, and notes current limits so you can start using them today.

## Gemini 4 Argon: The New Frontier Model

Gemini 4 Argon became generally available on October 13, 2026. It handles complex multi-step tasks in coding, legal work, finance, and science. The model uses a 1M token context window and supports thinking levels (low, medium, high).

In the Gemini app, Pro and Ultra users select Argon from the model menu. On the API, the model ID is `gemini-4-argon`. Introductory pricing runs $2 per million input tokens and $10 per million output tokens through November 30, 2026, then doubles. Cached input stays 95% cheaper.

Argon breaks large jobs into steps and keeps you updated on progress. Early users report strong results on agentic coding and long reports. For Android integration details, see our guide on [adding Gemini 4 Argon with Firebase AI Logic](/blog/add-gemini-4-argon-android-firebase-ai-logic/).

## Desktop Apps: macOS Antigravity and Windows Shortcut

The Gemini app for macOS now includes a one-click Antigravity button. Jump from chat into a local coding environment to build, run, and debug software or prototype 3D ideas. Antigravity requires a Google AI Ultra plan and is currently English-only for users 18+.

On Windows, the desktop app (launched September 10, 2026) opens with Alt+Space. It supports chat, image generation, and tasks across Gmail and Drive. More native features such as screen sharing and local file Tasks are still rolling out.

Download both at gemini.google/desktop. Requirements are modest: Windows 10 or later, or Apple Silicon Mac on macOS Sequoia (15) or later, plus 8 GB RAM.

## Skills Replace Gems

Skills are reusable, slash-command prompt sets that live inside any chat. You can stack multiple Skills in one prompt. They began rolling out to the Gemini app on October 13, 2026, for free and paid accounts.

Gems move to Settings on November 17, 2026. Personal accounts see automatic migration to draft Skills. Business and enterprise accounts keep Gems until no sooner than March 1, 2027; education follows in June 2027. Some features (Canvas, Deep Research, music generation) do not carry over yet.

**How to create a Skill:**

1. Open gemini.google.com on a computer.
2. Click Customize or the Skills section.
3. Add a name, description, and instructions.
4. Attach knowledge files if needed (supported types only; 100 MB limit).
5. Save and call it with `/skill-name` in any chat.

Test the Skill with a short prompt before relying on it for long tasks.

## File Creation, Preview, and Editing

On October 29, 2026, Google added full preview and editing for files generated inside the Gemini chat. Ask for a PDF study guide, slide deck, spreadsheet, Markdown file, or code, then expand it to full screen, type edits, or highlight sections for targeted changes.

PDF editing works on web and mobile. Other formats (Docs, Sheets, Slides, code) are web-only for now. The feature is available to all users in supported languages.

**Quick workflow:**

1. Prompt: “Create a one-page PDF summary of quantum computing basics with diagrams.”
2. Wait for the inline preview.
3. Expand to full screen or highlight a paragraph and say “Make this section shorter.”
4. Download or open in the matching Google app.

This removes the copy-paste step for most document work.

## Other October Features

**Personal Intelligence with Maps.** Deeper Google Maps integration helps with location-aware planning. Rollout is gradual by region.

**Gemini Notebook integration.** Add NotebookLM sources directly. Off by default in the EEA.

**Expanded connectors.** Link more third-party apps (over 40, including Instacart, OpenTable, Adobe, Shopify) via the Customize menu. Mostly US English at launch.

**Immersive explorations.** Interactive deep dives for students and learners. Select a topic and step inside visual explanations.

**Lyria 3.5 music.** Generate full tracks (up to about 3 minutes) with better vocals and structure. Available globally in the app and API. Choose genre, vocals, and length. Requires 18+ and Keep Activity on for full tracks.

**Shareable avatars.** Create and share your avatar for personalized images without re-uploading photos each time.

## Practical Tips

Start with Skills for any prompt you reuse more than twice a week. Export critical Gem files before the November 17 move if they contain unsupported types.

For Argon, begin with medium thinking. Raise to high only for hard multi-step coding or analysis. Monitor token use because the introductory rate ends soon.

On desktop, use the keyboard shortcut instead of switching to the browser. On Mac, test Antigravity with a small prototype before larger projects.

File editing shines for iterative drafts. Generate, highlight, revise, then export. Keep the chat open so context stays available.

## Availability and Pricing Notes

Argon and Antigravity require paid plans (Pro or Ultra for the model in the app; Ultra for Antigravity). Skills, file editing, Lyria 3.5, and the Windows app are free for most users. Desktop features and some connectors have language or region limits. Check gemini.google.com or the Gemini Drops hub for the latest status in your country.

## Conclusion

The October 2026 Gemini Drops turn the app into a more complete workspace. Argon handles harder tasks, Skills keep your best prompts ready, desktop apps reduce context switching, and inline file tools cut extra steps. Start with the features available on your plan and device. Create one Skill today and generate a short file to see the difference.
