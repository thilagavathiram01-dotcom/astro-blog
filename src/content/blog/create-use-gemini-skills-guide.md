Google is replacing Gems with Skills in the Gemini app. For personal accounts, the transition starts in November 2026, with Gems moving on November 17. Skills let you save reusable instructions that Gemini can apply automatically or on demand. You create them once and reuse them across chats without retyping preferences or re-uploading files.

This guide shows how to create and use Skills on gemini.google.com or the Gemini mobile app. It covers the four creation methods, how to trigger them, and what to do with existing Gems. All steps come from Google’s official Help Center pages.

## Requirements before you start

You need a personal Google Account and must be 18 or older. Sign in to the Gemini app or gemini.google.com. Turn on Keep Activity in Gemini settings. Skills are currently available in the Gemini mobile app, the Gemini app on Mac, and the web app. They do not yet sync with Google Workspace apps.

If you use Gems today, Google will automatically convert remaining ones to draft Skills later. You can recreate them manually now for earlier access.

## How to reach the Skills page

On a computer, go to gemini.google.com. In the sidebar, click Customize. If you do not see it, click More first. Then click Skills at the top. On the Gemini mobile app, tap the menu, then Customize, then Skills.

From here you can create, edit, activate, or delete Skills. You can also ask Gemini to create one directly from any chat.

## Four ways to create a Skill

Google offers four methods on the Skills page.

**Create with Gemini.** Click Create, then Create with Gemini. Describe the task in the chat that opens. Gemini drafts the name, description, and instructions. Review and save. This is the fastest option if you are new to Skills.

**Edit a prefilled template.** Under Recommended, select a template. Adjust the name, description, and instructions. Click Create when finished.

**Create manually.** Click Create, then Create manually. Enter a name in lowercase with hyphens (for example, summarize-meeting-notes). Add a 1–2 sentence description and the full instructions. Click Create.

**Upload a file or folder.** Click Create, then Upload. Select a SKILL.md file, or a folder or .zip that contains SKILL.md at the root. You can add reference files from your device, Google Drive, Google Photos, or Notebooks. The total size must stay under 100 MB. Remove hidden files such as .DS_Store before uploading. Supported types include .docx, .pdf, .md, .txt, .csv, .xlsx, .pptx, images, and certain code files.

You can also type in any chat: “Create a skill based on these instructions: [your details].” Gemini saves the result to your Skills page.

## Write effective Skills

The name and description control when Gemini applies the Skill. Start the name with a verb and use lowercase hyphens. Avoid generic words such as helper or data. Example: plan-meal-from-recipe.

Write the description in the third person. Begin with what the Skill does, then add “Use when…” followed by concrete examples. A vague description means Gemini may skip it. Keep it to one or two sentences.

In the instructions, focus on the type of task rather than one specific request. Include output formats or templates when you need consistent results. Add a section that lists common mistakes to avoid. Tell Gemini what to do if required information is missing. You can reference other Skills inside the instructions to build multi-step workflows.

## How to use Skills in a chat

Type / in the prompt box (or @ on accounts with the updated shortcut). Select the Skill from the list, then add your request. Gemini applies the instructions.

Activated Skills can also trigger automatically when your prompt matches the description. You can stack multiple Skills in one message. For example, combine a writing-style Skill with a meeting-prep Skill.

To manage automatic use, open the Skills page, find the Skill, and turn it on or off. If a Skill is off and you request it, Gemini asks whether to activate it. You cannot activate, deactivate, or delete from inside a chat—those actions stay on the Skills page.

## Manage, edit, and delete Skills

On the Skills page, click the three-dot menu next to any Skill. Choose Edit to change the name, description, or instructions. To update attached files, download the Skill as a .zip, add or replace files, and upload it again. You can also ask Gemini in chat to update an existing Skill.

Download a Skill to back it up or share the SKILL.md file. Deletion is permanent. Once removed, the Skill cannot be recovered.

## Prepare for the Gems transition

Starting November 17, 2026, Gems move to the Settings panel in the Gemini app for personal accounts. Users can still create, edit, and use them there for a period. Google will later convert remaining Gems into draft Skills automatically. Workspace business, enterprise, and education accounts follow later timelines in 2027.

To move a Gem yourself:

1. Open the Gem, download any knowledge files, and copy the name, description, and instructions.
2. Create a new Skill manually and paste those details. The name converts to the required lowercase hyphen format.
3. If you need the files, download the new Skill, place SKILL.md and the files in one folder, then upload the package.

Past chats that used Gems remain in your history. Some features such as Canvas or Deep Research are not yet available inside Skills.

If you analyze data with Gemini tools, the same instruction-writing habits apply. See the guide on [analyzing data with Gemini in BigQuery](/blog/analyze-data-gemini-bigquery-step-by-step/).

## Tips for better results

Test each Skill in a new chat right after creation. Refine the description if Gemini does not trigger it when expected. Keep reference files small and relevant—the 100 MB limit is total across all files in one Skill. Start with one recurring task such as weekly status updates or email drafts before building complex stacks.

Skills work across the mobile app and web once created. Full editing and uploads remain easiest on gemini.google.com.
