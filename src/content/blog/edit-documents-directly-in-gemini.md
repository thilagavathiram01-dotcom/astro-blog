Google added direct file generation, preview, and editing inside the Gemini app on October 29, 2026. You can now create a PDF study guide from handwritten notes, expand it to full screen, type changes yourself, highlight sections for Gemini to revise, and ask follow-up questions—all without leaving the chat.

The feature is available to all users in every language where the Gemini app works. PDF preview and editing works on both web and mobile. Google Docs, Sheets, slide decks, Markdown, TXT, and code files are web-only for now.

## What You Can Do

Ask Gemini to generate a file. A preview opens inside the conversation. From there you have three options:

- Expand the file to full screen and type edits directly.
- Highlight any text and ask a question about it.
- Tell Gemini to refine the selected section or the whole file.

You can export the finished file or open it in the matching Google Workspace app. This removes the old loop of generating, downloading, editing elsewhere, and uploading again.

## Step-by-Step: From Notes to Study Guide

1. Open gemini.google.com or the Gemini app and start a new chat.
2. Upload photos of your handwritten lecture notes using the plus button.
3. Prompt: “Turn these notes into a one-page PDF study guide with clear headings and five practice questions.”
4. Wait for the preview to appear in the chat.
5. Expand to full screen if you want to type corrections yourself.
6. Highlight any section and type “Explain this in simpler words” or “Make this bullet more concise.”
7. Ask follow-up questions about the content while the file stays open.
8. Export or download when the guide looks right.

The same flow works for Google Docs, Sheets, and slide decks on the web. For Sheets you can highlight a table and say “show this as a graph instead.” Gemini updates the visual in place.

## Supported Formats and Limits

| Format | Web | Mobile |
|--------|-----|--------|
| PDF | Preview + edit | Preview + edit |
| Google Docs | Preview + edit | No |
| Google Sheets | Preview + edit | No |
| Slide decks | Preview + edit | No |
| Markdown / TXT | Preview + edit | No |
| Code | Preview + edit | No |

Heavy iteration counts against your normal Gemini usage quota. Complex multi-page files may take longer to generate and refresh.

## Tips for Cleaner Results

Upload clear, well-lit photos when starting from handwritten notes. Include every page in one message so Gemini sees the full set.

Be specific in the first prompt. State the audience, length, and required sections. “One-page study guide for a biology midterm with headings, key terms, and five questions” works better than “make a PDF.”

After the first preview, refine in small steps. Fix headings first, then examples, then questions. Highlighting a single paragraph and requesting a change keeps the rest of the file stable.

On the web, switch to full-screen mode for longer typing sessions. On mobile, stick to PDFs until other formats gain support.

## What Happens After You Finish

Export the file to Google Drive, download it, or open it directly in Docs, Sheets, or Slides. You can return to the original Gemini chat later and request updates; the conversation context remains.

Keep the source photos or notes. Re-uploading them later lets you regenerate a fresh version if the first draft drifts too far from your material.
