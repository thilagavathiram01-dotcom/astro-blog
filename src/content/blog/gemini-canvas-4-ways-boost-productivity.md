Gemini Canvas turns your chat into an interactive workspace. You describe what you need and the tool builds documents, apps, quizzes, or trackers right beside the conversation. Google highlighted four practical uses on November 23, 2026, that help with daily work and learning.

This guide shows how to open Canvas and apply each of those four methods. You can start from the web app at gemini.google.com or the Gemini mobile app. All steps rely on official guidance from Google.

## What is Gemini Canvas

Canvas is an interactive space inside the Gemini app. It sits next to your chat so you can generate content, edit it directly, and ask for changes without leaving the window. You can write documents, build simple web apps, turn notes into quizzes, or convert data into trackers.

Google describes it as a place to collaborate on writing, coding, and creation. Changes appear in real time. You can highlight text and request targeted edits, or switch between code and preview for apps. The feature is available to all Gemini users. Paid Google AI Pro and Ultra plans unlock more capable models and a larger context window for complex projects.

## How to open Canvas

Start by signing in at gemini.google.com. Below the prompt box, click the tools icon (often labeled + or Add files / tools). Select Canvas from the list. Type your prompt and submit. The canvas opens beside the chat.

On the mobile Gemini app, tap the add button and choose Canvas. Name the format you want in the prompt, such as “create a quiz” or “build a simple pricing calculator.” Google notes that specifying the output type improves results.

You can also upload files or images with the prompt. Once the canvas loads, edit directly or continue the conversation to refine the output. Changes save automatically.

## Create web apps and mini-games

Canvas can generate working single-page web apps and simple games from a plain description. Ask for a 3D visualizer, a playable browser game, or a small interactive tool. The output is typically a self-contained HTML file you can preview live.

Try a prompt like: “Build a tic-tac-toe game with a clean interface and score tracking.” Or request a visualizer: “Create a 3D chart that shows monthly sales with adjustable sliders.” After generation, switch to the preview tab to test it. Use the chat to request changes such as “make the buttons larger” or “add a reset option.”

You can edit the code directly in the code view or ask Gemini to update specific parts. Export or share the finished app when ready. This approach suits quick prototypes without setting up a local development environment.

## Make custom study tools

Turn static notes or uploaded PDFs into interactive learning materials. Prompt Canvas to create quizzes, flashcards, or sandboxes based on your content. Upload a document first, then ask for a quiz that tests the key points.

Example prompt: “Turn these notes into a multiple-choice quiz with explanations for each answer.” Or “Create flashcards from this PDF covering the main concepts.” The canvas generates the interactive version. You can practice directly and ask for adjustments, such as harder questions or more examples.

This works well for exam preparation or reviewing meeting notes. The Create menu (available after generating a document) also offers quiz and flashcard options from existing content.

## Design office productivity boosters

Convert spreadsheets or raw data into practical tools. Ask for a sales tracker, pricing calculator, or task list that updates based on inputs. Upload a spreadsheet if you have one, or describe the structure.

Prompt example: “Create a pricing calculator that takes quantity and unit cost and shows total with tax.” Or “Build a simple sales tracker with columns for date, product, and amount, plus a running total.” Canvas produces an interactive version you can use and modify.

Highlight sections to request specific updates. These tools stay in the canvas so you can iterate without copying data between apps. Export to Google Sheets or other formats when the design is complete.

## Refine writing side-by-side

Canvas supports focused editing for documents, proposals, or reports. Generate a draft or paste existing text. Highlight any sentence or paragraph, then ask Gemini to adjust tone, rephrase, or restructure only that section.

Quick tools include Change length, Change tone, and Suggest edits. You can also use the formatting toolbar for headings, bold, italics, and lists. The chat stays available for broader requests such as “make the introduction more formal” while the canvas shows the live result.

This side-by-side view keeps context visible. It helps when polishing a speech, revising an essay, or tightening a business proposal. Select text and request precise changes without regenerating the entire document.

## Tips for better results

Be specific in prompts. Name the format, features, and audience. For apps, request a single HTML file so the preview loads cleanly. Change one element at a time rather than asking for many updates in one message.

Upload source material when possible. Notes, PDFs, or spreadsheets give Canvas concrete content to transform. Review the output and use the chat for follow-up refinements. Check Google’s help pages for current limits, as availability can depend on your plan and region.

## Conclusion

Gemini Canvas provides four concrete ways to move from chat to usable output: interactive apps and games, study tools from notes, office trackers and calculators, and precise writing refinements. Open the tool from the prompt bar, describe the result you need, and iterate in the shared workspace. These methods reduce context switching for everyday tasks and learning.

Try one of the examples in your next Gemini session. Official documentation and the November 2026 announcement confirm the capabilities described here.
