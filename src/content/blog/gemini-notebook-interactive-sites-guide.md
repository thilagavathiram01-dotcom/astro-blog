Google rolled out a new feature in Gemini Notebook on November 16, 2026. You can now turn the sources in your notebook into interactive websites by typing a simple prompt in the chat. The sites work for study explainers, data dashboards, and project trackers, and you can open them in a new tab or share them.

This builds on the existing ability to add sources like textbooks, PDFs, and web pages. If you already use free textbooks in Gemini Notebook, this gives you a visual way to explore that material. See our guide on [adding free textbooks to Gemini Notebook](/blog/add-free-textbooks-gemini-notebook/) for the setup steps.

## What the interactive sites feature does

Gemini Notebook uses the sources you have already added. When you ask it to create a site, it builds an interactive page based on that material. Google highlights three main uses.

Visual explainers help with exam prep. Examples include an interactive periodic table or a historical timeline you can click through. Interactive dashboards let you explore data, such as quarterly sales numbers with charts and filters. Project management trackers outline tasks and deadlines in a clickable format.

Once the site is ready, select “Open in a new tab” to interact with it. You can also share the result with others. The feature rolls out globally on the web for Gemini Notebook users aged 18 and older, including Google Workspace subscribers. Mobile app support is coming soon.

## How to create an interactive site

Open Gemini Notebook at notebook.google.com and sign in. Create a new notebook or open one that already has sources. Make sure the sources you want to use are added and selected. The tool draws only from what you provide, so quality sources lead to better sites.

In the chat panel, type the prompt “make me a site” followed by a clear description of what you need. For example: “make me a site to help me understand the periodic table from these sources.” Or “make me a site that shows quarterly sales as an interactive dashboard with charts.”

Gemini Notebook processes the request and generates the site. When it finishes, choose “Open in a new tab.” The site loads in its own browser tab so you can click, filter, or explore without staying inside the chat. Sharing options appear so others can view the same page.

You can refine the request if the first result needs changes. Add more detail about the layout, specific data points, or interactive elements you want. The feature works with the sources already in the notebook, so update those first if needed.

## Examples for students and professionals

Students can turn textbook chapters or lecture notes into an interactive explainer. Upload or add a chemistry source, then ask for a periodic table that highlights groups and shows details on click. History students can request a timeline that expands events with source citations.

Professionals can load sales spreadsheets or reports and ask for a dashboard. The site can include sortable tables, bar charts that switch views, and filters for time periods. Project teams can create a tracker that lists tasks, owners, and deadlines, with status indicators you can update visually.

These outputs stay grounded in your sources. The tool does not pull random web information unless you have added those pages as sources. This keeps the content accurate for study or work use.

## Tips for better results

Be specific in your prompt. Instead of “make me a site,” add the purpose, audience, and key elements. “Make me a site for exam review that includes a quiz on the first three chapters and a timeline of key events” gives clearer direction.

Select only the relevant sources before you ask. Extra unrelated material can dilute the output. Check the source panel and toggle off anything not needed for this site.

After the site opens, test the interactive parts. Click filters, sort columns, or expand sections. If something is missing, go back to the chat and ask for an adjustment, such as “add a filter for date range to the dashboard.”

Pair this with other Gemini Notebook tools. Generate a quiz or study guide from the same sources, then link the ideas in your interactive site. The free textbook catalog works well as a base for explainer sites.

## Limits to keep in mind

The feature is available on the web first. Mobile app support arrives later. Only users 18 and older can use it, including those on Google Workspace plans.

Sharing works, but Google has not detailed every permission option in the initial announcement. Test a shared link to confirm what the recipient sees. The site is based on your current sources; if you update the notebook later, you may need to regenerate.

It is not a full website builder for public company sites. The results are interactive pages meant to help you and others understand the material in your notebook. For complex custom code or public hosting beyond sharing, you may still need other tools.

## Conclusion

Interactive sites turn Gemini Notebook from a chat and study tool into a place where you can quickly build clickable explainers, dashboards, and trackers. Type “make me a site” plus a description, open the result in a new tab, and share when ready. Start with the sources you already have, especially free textbooks or project files, and refine the prompt until the page matches what you need.

The rollout began November 16, 2026 on the web. Check notebook.google.com to try it with your own material.
