Google added direct file editing inside Gemini chats on October 29, 2026. You can now generate a document, spreadsheet, presentation, PDF, or code file, preview it in the conversation, and refine it without downloading or switching apps.<grok type="render_inline_citation" citation_id="57" />

Previously, Gemini could create and export files. Any tweak required regenerating the whole file or opening it elsewhere. The new preview keeps the file open in the chat so you edit it in place.

This works for all Gemini users in every language where the app is available, including free personal accounts. No paid plan is required.<grok type="render_inline_citation" citation_id="59" />

## What you can generate and edit

Gemini supports several formats. You ask for the file type in your prompt, upload source material if you have it, and the result appears as an interactive preview.

Supported formats include:

- PDFs
- Google Docs
- Google Sheets
- Slide decks
- Markdown files
- Plain text (TXT)
- Code files

You can also upload photos of handwritten notes and ask Gemini to turn them into a structured PDF study guide. Once generated, you refine the content or visuals further.<grok type="render_inline_citation" citation_id="57" />

If you already use Gemini for study materials, our guide on [creating a PDF study guide from handwritten notes](/blog/create-pdf-study-guide-gemini-handwritten-notes/) shows the upload and prompt steps that pair well with this editing flow.

## Web versus mobile support

Platform support is split. PDF preview and editing works on both the web (gemini.google.com) and the Gemini mobile app. All other formats—Google Docs, Sheets, slide decks, Markdown, TXT, and code—are currently available only on the web.<grok type="render_inline_citation" citation_id="57" />

On mobile, stick to PDFs for full in-chat editing. For Docs, Sheets, or presentations, switch to a browser. Google says the feature is available now across Rapid Release and Scheduled Release Workspace domains as well as personal accounts.<grok type="render_inline_citation" citation_id="59" />

## How to generate, preview, and edit a file

Follow these steps on the web for the widest format support. The same flow applies to PDFs on mobile.

1. Open gemini.google.com (or the Gemini app for PDFs) and start a new chat or continue an existing one.

2. Optionally upload source material. Click the plus icon, choose files or photos, and attach lecture notes, a report, or images of handwritten pages.

3. Write a clear prompt that specifies the format. Example: “Create a PDF study guide from these lecture notes with key concepts, practice questions, and a summary table.” Or: “Generate a Google Sheet tracker for project tasks with columns for owner, status, and due date.”

4. Wait for Gemini to generate the file. It appears as a preview card in the chat.

5. Open the preview. Expand it to full screen so you can type edits directly into the text, just as you would in a word processor or spreadsheet.

6. Highlight any section, table, or visual. Then type a request such as “make this paragraph shorter,” “turn this table into a graph,” or “explain this concept in simpler terms.” Gemini applies the change to the existing file instead of regenerating everything.

7. Review the updated preview. Ask follow-up questions about specific parts if needed.

8. When the file looks correct, use the export or open options. You can download it, open it in Google Docs or Sheets, or save it to Drive.<grok type="render_inline_citation" citation_id="57" />

## Practical tips for better results

Specify the exact format and structure in your first prompt. “Create a PDF with three sections and a summary table” produces more usable output than a vague request.

Use the highlight feature for targeted changes. Asking Gemini to rewrite one paragraph or convert one chart is faster and more accurate than regenerating the whole file.

Check facts and calculations yourself. Gemini can summarize notes or organize data, but it may misread handwriting or invent details. Verify numbers, quotes, and citations before sharing.

Start with a clean source. Clear photos of handwritten notes or well-structured text produce better study guides and documents. Crop out extra margins or shadows when possible.

For long documents, break the work into steps. Generate an outline first, then expand sections one by one, editing as you go. This keeps the context focused.

Workspace users can open the refined file directly in Google Docs, Sheets, or Slides for further collaboration. The in-chat preview is useful for quick drafts; the native apps remain better for complex formatting or real-time team editing.<grok type="render_inline_citation" citation_id="59" />

## Limitations to know

Non-PDF formats are web-only for now. Mobile users who need to edit a Sheet or slide deck should switch to a desktop or laptop browser.

The preview is interactive but not a full replacement for the dedicated apps. Complex layouts, advanced formulas, or heavy formatting still work better after you open the file in Docs or Sheets.

Editing applies to the generated file inside that chat. Starting a new conversation creates a fresh context. Keep related edits in the same chat thread when possible.

## Conclusion

The October 29 update removes the extra step of downloading a Gemini-generated file just to fix a typo or adjust a chart. You generate, preview, and refine documents, spreadsheets, presentations, PDFs, and code in one conversation.

Try it with a small task first—a simple PDF summary or a basic task tracker—so you see how the full-screen editor and highlight prompts behave. Once the workflow feels familiar, use it for study guides, reports, or project trackers.
