Google added in-chat file generation, preview, and editing to the Gemini app on 29 October 2026. You can now create a PDF study guide, a slide deck, or a spreadsheet, see it inside the conversation, and refine it without switching apps.

This guide shows exactly how the feature works, which formats are supported on web versus mobile, and practical steps to generate and edit files.

## What the October 29 update added

Gemini already let you generate files earlier in 2026. The new change keeps the file open inside the chat. You can expand it to full screen, type changes yourself, highlight a section and ask Gemini about it, or tell Gemini to refine the whole file.

PDF preview and editing work on both the web (gemini.google.com) and the mobile apps. All other formats—Google Docs, Google Sheets, slide decks, Markdown, TXT, and code—are available on the web only for now. The feature is available to all users in every language where the Gemini app runs.

## How to generate a file

Open the Gemini app or go to gemini.google.com. Start a new chat or continue an existing one.

Type a clear prompt that specifies the file type and purpose. Examples that work well:

- “Create a PDF study guide from these handwritten lecture notes” (then attach the image or notes).
- “Generate a Google Sheets tracker for my monthly expenses with columns for date, category, and amount.”
- “Make a short slide deck outline for a 10-minute product update.”

Gemini produces the file and shows a preview card in the chat. Tap or click the preview to open it.

## Three ways to edit the file

Once the preview appears, you have three editing options:

1. **Expand to full screen and type.** Open the file in the larger view and edit text directly, the same way you would in a basic editor.
2. **Highlight and ask.** Select a paragraph, table, or visual. Then ask Gemini to shorten it, turn the table into a graph, or explain the section.
3. **Prompt for refinement.** Type a follow-up such as “Make the tone more formal” or “Add a summary section at the end.” Gemini updates the file.

## Format support: web vs mobile

| Format              | Web (gemini.google.com) | Mobile app |
|---------------------|-------------------------|------------|
| PDF                 | Yes                     | Yes        |
| Google Docs         | Yes                     | No         |
| Google Sheets       | Yes                     | No         |
| Slide decks         | Yes                     | No         |
| Markdown / TXT      | Yes                     | No         |
| Code files          | Yes                     | No         |

On mobile you can still generate most formats, but only PDFs can be previewed and edited in the chat. For Docs, Sheets, or slides, use the web version.

## Export and next steps

After editing, use the export or share controls in the preview. Common options include:

- Download the file (PDF, PPTX, or other supported formats).
- Upload it to Google Drive.
- Open a Google Sheet or slide deck directly in the corresponding Google app.

If you are building study materials, the same workflow pairs well with Gemini Notebook. You can generate a quiz or summary from a textbook you added earlier—see our guide on [adding free textbooks to Gemini Notebook](/blog/add-free-textbooks-gemini-notebook/).

## Tips for better results

- Be specific about structure. Say “include a table of contents and three key takeaways” rather than “make a document.”
- For PDFs from photos or handwritten notes, upload the source first so Gemini has the raw content.
- Review the preview before exporting. The in-chat editor is fast for small fixes but not a full desktop suite.
- On mobile, stick to PDFs if you need to edit on the go. Switch to web for everything else.

## Conclusion

The October 29 update turns Gemini from a chat tool that exports files into one that keeps the file open for quick edits. Generate a PDF on your phone, refine a spreadsheet on the web, or highlight a section and ask for a change—all without leaving the conversation.

Start with a simple prompt today. Once the preview appears, expand it and make one small edit to see the flow.
