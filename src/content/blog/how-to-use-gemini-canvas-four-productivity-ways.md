Google published a short post on 23 November 2026 highlighting four practical ways people use Gemini Canvas. Canvas is the interactive workspace that sits next to your chat in the Gemini app. You generate something, then edit it directly or by asking follow-up questions.

This guide walks through each of the four uses with concrete steps. All details come from Google’s official blog post and the Gemini Apps Help pages for Canvas.

## Start a Canvas session

Open [gemini.google.com](https://gemini.google.com) in a browser and sign in. Below the prompt box, select **Canvas**. On some accounts it appears under the **+** or **Tools** menu. Type your request and submit. The result opens in a panel on the right while the chat stays on the left.

You can also upload files or images with the **Add files** control. Changes save automatically. On mobile, the path is usually **Add > Canvas**.

Canvas is available to signed-in Gemini users. Higher plans give larger context windows and stronger models, but the core features work on the free tier.

## Create web apps and mini-games

Ask Canvas to build a small interactive prototype. Google’s example is a 3D visualizer or a playable browser game such as tic-tac-toe.

1. Select Canvas.
2. Prompt: “Create a simple tic-tac-toe game I can play against the computer. Use clean buttons and show the winner.”
3. The preview appears on the right. Switch to **Code** view if you want to inspect or edit the HTML/JavaScript.
4. Follow up: “Change the theme to dark mode and add a restart button.”

You can select elements with **Select & ask** and describe the change. Preview updates live. Share a public link if you want others to try the prototype. Anyone with the link can view it; they can also copy it to their own Canvas to edit further.

This path is useful for quick demos, teaching concepts, or testing an idea before you write production code.

## Make custom study tools

Turn notes or a PDF into interactive material. Google lists quizzes, flashcards, and sandboxes.

1. Upload the source (notes, slides, or textbook chapter) or paste a summary.
2. Prompt: “Create a 10-question quiz on the attached material. Include explanations for wrong answers.”
3. The quiz opens in Canvas. Start it, request hints, or ask follow-up questions in the chat.
4. From the **Create** menu you can also generate flashcards or a study guide from the same document.

Google’s help page notes that quizzes and flashcards can be shared. Work or school accounts may restrict sharing. Under-18 users have limited Create options for certain formats.

For longer research that already lives in Notebooks, you can still generate the quiz from a written summary rather than raw files.

## Design office productivity boosters

Convert a spreadsheet or list into a lightweight tool. Google’s examples are sales trackers, pricing calculators, and task lists.

1. Upload a CSV or describe the data.
2. Prompt: “Build a simple pricing calculator. Inputs: quantity and unit price. Output: total, discount if quantity > 10, and a running list of line items.”
3. Test the inputs in the preview. Ask for a dark mode toggle or an export button if needed.
4. Export the result or copy the code if you want to host it elsewhere.

The same **Create** menu can turn an existing Canvas document into a web page or infographic. These stay single-file HTML prototypes rather than full multi-user applications.

## Refine writing side-by-side

Highlight text on the Canvas and ask for tone, length, or structure changes. Google’s post mentions adjusting a proposal or rephrasing sections.

1. Start with “Write a 500-word project proposal for a weekend bakery sale. Include budget and timeline.”
2. The draft appears in Canvas. Select a paragraph.
3. Choose **Suggest edits** or type “Make this more concise and professional.”
4. Use the length and tone controls for the whole document if available.

You can also add LaTeX formulas or switch formatting. When the draft is ready, export to Google Docs from the **Share & export** menu.

This is faster than copying text back and forth between chat and a separate editor.

## Practical tips

Start with a clear format request. “Create a quiz about…” or “Build a calculator that…” reduces extra back-and-forth.

Make one change at a time. Asking for theme, new features, and copy edits in a single prompt often resets parts you already liked.

Check facts yourself. Canvas drafts from your prompt and uploaded files. It does not replace verification for numbers, dates, or external claims.

Export when you need collaboration or a brand template. Canvas is excellent for the first version. Google Docs, Slides, or your own codebase are better for long-term editing.

If you already have a finished outline in Google Docs, you can still bring it into Canvas for the interactive formats. Our earlier guide on [turning notes into slides with Gemini Canvas](/blog/gemini-canvas-create-slides/) covers the slide-specific export path in more detail.

## Current limits

Canvas creates single-page prototypes and documents, not multi-file production apps. Shared public links are viewable by anyone who has them; review app data before you share.

Some Create options (certain quizzes, audio overviews) are restricted for users under 18. Availability can vary by account type and region. If Canvas does not appear, refresh the page and confirm you are signed into the correct Google Account.

Python code can be exported to Colab. Other languages stay inside the Canvas code view or can be copied out.

## Conclusion

Gemini Canvas turns a chat into a workspace for apps, study materials, simple calculators, and writing. The 23 November 2026 blog post highlighted four uses that match everyday needs. Open gemini.google.com, select Canvas, and try one of the prompts above with your own material.

The first version is usually close enough to refine with one or two follow-ups. Export or share only after you have checked the result.
