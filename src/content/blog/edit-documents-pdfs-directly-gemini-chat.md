Google has rolled out the ability to generate, preview, and edit files directly inside Gemini chats. You no longer need to download a document, open another app, and upload a revised version. Everything happens in one place.

This update covers PDFs, Google Docs, Google Sheets, slide decks, Markdown files, TXT files, and code. PDF editing works on both web and mobile. Other formats currently work on the web version only. The feature is available to all Gemini users in supported languages.

## What Changed in Gemini File Handling

Previously, Gemini could create files for you and let you download or save them to Drive. Editing required leaving the conversation. Now the generated file opens inside the chat. You can expand it to full screen, type changes yourself, highlight sections, and ask Gemini to refine specific parts.

This removes the context-switching that slows down work. Students can turn handwritten notes into a study guide and tweak it immediately. Professionals can build a tracker in Sheets and adjust formulas without switching tabs. Developers can review generated code snippets and correct them in place.

## Supported File Types and Platforms

Here is the current availability:

- **PDF**: Preview and edit on both web and mobile Gemini app.
- **Google Docs**: Web only.
- **Google Sheets**: Web only.
- **Slide decks**: Web only.
- **Markdown and TXT files**: Web only.
- **Code files**: Web only.

You can upload the finished file to Google Drive from within the editor. For native Google formats, you can also open them directly in the corresponding Workspace app.

## How to Generate and Edit a File in Gemini

Follow these steps on the Gemini web app (gemini.google.com). Mobile steps are similar for PDFs.

1. Open a new chat or continue an existing one.
2. Describe the file you need. For example: "Create a PDF study guide from these lecture notes" and upload photos of handwritten notes. Or: "Build a Google Sheet tracker for project tasks with columns for owner, deadline, and status."
3. Wait for Gemini to generate the file. A preview appears in the chat.
4. Click the expand icon to open the file in full-screen mode.
5. Edit directly: type changes, fix typos, or adjust layout.
6. Highlight any section and type a follow-up prompt in the chat box, such as "Make this paragraph more concise" or "Turn this table into a graph."
7. Review the updated version. Use undo if needed.
8. Download the file, share it, or save it to Drive.

The process works for both new generations and refinements of existing content. Highlighting lets you target specific parts instead of regenerating the entire document.

## Practical Examples

**Study guide from notes**  
Upload photos of handwritten lecture notes. Ask Gemini to create a structured PDF study guide with headings, key points, and a summary. Expand the PDF, correct any misread text, and highlight a section to request a diagram.

**Project tracker**  
Prompt: "Create a Google Sheet with columns for Task, Owner, Due Date, Status, and Notes. Pre-fill five sample rows." Preview it in chat, expand to full screen, add conditional formatting via a prompt, then open it in Sheets for further work.

**Presentation outline**  
Request a slide deck outline for a team meeting. Preview the layout, highlight a slide, and ask Gemini to adjust the tone or add speaker notes. Export as PPTX or open in Google Slides.

**Code snippet**  
Ask for a Python script that processes CSV data. Expand the code file, fix a bug yourself or highlight a function and request an improvement, then download the final version.

These workflows keep you in one interface. You still control the final output.

## Tips for Better Results

- Be specific in the initial prompt. Include format preferences, length, tone, and required sections.
- Upload reference material when available. Photos of notes, existing documents, or data tables improve accuracy.
- Use highlighting for targeted changes rather than vague full-file requests.
- Check platform support. Start on web if you need Docs, Sheets, or slides.
- Review generated content carefully. AI can misinterpret handwriting or complex data.
- Save versions to Drive so you have a history outside the chat.

## Limitations to Know

Most non-PDF formats are web-only for now. Mobile users can generate and edit PDFs but must switch to a browser for other file types. Generation speed varies with file complexity. Complex Sheets or long slide decks may take longer to preview. Always verify factual accuracy and calculations before relying on the output.
