Google added native file editing to the Gemini app on October 29, 2026. You can now generate a PDF, Google Doc, spreadsheet, slide deck, Markdown file, or code snippet, preview it inside the chat, and refine it without switching apps. PDF preview and editing works on both web and mobile. Other formats currently work on the web version only.<grok type="render_inline_citation" citation_id="218" />

This update builds on the file generation feature launched in April 2026. Instead of downloading a file and opening it elsewhere, you stay in the conversation. Expand the preview to full screen, type changes yourself, highlight a section to ask a question, or tell Gemini to rewrite a specific part.

## What formats work and where

PDF preview and editing is available on the Gemini web app and the mobile apps. You can upload handwritten notes or an existing PDF, ask for a cleaned-up version, then edit the result on your phone.

Google Docs, Google Sheets, slide decks, Markdown files, plain text files, and code are supported for generation, preview, and editing on the web only. On mobile these formats can still be generated and downloaded, but the in-chat editor is limited to PDFs for now.<grok type="render_inline_citation" citation_id="221" />

The feature is available to all Gemini users in every language where the app is offered. No paid subscription is required.

## How to generate and edit a file

Open the Gemini app on the web at gemini.google.com or the mobile app. Sign in with your Google account.

Upload source material if you have any. You can drop in photos of handwritten lecture notes, an existing PDF, or a text document. Then type a clear request that names the output format. For example: “Create an in-depth study guide as a PDF from these lecture notes. Include key formulas and a summary table.”

Gemini generates the file and shows a preview inside the chat. Click the preview to open it. On the web you can expand it to full screen and type directly into the document, the same way you would in a basic editor.

Highlight any section of text or a visual element. Ask a question about it (“What does this formula mean?”) or request a change (“Turn this table into a graph” or “Rewrite this paragraph in simpler language”). Gemini updates the file in place instead of creating a brand-new version each time.<grok type="render_inline_citation" citation_id="218" />

When you are satisfied, download the file or save it to Google Drive. Google Docs and Sheets open directly in their native apps. Slide decks can be opened in Google Slides or downloaded as PPTX or PDF.

## Practical example: turning notes into a study guide

Upload a photo of handwritten notes or paste text. Prompt: “Turn these notes into a clean PDF study guide. Add a short introduction, organize the content into sections, and include a practice question at the end of each section.”

Review the preview. Expand it and fix any factual errors by typing them yourself. Highlight a dense paragraph and ask Gemini to break it into bullet points. Highlight a table and request a graph. Ask follow-up questions about specific concepts while the file remains open.

This workflow keeps the original source, the generated guide, and your edits in one conversation. You can continue refining over multiple turns without losing context.

## Tips for better results

Name the exact format in your prompt. “Create a PDF” or “Create a Google Doc” produces more consistent output than a vague request.

For PDFs on mobile, keep the initial generation focused. Long or highly visual documents are easier to refine on the web, where the full editor is available.

Use highlighting for targeted edits. Broad requests such as “make the whole document better” can rewrite more than you intended. Specific instructions (“Shorten the second paragraph” or “Add a column for units to this table”) stay precise.

Save important versions to Drive as you go. The chat history retains the conversation, but Drive gives you a permanent copy outside the chat.

Combine this with other Gemini tools. If you use Gemini Notebook for source-grounded study, generate a PDF study guide from notebook content and then edit it in the main Gemini app. See our guide on [adding free textbooks to Gemini Notebook](/blog/add-free-textbooks-gemini-notebook/) for related workflows.

## Limits to keep in mind

Only files generated inside the current chat can be edited with the new tools. Uploaded files that were not created by Gemini follow the previous download-and-edit path.

Mobile support is currently limited to PDFs. For Docs, Sheets, slides, or code, switch to the web version.

Complex layouts, heavy graphics, or very long documents may still benefit from a final pass in the native Google app after you save to Drive.

The editor supports direct typing, highlighting, and prompted changes. It does not include every advanced formatting tool found in Google Docs or Sheets.

## Conclusion

Generating and editing files inside the Gemini chat removes an extra step from common workflows. Upload notes, request a PDF or Doc, review the preview, and refine it in place. PDFs work on both web and mobile; other formats are web-only for now. The feature is available to every Gemini user.

Start with a clear prompt that names the format, use highlighting for precise edits, and save finished versions to Drive. The update rolled out on October 29, 2026, and is live across supported languages.
