Google added direct file generation and editing inside the Gemini app on October 29, 2026. You can now create a PDF study guide from handwritten notes, expand it to full screen, highlight a section, and ask Gemini to rewrite it or turn a table into a graph—all without leaving the chat.

This works for PDFs on both web and mobile. Google Docs, Sheets, slide decks, Markdown, TXT, and code files are available on the web for now. The feature is open to all Gemini users in every language where the app is available.

If you already turn notes into study materials, see our [PDF study guide from handwritten notes](/blog/create-pdf-study-guide-gemini-handwritten-notes/) for related steps.

## What you can generate and edit

Gemini creates the file in the chat, then lets you preview and edit it in place. Expand the document to full screen to type changes yourself. Highlight text and ask a question or request an edit. Gemini can update text, visuals, or structure based on your prompt.

PDF preview and editing runs on web and mobile. Other formats stay web-only at launch. You can download the finished file or keep refining it in the same conversation.

The official demo shows turning lecture notes into a PDF study guide, then manually editing it and asking Gemini to adjust specific parts.

## Requirements and access

You need a Google account signed into the Gemini app or gemini.google.com. The feature is available to free and paid users. No special plan is required for basic generation and editing.

On mobile, PDF support is ready. For Docs, Sheets, and other formats, open Gemini in a desktop browser. Language support matches the Gemini app in your region.

Updates roll out progressively. If the expand or highlight options do not appear, refresh or check for the latest app version.

## Step-by-step: Create a PDF study guide

1. Open the Gemini app on your phone or go to gemini.google.com.
2. Upload a photo of handwritten notes or paste text. Ask: “Turn these notes into a clear PDF study guide with headings, key points, and a short summary.”
3. Gemini generates the PDF. Tap or click to preview it in the chat.
4. Expand to full screen if the option appears. Type small corrections directly.
5. Highlight a section. Type a request such as “Make this explanation shorter and add one example.”
6. Review the update. Download the PDF or ask for more changes.

You can repeat the highlight-and-ask step for visuals. Select a table and say “Show this as a graph instead.”

## Editing other file types on the web

On gemini.google.com the same flow works for Google Docs, Sheets, slide decks, Markdown, plain text, and code. Generate the file, expand it, and edit by typing or by prompting Gemini on highlighted content.

For a resume, ask Gemini to create a Google Doc from your bullet points. Expand, adjust formatting by hand, then highlight a job description and request a stronger action-verb rewrite. Download or open in Google Docs when finished.

Code files follow the same pattern. Generate a script, expand the editor, highlight a function, and ask for a bug fix or clearer comments.

## Tips for cleaner results

Give Gemini a clear structure in the first prompt. Specify headings, length, and tone. “Create a one-page PDF with three main sections and bullet points under each” produces better output than a vague request.

Upload clean images of notes. Good lighting and straight angles help Gemini read handwriting accurately.

Edit in layers. Fix big structure first with prompts, then make small wording changes yourself in full-screen mode.

Check facts before you rely on the file. Gemini can invent details. Cross-check names, numbers, and sources.

Save versions. Download intermediate copies so you can return to an earlier draft if a later edit goes off track.

## Limits to know

Only PDFs support full preview and editing on mobile right now. Other formats require the web version. Google has not published a timeline for mobile expansion of Docs and Sheets editing.

Large files or complex layouts may need several rounds of editing. Complex charts or multi-page presentations can lose formatting when converted.

The feature does not replace dedicated editors for final production work. Use it for drafts and quick revisions, then move the file to Google Docs, Sheets, or another tool if you need advanced formatting.

## Conclusion

Direct file generation and editing turns the Gemini chat into a practical workspace. You can turn notes into a PDF study guide, refine a resume, or adjust a spreadsheet without switching apps. PDF support works on phone and web today; other formats are web-only for the moment.

Try it with a small task first. Upload a short set of notes or ask for a simple document. Once the flow feels natural, use it for longer projects. Official details are on the Google blog post from October 29, 2026.
