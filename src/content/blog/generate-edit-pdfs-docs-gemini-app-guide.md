Google added direct file generation, preview, and editing inside the Gemini app on 29 October 2026. You can now create a PDF study guide, refine a document, or turn a table into a graph without leaving the chat.<grok type="render_inline_citation" citation_id="20" />

This works for all Gemini users in every language where the app is available. PDF editing runs on both web and mobile. Other formats stay web-only for now.<grok type="render_inline_citation" citation_id="10" />

## What the New File Tools Cover

Gemini can generate and refine several file types in one conversation:

- PDFs (preview + edit on web and mobile)
- Google Docs, Sheets, and slide decks
- Markdown, TXT, and code files
- Spreadsheets and presentations

You expand any generated file to full screen, type changes yourself, highlight sections, and ask Gemini to rewrite text or adjust visuals. Export or open the finished file in Drive or the matching Google app.<grok type="render_inline_citation" citation_id="24" />

## How to Generate a File in Gemini

Open the Gemini app or gemini.google.com. Describe what you need in plain language.

Example prompts that work well:

1. "Create a one-page PDF study guide from these lecture notes. Include key terms and three practice questions."
2. "Build a Google Sheet tracker for my monthly expenses with columns for date, category, amount, and notes."
3. "Draft a five-slide presentation outline for a team update on Q4 results."

Gemini returns a preview card in the chat. Tap or click it to expand. From there you can download, open in the native app, or keep editing.<grok type="render_inline_citation" citation_id="11" />

## Edit Files Without Leaving the Chat

Once the file appears:

- Expand to full-screen view.
- Type corrections directly into the document or PDF.
- Highlight a sentence, table, or image and ask Gemini a follow-up such as "make this more concise" or "show this as a graph instead."
- Use the undo button if a change goes too far.

On mobile, PDF edits are fully supported. For Docs, Sheets, or slides, switch to the web version if you need deep manual changes.<grok type="render_inline_citation" citation_id="19" />

## Practical Tips for Better Results

- Upload source material first (handwritten notes, screenshots, or existing files) so Gemini has real context.
- Be specific about format and length: "single-page PDF" or "three-column spreadsheet" reduces rework.
- Highlight only the section you want changed. Broad prompts can rewrite the entire file.
- After generation, open the file in Google Docs or Sheets for final formatting and sharing.
- Paid Gemini plans can chain these steps into Tasks for repeated workflows.

## Limitations to Know

PDF preview and editing work on mobile and web. Docs, Sheets, slide decks, Markdown, TXT, and code are web-only at launch. PowerPoint export is not direct; create a Google Slides deck and download it as PPTX if needed.<grok type="render_inline_citation" citation_id="16" />

Complex layouts or heavy formatting may still need a final pass in the native app. Gemini follows your prompt closely, so clear instructions produce cleaner first drafts.

## Why This Changes Daily Work

Previously you generated text in Gemini, copied it, and reformatted it elsewhere. Now the full cycle—draft, preview, edit, export—stays inside one chat. Students can turn notes into study PDFs. Teams can spin up trackers or slide outlines and refine them on the spot. The feature is available to every Gemini user, not just paid plans.<grok type="render_inline_citation" citation_id="17" />

Start with a small task today: upload a short document and ask for a summary PDF. Expand the result, highlight a paragraph, and request a tighter version. You will see the full workflow in under a minute.
