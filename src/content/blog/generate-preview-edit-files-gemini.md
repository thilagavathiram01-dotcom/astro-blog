Google added the ability to generate, preview, and edit files directly inside Gemini chats on October 29, 2026. You can create a PDF, Google Doc, spreadsheet, slide deck, Markdown file, text file, or code snippet, then refine it without leaving the conversation. PDF editing works on both web and mobile. Other formats currently work on the web version only.<grok type="render_inline_citation" citation_id="296" />

This update builds on earlier file generation. Previously you could ask Gemini to create a file and download it. Now the preview opens inside the chat so you can type changes yourself, highlight sections for targeted edits, or ask Gemini to revise the content.

## What you can create and edit

Gemini supports several formats. You request the file type in your prompt and the app opens a preview. From the preview you can expand to full screen for manual typing, select text to ask a question about that section, or instruct Gemini to change wording, structure, or visuals.

Supported formats:

- PDF: preview and edit on web and mobile. Export or save to Drive.
- Google Docs: preview and edit on web. Open in Docs or save to Drive.
- Google Sheets: preview and edit on web. Open in Sheets.
- Slide decks: preview and edit on web. Open in Google Slides or download as PPTX or PDF.
- Markdown, TXT, and code: preview and edit on web. Save to Drive.

The feature is available to all Gemini users in every language where the app is offered. No paid plan is required.<grok type="render_inline_citation" citation_id="291" />

## Step-by-step: create and edit a file

Open the Gemini app on the web at gemini.google.com or the mobile app if you need a PDF. Sign in with your Google account.

Start a new chat or continue an existing one. Upload source material if you have any, such as photos of handwritten notes or an existing document. Then ask for the file and specify the format. Example prompts:

- “Create a PDF study guide from these lecture notes.”
- “Generate a Google Doc outline for a project proposal on renewable energy.”
- “Build a spreadsheet tracker for monthly expenses.”
- “Make a short slide deck summarizing this report.”

Gemini generates the file and shows a preview inside the chat. Open the preview. Expand it to full screen if you want to type edits directly. Click into the text and make changes as you would in a normal editor.

To have Gemini revise a section, highlight the text and type an instruction such as “make this shorter” or “turn this table into a graph.” You can also ask follow-up questions about the content without highlighting.

When the file looks correct, use the export or save options in the preview. PDFs can be downloaded or uploaded to Drive. Docs, Sheets, and slides open in their native apps. Code and Markdown save to Drive.

The same flow works for refining an existing generated file later in the conversation. Re-open the preview and continue editing.

## Practical examples

Students can upload photos of handwritten notes and ask for a PDF study guide. Once generated, expand the preview, correct any misread formulas, and highlight sections to request clearer explanations. The result stays in one chat.

Professionals can request a slide outline, review it in the preview, highlight bullet points for tighter wording, then open the deck in Google Slides for final design. Spreadsheet users can generate a tracker, adjust column labels manually, and ask Gemini to add calculated fields.

Developers can ask for a code snippet or Markdown README, expand the preview to edit comments, and save the file to Drive for later use in a project.

## Tips for better results

Be specific in the initial prompt. Name the format and any constraints such as length, tone, or required sections. Upload clear source material when possible. Handwritten notes work best when the photo is well lit and the text is legible.

Use highlighting for targeted changes rather than asking Gemini to regenerate the entire file. This keeps your manual edits intact.

Check the preview carefully before exporting. Gemini grounds the content in your prompt and any uploaded sources, but you should verify facts, numbers, and citations.

For study workflows, combine this with Gemini Notebook. Add free textbooks as sources, then ask for a study guide that you can further edit inside a chat. See our guide on [adding free textbooks to Gemini Notebook](/blog/add-free-textbooks-gemini-notebook/) for the catalog steps.

If the preview does not appear, refresh the page or start a new chat. Ensure you are on the latest version of the Gemini app. PDF editing is the only option on mobile; other formats require the web version.

## Limits to keep in mind

Only PDFs support full preview and editing on mobile. Docs, Sheets, slide decks, Markdown, text, and code are web-only for now. Google may expand mobile support later.

Large or complex files may take longer to generate. If the preview fails to load, try a simpler prompt or break the request into smaller parts.

Exported files follow standard Google Drive or download permissions. You remain responsible for reviewing content before sharing.

## Conclusion

Generating and editing files inside Gemini removes the extra step of downloading and reopening a document. You create the file, refine it in the same chat, and export when ready. Start with a clear prompt that names the format, use the preview tools to make targeted changes, and export to Drive or the native app.

The feature rolled out October 29, 2026 and is available to all users. Try it on a study guide, report outline, or tracker the next time you need a document quickly.
