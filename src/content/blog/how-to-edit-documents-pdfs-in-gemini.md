Google added native file editing to the Gemini app on October 29, 2026. You can now generate a document, PDF, spreadsheet, slide deck, or code file, preview it inside the chat, and refine it without switching apps.

This changes everyday workflows. Upload notes, ask for a study guide, then tweak the result by hand or with a follow-up prompt. PDF editing works on both web and mobile. Other formats currently work on the web version only.

The feature is available to all users in every language where Gemini is offered. No paid plan is required for basic access.

## What you can edit and on which devices

Gemini supports these formats for in-chat preview and editing:

- PDFs on both web (gemini.google.com) and the mobile app
- Google Docs, Google Sheets, slide decks, Markdown files, TXT files, and code on the web only

You generate the file from a prompt or from uploaded source material. The preview opens in the conversation. From there you can expand it, type changes, highlight sections, or ask Gemini to revise specific parts.

## Generate a file from a prompt

Open gemini.google.com or the Gemini app and sign in. Write a clear prompt that specifies the format and content. Examples that work well:

- “Create a one-page PDF study guide from these handwritten lecture notes. Use one heading per topic and three bullet points under each.”
- “Generate a Google Sheets tracker for monthly expenses with columns for date, category, amount, and notes.”
- “Draft a short Google Doc meeting agenda with three discussion items and action-item space.”

Upload source files or photos if the request needs them. Gemini processes the material and returns a preview inside the chat. Review the structure, headings, numbers, and names first. Catching factual errors early saves time.

If the output misses a section, reply in the same chat with a specific correction instead of starting over.

## Three ways to edit the preview

Once the file appears, Google provides three editing paths:

1. Expand to full screen and type changes yourself. This works like a basic editor for text, tables, and simple layout adjustments.
2. Highlight a sentence, paragraph, table, or visual element, then ask a question or request a change. For example, select a table and type “show this as a graph instead.”
3. Describe the revision in the chat and let Gemini update the file. Useful for tone shifts, length changes, or structural moves.

PDF preview and editing follow the same pattern on mobile. Other formats require the web interface for full editing controls. After you finish, download the file or open it in the matching Google app where supported.

## Practical workflow example

Start with uploaded photos of handwritten notes. Prompt: “Turn these notes into a clean PDF study guide with a summary box at the top and key terms highlighted.”

Open the PDF preview. Expand it. Fix a typo by typing directly. Highlight a dense paragraph and ask “rewrite this in simpler language while keeping the original meaning.” Review the updated section. Ask one more question about a diagram. Export the finished PDF.

The same loop applies to a spreadsheet or slide outline. Keep each request focused. Broad prompts such as “make it better” often produce larger rewrites than needed.

## Tips for cleaner results

Specify the audience and purpose in the first prompt. “For a first-year student” or “for a client presentation” produces more relevant structure.

Check numbers, dates, and names before sharing. Gemini can invent plausible details when source material is incomplete.

Use highlight-and-ask for localized fixes. It preserves the rest of the document better than a full rewrite request.

On mobile, stick to PDFs for now. Switch to the web version when you need Docs, Sheets, or slides.

Export and open the file in its native app for final formatting polish, such as advanced table styles or slide transitions.

## Limitations to know

PDF editing is the only option fully available on mobile today. Google has not published a timeline for expanding other formats to the app.

The editor supports basic text and visual changes inside the preview. Complex layout work, tracked changes, or advanced formulas still work better in the original Google apps after export.

Always review AI-generated content for accuracy before you share or submit it.

## Conclusion

You can generate, preview, and edit documents, PDFs, spreadsheets, and more inside a Gemini chat starting October 29, 2026. The process stays in one conversation: prompt, review the preview, type or highlight to edit, then export.

Start with a small test file such as a checklist or short summary. Practice the three editing methods. Move larger projects once the flow feels natural.
