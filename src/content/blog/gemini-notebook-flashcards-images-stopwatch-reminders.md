Google added three practical upgrades to flashcards inside Gemini Notebook on November 24, 2026. Cards can now include relevant images taken straight from the files you uploaded. A stopwatch lets you time review sessions. And the mobile app can send reminders so you actually return to the deck.

These changes sit on top of the existing Studio flashcard tool. You still generate decks from your own sources. The new pieces simply make the resulting cards more visual, more exam-like, and easier to schedule.

The update is live for personal Google accounts, Workspace Individual subscribers, and all Google Workspace customers. No extra paid tier is required.

## What the three upgrades do

Flashcards already turned selected notebook sources into question-and-answer decks. You could choose card count, difficulty, and a custom prompt before generation. After the November update, three new behaviors appear during or after generation.

**Images from sources.** Gemini Notebook looks through the PDFs, slides, Docs, or image files already attached to the notebook and inserts matching pictures onto the cards. A biology deck can show the diagram that appeared in your lecture slides next to the term. An anatomy card can display the labeled heart figure instead of describing it in text alone.

**Built-in stopwatch.** While you review a deck you can turn on a timer that runs for the whole session. The clock tracks how long you take to work through the cards. You can use it to practice under time pressure or simply measure whether a second pass is faster than the first.

**Mobile study reminders.** Inside the Gemini Notebook mobile app you can schedule a notification that points back to a deck you already created. The reminder appears on your phone at the time you choose, so the deck does not stay buried in the notebook list.

All three are available without an admin switch. Workspace administrators can still turn Gemini Notebook on or off for the domain, but once the product is enabled these flashcard features appear for end users.

## How to generate a deck that includes images

Start with sources that already contain pictures or diagrams. A plain text PDF of bullet points will produce mostly text cards. A set of lecture slides with labeled figures gives the model something useful to pull.

1. Open [Gemini Notebook](https://notebook.google.com/) and open or create a notebook.
2. Add the files that hold the material you want to memorize. Include any slides, textbook pages, or images that should appear on the cards.
3. In the Studio panel on the right, choose Flashcards.
4. Adjust the number of cards, difficulty level, and optional steering prompt. A narrow prompt such as "focus on the labeled diagrams in the uploaded slides" helps the model prefer visual cards.
5. Generate the deck. Generation runs in the background.
6. Open the finished deck. Relevant images from your sources appear on the cards automatically.

You can still mark cards as known or missed. Progress is saved so the next session can emphasize the ones you got wrong.

If you already have a study notebook that mixes quizzes and overviews, the same sources feed the new image-aware flashcards. See the earlier guide on [Gemini Notebook study tools](/blog/gemini-notebook-study-tools/) for how those other Studio outputs fit together.

## Using the stopwatch for timed practice

Once a deck is open, look for the stopwatch control during review. Turn it on before you start flipping cards. The timer runs for the entire session and shows elapsed time.

Useful patterns:

- Set a personal target. Work through twenty cards and note the total time. On the next review aim to finish the same set faster while keeping accuracy.
- Simulate exam conditions. Some certifications and language tests expect answers within a fixed window. The stopwatch gives a simple way to practice that pressure without building a separate timer.
- Compare sessions. Record the time for a first pass, then review only the missed cards and time that shorter set. The numbers show whether focused review is efficient.

The stopwatch is optional. Leave it off if you prefer untimed free recall. It does not change scoring or force you to answer within a limit; it only measures the time you spend.

## Setting mobile reminders so the deck gets used

Reminders live in the Gemini Notebook mobile app, not the web interface.

1. Install or open the official Gemini Notebook app on Android or iOS.
2. Navigate to a notebook that already contains a generated flashcard deck.
3. Open the deck and look for the reminder or notification option.
4. Choose a time and day (or a repeating schedule if the control offers it).
5. Confirm. A push notification will arrive on the device at the scheduled time and open the relevant deck.

A simple weekly rhythm works for most topics: generate the deck on Sunday, review it once, then set a reminder for Wednesday and another for the following Sunday. The notification removes the need to remember which notebook holds which set of cards.

Reminders point at decks you already created. They do not generate new cards on their own.

## Practical tips for better decks

- Prefer sources with clear diagrams or labeled images when you want visual cards. The model pulls from what you uploaded; it does not invent new illustrations.
- Keep one subject per notebook. A mixed notebook produces mixed cards that are harder to review under a timer.
- Use a steering prompt to limit scope. "Only the formulas from chapter 4" or "only the safety symbols in the uploaded manual" keeps the deck focused.
- After a timed session, open the cited source for any card you missed. The image helps recognition, but the original file is still the authority.
- Export the deck to CSV if you want a backup or need to move the cards elsewhere. The export option remains available after generation.
- Pair the flashcards with the other Studio tools already in the notebook. A short video overview plus an image-aware deck covers both passive review and active recall.

Limits still apply. Daily generation caps, source count limits, and age or plan gates that existed before November continue to exist. The new features do not raise those ceilings. Check the current Gemini Notebook help page if you hit a restriction.

## Conclusion

The November 2026 flashcard updates make an already useful Studio tool more practical for real study and training sessions. Images from your own materials improve recognition. The stopwatch adds a simple way to practice speed. Mobile reminders turn one-time decks into a repeatable habit.

Open a notebook that already holds your slides or notes, generate a fresh deck, turn on the timer for one session, and set a reminder in the mobile app. The three features are available on personal accounts and Workspace accounts today.
