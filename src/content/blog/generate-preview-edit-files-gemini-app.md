Google added the ability to generate, preview, and edit documents, PDFs, presentations, spreadsheets, code, and other files right inside Gemini chats. You no longer need to download a file, open it elsewhere, and upload a revised version. The feature rolled out on October 29, 2026, to all users in every language where the Gemini app is available.

This guide shows exactly how to use the new tools on the web and mobile. It follows Google’s official announcement and Workspace updates.

## What the New File Tools Cover

You can ask Gemini to create a file from a prompt or from uploaded content. Once the file appears in the chat, you can:

- Expand it to full screen and type changes yourself.
- Highlight text or elements and ask Gemini a question about that section.
- Tell Gemini to refine the whole file or specific parts.

PDF preview and editing work on both the web version of Gemini and the mobile app. Google Docs, Google Sheets, slide decks, Markdown files, TXT files, and code are supported on the web only for now.

Google’s example starts with handwritten lecture notes. Upload photos of the notes, ask Gemini to turn them into a PDF study guide, then edit the result manually or by highlighting sections.

## Generate a File in Gemini

Open the Gemini app on the web or mobile. Start a new chat or continue an existing one.

Type a clear request. Examples that work well:

- “Create a one-page PDF summary of these meeting notes.”
- “Turn this table of data into a Google Sheet with a chart.”
- “Draft a Markdown file that outlines the project plan.”
- “Make a short slide deck from this outline.”

You can also upload files or photos first (tap the + button on mobile or the attach option on the web), then ask Gemini to transform them.

Gemini generates the file and shows a preview inside the chat. On the web you will see interactive previews for Docs, Sheets, slides, and code. On mobile the preview appears for PDFs.

## Preview and Expand the File

The preview sits in the conversation so you can check it before downloading. Tap or click the expand control to open the file in a full-screen view.

In full-screen mode you can scroll through the content, check formatting, and prepare for manual edits. The preview includes an export or download option so you can save the file to your device or to Google Drive once it looks correct.

If you are on mobile and the file is not a PDF, switch to the web version of Gemini at gemini.google.com for full editing support.

## Edit the File Yourself or With Gemini

Three editing paths are available:

1. **Manual edits in full screen.** Expand the file and type changes directly, the same way you would edit a normal document.
2. **Highlight and ask.** Select a sentence, paragraph, table, or visual. Then type a question or instruction such as “Rewrite this in simpler language” or “Turn this table into a graph.”
3. **Prompt Gemini to refine.** Stay in the chat and say “Shorten the introduction” or “Add a conclusion section that summarizes the key points.” Gemini updates the file in place.

Google notes that you can highlight specific sections for text or visual changes and still ask follow-up questions about the content.

## Step-by-Step: Turn Handwritten Notes into an Editable PDF

1. Open the Gemini app.
2. Tap the + button (mobile) or the attach icon (web) and upload photos of your handwritten notes.
3. Type: “Create a PDF study guide from these lecture notes. Organize the key points with headings and bullet lists.”
4. Wait for the preview to appear in the chat.
5. Expand the PDF to full screen and read through it.
6. Highlight any section that needs work and ask Gemini to rewrite it, or type your own corrections.
7. Export the finished PDF to Drive or download it.

The same flow works for other file types on the web. For example, ask for a Google Sheet of expense categories, then expand it and add a formula or chart yourself.

## Platform Differences and Limits

| File type          | Web Gemini | Mobile Gemini |
|--------------------|------------|---------------|
| PDF                | Yes        | Yes           |
| Google Docs        | Yes        | No            |
| Google Sheets      | Yes        | No            |
| Slide decks        | Yes        | No            |
| Markdown / TXT     | Yes        | No            |
| Code               | Yes        | No            |

The feature is available to all users, including free accounts, Workspace customers, and Workspace Individual subscribers. It is not limited to paid Gemini plans.

If you already use Gemini inside Google Docs or Sheets, the new chat-based tools complement those integrations. You can start a draft in the Gemini app and open the finished file in the full Workspace editor later.

For more on working with Gemini inside Google Docs, see our guide to [drafting and editing with Gemini in Google Docs](/blog/how-to-use-gemini-in-google-docs-to-draft-edit-and-collaborate/).

## Tips for Better Results

- Be specific in the first prompt. Include the desired format, length, and tone.
- Upload clean photos of handwritten notes for better text recognition.
- Use full-screen mode for precise manual edits rather than relying only on chat prompts.
- After Gemini revises a section, review the whole file—AI can occasionally introduce small inconsistencies.
- Export early and often if you plan to share the file outside Gemini.

## Conclusion

Generating and editing files inside Gemini removes several steps from everyday document work. You can create a PDF study guide from photos, refine a spreadsheet chart with a single instruction, or draft Markdown without leaving the chat. The tools are live for all users now, with broader format support on the web and solid PDF support on mobile.

Start with a simple prompt today and expand the preview to try manual edits. The workflow is straightforward once you have used it once.
