Google added computer use to the Gemini app for Mac on 19 November 2026. The feature lets Gemini click, type, navigate menus and fill forms across your local files, desktop apps and websites. It runs in an isolated background window with a live preview in your chat, so your main screen and cursor stay free.

This guide shows eligibility, setup, how to start a task, safety controls and practical tips. All details come from Google’s official announcement and help documentation.

## Who Can Use Computer Use

Computer use is rolling out in English in the United States. You need:

- An Apple Silicon Mac running macOS Sequoia 15.0 or later.
- A personal Google Account for users aged 18 or older.
- A Google AI Plus, Pro or Ultra subscription.

Free accounts, work or school accounts, Intel Macs and other platforms are not supported at launch. Google has not announced expansion dates for other countries or languages.

Download the Gemini app for Mac from gemini.google/mac if you do not already have it.

## How to Enable Computer Use

1. Open the Gemini app on your Mac and sign in with an eligible account.
2. Go to Gemini > Settings (or press Command + comma).
3. Select Computer use in the sidebar.
4. Turn on Allow Gemini to work with your Mac.
5. Grant macOS Accessibility and Screen & System Audio Recording permissions when prompted. Open System Settings > Privacy & Security if the prompts do not appear.

After enabling, you can manage allowed and blocked apps. Block sensitive apps such as password managers, banking apps and Messages right away. You can allow an app once later if a specific task needs it.

## Starting a Computer Use Task

1. Open a chat in the Gemini app.
2. Click Task below the input box (or switch to Task mode).
3. Type @Computer use followed by a clear description of the job.
4. Submit the prompt.
5. When Gemini requests access to an app for the first time, choose Deny, Allow once or Always allow.
6. Watch the live preview in the chat. Pause or stop the task at any time with the Stop task control.

Gemini works in its own background window. You can continue using your Mac for other work. It pauses for logins and payments and asks for approval before key actions.

Example prompt: “Take the butterfly sketch in Downloads and model and rig it in Blender. @Computer use”

## Practical Examples

Google lists several use cases:

- Extract weights, dimensions and addresses from local PDFs to fill multi-box shipping quotes.
- Pull metrics and screenshots from live dashboards and build a presentation in Google Slides.
- Batch color-grade photos in design software or set up complex 3D scenes.
- Analyze a folder of clothing photos, research pricing and stage resale listings.

Start with a small, low-stakes task. Review the live preview before approving any file changes or external actions. Gemini tries to back up files before modifying them; those backups last 24 hours or until the next prompt.

## Safety and Controls

You stay in control:

- Choose which apps Gemini can access via the allow/block list.
- Watch every step in the live preview inside the chat.
- Pause or stop the task with one click.
- Approve key actions before they happen.
- Gemini pauses for sign-ins and payments so you complete those steps yourself.

Google recommends using Gemini 4 Hydrogen or a newer model for better results. The feature runs inside a hardware-isolated virtual machine with protections against prompt injection. Do not enter passwords or payment details into the task thread.

## Tips for Better Results

Write specific prompts. Name the apps, files and expected output. For multi-step work, break the request into stages if the first attempt drifts.

Grant the narrowest app permissions needed. Allow Blender only when the task requires it, then revoke access afterward.

Monitor the first few runs closely. Once you trust the workflow, you can leave it running while you work on other tasks.

Check official Gemini Apps Help for the latest eligibility and permission details, because rollout status can change.

## Conclusion

Gemini computer use on Mac lets eligible US users hand off multi-step desktop chores while keeping their screen free. Enable it in Settings, start tasks with @Computer use, choose app permissions carefully and watch the live preview.

Confirm your subscription and Mac meet the requirements, then try a simple form-filling or file-organization task. Adjust permissions based on the result. As the feature expands, the same controls and safety steps apply.
