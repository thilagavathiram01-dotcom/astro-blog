OpenAI now ships ChatGPT as a Microsoft add-in that lives in a sidebar inside Word. You stay in the document. You ask it to draft from notes, rewrite a selected paragraph, or summarize what you already wrote.

The add-in is listed as generally available on every ChatGPT plan OpenAI names on the product page: Free, Go, Plus, Pro, Business, Enterprise, Edu, Teachers, and K–12. Word, Excel, and PowerPoint share one Marketplace listing. This guide covers Word only, using OpenAI’s help article and product page.

## What the add-in actually does

ChatGPT for Word is not a new Word feature from Microsoft. It is OpenAI’s add-in. After you sign in with a ChatGPT account, the sidebar can:

- Draft a memo, proposal, or report from notes and source text you provide
- Summarize the open document or write an executive summary
- Revise a section for a different audience
- Reorganize headings, numbering, and formatting
- Flag unclear language or inconsistent terms

Supported ChatGPT apps can pull extra context from Outlook, SharePoint, Google Workspace, and Dropbox, depending on your plan, workspace settings, and permissions. Plugins are not supported in the Word add-in.

Add-in chats do **not** share history with chatgpt.com. Memory and skills from the main ChatGPT app do not carry over. Treat the sidebar as its own workspace.

## Install it from Microsoft Marketplace

Use the official listing only: [ChatGPT on Microsoft Marketplace](https://marketplace.microsoft.com/en-us/product/office/WA200010215) (product ID WA200010215, publisher OpenAI).

1. Open that listing and choose **Get it now**.
2. Finish Microsoft’s install steps for your account (work, school, or personal Microsoft account).
3. Open Microsoft Word.
4. Open **ChatGPT** from the ribbon.
5. Sign in with your ChatGPT account. If you belong to a workspace, select that workspace.
6. Open a document and type a request in the sidebar.

You can also start from Word: **Home → Add-ins**, search for ChatGPT, and pick the listing published by OpenAI—not a third-party clone.

If the add-in never appears:

- A Microsoft 365 admin may have blocked third-party add-ins. They must allow this one.
- A ChatGPT workspace admin can turn ChatGPT for Word off in the ChatGPT admin console.
- OpenAI says the add-in will be **enabled by default starting October 1, 2026**. Until then, an admin may still need to flip it on.

## How to use it without wrecking the file

OpenAI’s own advice is conservative, and it matches how Word documents actually break.

**For a small edit.** Select the text first. Tell the sidebar what to change *and* what must stay. Example: keep defined terms, keep the numbers, shorten the rest.

**For a large rewrite.** Ask for an outline or a list of proposed edits before you let it rewrite the body. Review that list. Then apply the change in a second step.

**For a first draft.** Paste notes or source text into the prompt. The add-in can see the open document. It cannot browse other files on your disk. If the source lives in another .docx, paste the relevant paragraphs.

Save a copy before a large rewrite. ChatGPT can drop a sentence you meant to keep.

## Prompts that match official examples

These are adapted from OpenAI’s help article and Word product page. Swap in your document instead of inventing new ones.

- “Write an executive summary of this document. Include the recommendation and the main risks.”
- “Shorten this section for an executive audience. Keep the facts and defined terms.”
- “Turn these notes into a client memo with clear headings.”
- “Find inconsistent terminology in this draft and suggest corrections.”
- “Tighten this proposal for an executive audience. Lead with the recommendation and supporting evidence.”
- “Organize this operating plan into goals, owners, milestones, and open questions.”
- “Proofread this document for grammar, repetition, and inconsistent terminology.”
- “Explain this contract clause in plain language and list questions for legal review.”

Use the last one as a reading aid, not as legal advice.

## Skills, apps, and what stays outside Word

**Skills** in the add-in are reusable instruction packs for jobs you repeat: memo format, contract-review checklist, house style. They are not the same skills you saved in the main ChatGPT app. Recreate the ones you need inside the add-in if you rely on them.

**Connected apps** can ground a draft in mail or files you already have access to. Availability depends on plan and admin policy. If a source does not appear, check ChatGPT app connections and the Microsoft account used to install the add-in.

**Excel and PowerPoint** use the same add-in. You do not install three products. After one Marketplace install, open ChatGPT from the ribbon in each Office app.

## Limits you should plan around

OpenAI documents these constraints:

- Complex tables, charts, and layout often need a manual pass after the model edits text.
- Other local files are out of reach unless you paste text into the prompt.
- The model can invent or alter facts. Check figures, citations, names, and dates before you send the file.
- Usage is token-based at the API rates for the model in use. Word draws from the same usage pool as other premium ChatGPT features on plans that share that pool.
- Free and paid personal plans have usage limits. Expect throttling on long documents.

On Business, Enterprise, Edu, and Teachers workspaces, OpenAI says inputs and outputs are **not used to train models by default**. Personal plans follow the data controls on that plan. Read your workspace policy before you paste client material.

## A 15-minute first workflow

1. Duplicate a real document you can afford to mess up.
2. Install the Marketplace add-in and sign in.
3. Ask for an executive summary only. Read it. Do not apply a full rewrite yet.
4. Select one weak paragraph. Ask for a shorter version that keeps defined terms.
5. Accept or reject in Word the way you would accept tracked changes: by reading, not by trusting the sidebar.
6. If the formatting slipped, fix headings and lists yourself. Do not ask the model to “make it pretty” on a complex template.

That sequence teaches you what the add-in is good at (structure and tone) and what it is bad at (pixel-perfect layout).

## Conclusion

ChatGPT for Word is useful when the document is already open and you want a draft, a shorter section, or a consistency pass without bouncing to a browser. It is not a replacement for review, and it is not a second copy of your ChatGPT history.

Install the OpenAI listing, keep a backup of important files, and start with summaries and selected-text edits. Turn on default access on October 1 only if your admin is ready for it.
