Gemini Canvas turns a normal chat into a live workspace where you and the model edit documents, preview code, and generate interactive tools together. On November 23, 2026, Google shared four concrete ways people are already using it to save time on study materials, office work, and writing.<grok type="render_inline_citation" citation_id="139" />

You stay in one window. The chat remains on the left. The canvas opens on the right so you can type, highlight, or click through a preview while you keep talking to Gemini.

## What Gemini Canvas Actually Does

Canvas is available to every Gemini user, free or paid. Google AI Pro and Ultra subscribers get the larger context window and stronger models, but the core tools work on the free tier. You open it from the tools menu rather than relying on Gemini to guess when you need it.

Once active, you can generate a first draft, then edit the text or code directly. Quick tools let you change length or tone. You can also ask Gemini to revise only the highlighted section. For code and apps the canvas shows a live preview so you see the result before you export or share.

The November update emphasizes practical outputs: playable browser games, custom quizzes from your own notes, calculators built from spreadsheets, and side-by-side writing revisions.

## How to Open Canvas

1. Go to gemini.google.com and sign in with your Google account.
2. Click the + button (Upload and tools) under or beside the prompt box.
3. Choose More tools, then Canvas.
4. Type your request and send it. A Canvas chip appears in the prompt area and the workspace opens beside the chat.

On the mobile app the path is similar: tap the tools icon and select Canvas. Formatting and preview controls are fuller on the web version. You can also start from an existing chat by turning Canvas on before you send the next message.

## Four Ways to Use It Right Now

### Create Web Apps and Mini-Games

Describe the idea in plain language. Gemini generates the code and shows a live preview. Official examples include 3D visualizers and simple browser games. You can highlight a section of the code and ask for an explanation, or type a follow-up such as “make the background dark and add a score counter.” Changes appear in the preview immediately. Export or share the finished HTML when you are ready.

### Make Custom Study Tools

Upload notes or a PDF, then ask for a quiz, flashcards, or interactive sandbox. The canvas turns the material into something you can click through. A typical prompt is “Turn these lecture notes into a 10-question multiple-choice quiz with immediate feedback.” You can edit questions directly or ask Gemini to add fill-in-the-blank items. This keeps practice material tied to your own sources instead of generic web content.

### Design Office Productivity Boosters

Paste or upload spreadsheet data and request a sales tracker, pricing calculator, or task list. Canvas builds an interactive page you can adjust. Change column names, add filters, or ask it to calculate totals. The result stays editable so you can keep refining it in the same window.

### Refine Writing Side-by-Side

Generate or paste a draft. Highlight any paragraph and use the quick tools or a chat instruction to adjust tone, shorten a section, or restructure the flow. Gemini shows the revised text in place. You can accept, reject, or keep iterating without copying text back and forth between apps.

## Step-by-Step: Turn Notes into a Quiz

1. Open Canvas as described above.
2. Click the + button and upload your PDF or paste the notes into the chat.
3. Prompt: “Create an interactive quiz based on this material. Include 8 multiple-choice questions and 2 fill-in-the-blank items. Show the correct answer and a short explanation after each attempt.”
4. Review the preview. Click through a few questions.
5. Highlight any weak question and type “Make this harder and add a real-world example.”
6. When it looks right, use the export or share option from the canvas toolbar.

The same pattern works for flashcards or a simple practice sandbox. Start with a clear format request so the first output is closer to what you need.

## Tips for Better Results

Name the exact format in the prompt. “Create a pricing calculator web page” produces a more useful first version than “help me with prices.”

Upload source files when the content must stay accurate. Canvas works well with PDFs and spreadsheets.

Edit directly on the canvas for small changes and use the chat for larger revisions. This keeps the conversation focused.

Test the preview on different screen sizes if you plan to share the page. Simple HTML exports run in any modern browser.
