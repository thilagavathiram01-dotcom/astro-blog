You type the same long prompt every morning to summarize emails or format reports. Gemini Skills stop that loop. Google rolled them out in late September 2026 so you save instructions once and call them anytime.

Skills live inside normal chats. Type a slash, pick one, and Gemini follows your exact rules. They replace Gems for personal accounts and work across the mobile app, Mac app, and gemini.google.com.

## What Gemini Skills Are and Why They Matter

A skill is a named set of instructions plus an optional short description. Gemini checks the name and description first to decide if it applies. When it matches, it reads the full instructions and follows them.

You can trigger a skill manually by typing / and selecting it. Gemini can also apply active skills automatically when your prompt fits. You can stack several skills in one chat—for example a writing-style skill plus a brand-guidelines skill.

This beats pasting long prompts or switching to a separate Gem chat. It also matches the open SKILL.md format used by some coding agents, so the same file can travel between tools.

## Requirements and Current Availability

You need three things:

- A personal Google account (Workspace accounts come later)
- Age 18 or older
- Keep Activity turned on in Gemini settings

Skills rolled out globally starting around September 30, 2026, with a gradual rollout. Some accounts still wait. They work with any current model from Gemini 3.8 Flash upward. Reference files (text, PDF, images, code) are supported now; Google Drive and NotebookLM links arrive in the coming weeks.

Gems stay usable until Google migrates them. Personal Gems convert to skills around November 17, 2026. Workspace timelines run into 2027.

## How to Create a Gemini Skill

You have four practical ways. All lead to the same Skills page under Menu > Settings > Skills.

### Create with Gemini in Chat

1. Open any chat in the Gemini app or on gemini.google.com.
2. Type: Create a skill based on these instructions: then describe the task in detail.
3. Submit. Gemini builds the skill and saves it.
4. Edit by describing changes in the same chat.

Example: “Create a skill that turns my rough meeting notes into a clean summary with decisions, action items, owners, and deadlines.”

### Create Manually

1. Go to Settings > Skills > Create Manually.
2. Enter a short name using hyphens only (no spaces): meeting-recap.
3. Write a one-to-two-sentence description that starts with “Use when…” and lists specific triggers.
4. Paste detailed instructions.
5. Save.

A strong description matters more than perfect instructions. Gemini only reads the name and description to decide relevance.

### Upload a SKILL.md File

Prepare a Markdown file with frontmatter or clear sections for name, description, and instructions. Upload it from the Skills page. This method works well if you already use similar files in coding agents. You can also drop in supporting reference files in the same folder.

### Recommended or Prefilled Templates

The Skills page shows suggested skills. Start from one and edit the instructions to match your workflow.

After creation, toggle the skill active if you want automatic use.

## Using Skills in Everyday Chats

Type / in the prompt box. A menu of your skills appears. Select one, add any extra context or files, and send.

Gemini can also pick skills on its own when the prompt matches an active skill’s description. You stay in control—deactivate any skill you do not want applied automatically.

Stack skills by calling more than one in the same prompt or by letting Gemini combine them. A writing-style skill plus a format skill produces consistent output without extra steps.

You cannot activate, deactivate, or delete skills from inside a chat. Use the Skills page for management.

## Tips for Writing Effective Skills

- Start the skill name with an action verb or clear outcome: draft-email, summarize-report.
- Make the description specific. “Use when I ask for a weekly status update or project recap” works better than “helps with work.”
- Write instructions in the third person and list exact output format, tone, length, and sections.
- Include examples of good and bad results if the task is nuanced.
- Test immediately after saving. Run the skill on real input and refine the description if Gemini misses it.
- Keep instructions focused on one main task. Split complex workflows into stacked skills.
- Reference other skills inside instructions when you need multi-step processes.

Google’s own guidance stresses that name and description decide whether the skill runs at all. Spend time there.

## Moving from Gems to Skills

Gems still work for now. Google will migrate them automatically when it removes Gems support. Personal accounts see the change in mid-November 2026. You keep the same instructions; they simply become skills you can call with / inside any chat.

Until then you can create new skills alongside existing Gems. Once migration finishes, skills become the single way to store reusable instructions.

If you use coding agents or Android development tools, the same SKILL.md format appears in other Google products. Our guide on [Android skills for AI agents](/blog/android-skills-ai-agents/) covers how developers package similar instructions for on-device and CLI workflows.

## Practical Examples You Can Build Today

- Meeting recap: turns notes into decisions, owners, and next steps.
- Email drafter: matches your tone and includes a clear subject line and call to action.
- Weekly status: extracts completed work, blockers, and priorities from raw updates.
- Content repurposer: turns one blog post into LinkedIn, X, and email versions.
- Research summarizer: extracts key claims, sources, and open questions from a PDF or long text.

Start with one high-frequency task. Measure the time saved after a week. Then add the next skill.

## Conclusion

Gemini Skills turn repeated prompting into a one-time setup. Create them in chat, by hand, or by uploading a file. Call them with a slash or let Gemini apply them when relevant. The feature is live for personal accounts right now and will fully replace Gems later this year.

Open gemini.google.com, turn on Keep Activity if needed, and build your first skill. The time you save on the next ten similar tasks will cover the setup.
