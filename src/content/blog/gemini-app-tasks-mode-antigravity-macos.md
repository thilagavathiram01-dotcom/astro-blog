Google updated the Gemini app on October 13, 2026 with Gemini 4 Argon and a cleaner way to run background work. Pro and Ultra subscribers now see a Chat / Task toggle under the prompt box. On macOS the same update adds a one-click path into Antigravity for agentic coding.<grok type="render_inline_citation" citation_id="66" />

Tasks mode is the new name for Gemini Spark. It keeps working after you close the window or leave your desk. Antigravity brings the full agent coding interface inside the consumer Gemini app so you do not switch applications.<grok type="render_inline_citation" citation_id="67" />

This guide shows the exact steps on the latest macOS Gemini app.

## Confirm your subscription and app version

Gemini 4 Argon and the Task toggle require a Google AI Pro or Ultra plan. Antigravity itself still needs Ultra. Free and AI Plus accounts do not see these controls.<grok type="render_inline_citation" citation_id="64" />

Open the Gemini app on your Mac and check the model picker. You should see Gemini 4 Argon listed if your plan qualifies. Update the app through the App Store if the toggle or Antigravity pill is missing.

![Gemini app on a Mac laptop](https://images.unsplash.com/photo-1517694712202-14dd9538aa97?auto=format&fit=crop&w=800&q=80)

## Switch from Chat to Tasks mode

1. Open the Gemini app on macOS.
2. Look below the main prompt box. A Chat / Task switcher appears there.
3. Select Task. The interface changes to the task dashboard.
4. Type a clear objective. Example: “Every weekday at 8:00 summarize unread Gmail from the last 12 hours and list calendar conflicts for today.”
5. Confirm the schedule if prompted. Gemini stores the task and runs it even when the app is closed.

You can also start a one-off task from the chat window by describing the goal and choosing the Task option. Progress updates appear in the conversation so you stay informed without babysitting the agent.<grok type="render_inline_citation" citation_id="66" />

The Scheduled view in the navigation drawer shows both active Spark-style tasks and older scheduled actions in one list.

## Open Antigravity for coding

On macOS a Liquid Glass pill labeled Antigravity sits in the top-right corner of the Gemini window.

1. Click the Antigravity pill.
2. The full Antigravity agent interface opens inside the same window.
3. Describe the app, website, or code change you want. Argon handles longer multi-step coding better than earlier models.
4. Click the same pill again to exit back to the normal Gemini chat.

Antigravity runs the same experience as the dedicated desktop app. You can prototype, test, and iterate without leaving Gemini. Ultra is required for this path.<grok type="render_inline_citation" citation_id="67" />

![Developer coding on a laptop with AI assistance](https://images.unsplash.com/photo-1555066931-4365d14bab8c?auto=format&fit=crop&w=800&q=80)

## Use Skills and Connectors with @

Skills replace the old slash commands. Type @ followed by a skill name to invoke reusable workflows. Connectors (formerly Connected Apps) appear in the Customize section of the side panel. More than 40 services including Instacart, OpenTable, Adobe, and Shopify are available for task automation.<grok type="render_inline_citation" citation_id="66" />

For deeper skill building, see our guide on [creating reusable Gemini skills](/blog/create-gemini-skills-reusable-tasks/).

## Tips for better results

- Write tasks with a clear trigger, action, and done condition. Vague requests produce generic output.
- Set the thinking level to High when you switch to Argon for complex coding or research tasks.
- Check the Scheduled view daily at first so you can edit or pause tasks that run too often.
- Keep sensitive data out of shared tasks until you review the connector permissions.

## Conclusion

The Chat / Task toggle and the built-in Antigravity pill turn the Gemini macOS app into both a conversation partner and a background worker. Pro subscribers get Argon and task automation. Ultra subscribers add the full coding agent in the same window. Update the app, flip the toggle, and test a simple scheduled task today.
