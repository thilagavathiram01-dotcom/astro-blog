OpenAI updated the official ChatGPT Chrome extension on 15 October 2026. You can now tag Chrome so ChatGPT reads your open tabs for better answers. In Work mode it can fill forms, send messages, download files, and group tabs.

This guide shows the exact setup from OpenAI’s documentation and the public announcement. It covers installation, permissions, and practical use. For related Android AI tools, see our [Gemini 4 Argon Android setup guide](/blog/gemini-4-argon-agentic-android-setup/).

## What the update adds

Chat mode lets ChatGPT gather information across the tabs you already have open. Ask it to compare three product pages by price, delivery, and return policy without copying text. Work mode lets the agent act inside those tabs. It can complete multi-step tasks while you keep browsing.

The extension also adds a full sidebar with your conversation history. Right-click any page and choose Ask ChatGPT. On YouTube videos with captions it can answer questions from the transcript. The same extension works in Edge, Brave, Opera, and Vivaldi. Side chat is available in all of them except Opera.

## Set up the extension

Update the ChatGPT desktop app first. Open Settings and choose Computer Use. Expand More browsers if Chrome is not listed. Select Chrome and follow the prompt to install the required plugin.

Click Install. This opens the Chrome Web Store page for the official ChatGPT extension published by OpenAI. Confirm the publisher is OpenAI before you add it. Review the permission prompt and click Add extension.

Return to Computer Use in the desktop app. The browser should now show Manage. The toggle controls whether Chrome appears in the @-mention menu. Use the same Chrome profile where you installed the extension.

For side chat, open Chrome and click the ChatGPT icon in the toolbar or Extensions menu. On macOS you can also press Cmd + Shift + period. The sidebar opens with your full ChatGPT history.

## Use Chat mode for tab context

Open several tabs you want to compare. In the ChatGPT desktop app or web app start a normal chat. Type @Chrome or select Chrome from the @ menu. Then ask your question.

Example: “Compare the three sofa listings I have open by dimensions, material, delivery time, and return policy.” ChatGPT reads the open pages and answers without you pasting links. It asks permission before using content from a new website.

You can also highlight text on a page, right-click, and choose Ask ChatGPT. The sidebar opens with that selection already in context.

## Use Work mode for browser control

Start a ChatGPT Work or Codex chat. @-mention Chrome and give a clear task. Examples from OpenAI include filling a registration form and stopping before submit, or organizing open tabs into groups.

The agent works in the background. It does not take over your active browsing session. It always asks permission before referencing browser history or managing downloads and uploads. You can manage site permissions under Computer Use > Manage.

## Permissions and limits

The extension can request access to website data, browser history, downloads, and tab groups. OpenAI states it asks before interacting with each new website by default. You can limit or revoke access per site.

Work mode requires a paid plan. Tab reading in regular Chat is available more broadly. Availability can depend on rollout and workspace settings. The Chrome Web Store listing shows roughly 7 million users for the official extension.

Always install from the Chrome Web Store and confirm the publisher is OpenAI. Lookalike extensions exist.

## Practical tips

Keep tasks specific. “Fill the form open in @Chrome and stop before submitting” works better than a vague request. For file uploads from your computer, enable Allow access to file URLs in the extension details page.

Use a dedicated Chrome profile for testing if you worry about access to work accounts. Review the Manage page after setup so you know which sites are allowed.

The extension complements rather than replaces Google’s Gemini Auto Browse or other agents. Choose the tool that matches the sites and accounts you already use.
