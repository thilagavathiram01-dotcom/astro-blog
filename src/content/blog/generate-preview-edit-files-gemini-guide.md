Google added direct file generation and editing inside the Gemini app on October 29, 2026. You can now create a PDF study guide, a Google Doc, a spreadsheet, a slide deck, Markdown, plain text, or code, then refine it without leaving the chat.<grok type="render_inline_citation" citation_id="25" />

The update builds on the file generation feature launched in April 2026. Preview and editing now happen in-chat. PDF support works on both web and the mobile app. Other formats are available on the web version only.<grok type="render_inline_citation" citation_id="27" />

This guide shows the exact steps, platform differences, and practical tips based on Google’s official announcement.

## What you can create and edit

Gemini supports these formats for in-chat preview and editing:

- PDF (web and mobile)
- Google Docs (web)
- Google Sheets (web)
- Slide decks (web)
- Markdown files (web)
- TXT files (web)
- Code (web)

You generate the file from a prompt or from uploaded content such as handwritten notes. Once the preview appears, you expand it to full screen, type changes yourself, highlight sections, or ask Gemini to revise text or visuals.<grok type="render_inline_citation" citation_id="25" />

## Step-by-step: generate a file

1. Open the Gemini app at gemini.google.com or the mobile app and start a new chat.
2. Describe the file you need. Example prompt: “Create a one-page PDF study guide from these handwritten lecture notes” and upload the image or photo of the notes.
3. Gemini generates the content and shows an in-chat preview.
4. Review the preview. For PDFs you can do this on phone or desktop. For other formats, use the web app.
5. Tap or click the expand option to open full-screen editing if you want to type changes directly.

## How to edit inside the chat

Three editing methods are available once the preview is open:

- **Direct typing**: Expand to full screen and edit the text or layout yourself.
- **Highlight and ask**: Select a paragraph, table, or visual element, then ask Gemini a question or request a change (for example, “turn this table into a graph”).
- **Prompt refinement**: Tell Gemini in the chat to revise the whole file or a specific part. It updates the preview.

After edits, you can download the file or open it in the corresponding Google app (Docs, Sheets, or Slides) where supported. The feature is available to all Gemini users in every language where the app is offered.<grok type="render_inline_citation" citation_id="25" />

## Web versus mobile differences

| Format          | Web Gemini | Mobile Gemini app |
|-----------------|------------|-------------------|
| PDF             | Preview & edit | Preview & edit |
| Google Docs     | Preview & edit | Not available |
| Google Sheets   | Preview & edit | Not available |
| Slide decks     | Preview & edit | Not available |
| Markdown / TXT  | Preview & edit | Not available |
| Code            | Preview & edit | Not available |

Use the web version when you need Docs, Sheets, decks, or code. Stick to mobile for quick PDF work from photos of notes.<grok type="render_inline_citation" citation_id="28" />

## Practical tips for better results

- Be specific in the initial prompt. Include length, tone, structure, and output format.
- Upload clear images for handwritten content. Gemini handles context even when handwriting is imperfect, but legible input reduces errors.
- Highlight targeted sections instead of asking for wholesale rewrites when only one part needs change.
- Check citations or data tables after generation. Gemini can refine visuals on request, such as converting a table to a chart.
- Export early if you need advanced formatting that the in-chat editor does not cover.

If you already use Gemini inside Google Docs or Sheets, the new in-chat flow keeps the entire draft-and-refine loop in one place. For related Workspace workflows, see our guide on [using Gemini in Google Docs](/blog/how-to-use-gemini-in-google-docs-to-draft-edit-and-collaborate/).

## Limitations to know

Non-PDF formats require the web app. The feature does not replace full desktop editors for complex layouts, macros, or advanced design. Always review generated content for accuracy before sharing, especially for study materials or professional documents.

Google has not announced paid-plan restrictions; the capability is available to all users in supported regions and languages.<grok type="render_inline_citation" citation_id="25" />

## Conclusion

The October 29 update removes the need to copy text out of Gemini and paste it into another app just to fix small issues. Generate the file, preview it, edit directly or by prompt, and export. Start with a clear prompt and a PDF on any device, or open the web app for Docs, Sheets, and decks.

Official details are on the Google blog announcement and the Gemini help center. Test the flow with a small document first so you learn the expand and highlight controls before relying on it for longer work.
