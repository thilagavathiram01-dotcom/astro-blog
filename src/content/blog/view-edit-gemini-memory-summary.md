Google rolled out Memory summary in the Gemini app on 9 November 2026. The page shows what Gemini Apps understands about you, sorted into categories, and gives you tools to add, correct, or delete those details. Official Help pages confirm the feature, the requirements, and the exact steps.

This guide follows the Gemini Apps Help article “View & manage your memory summary in Gemini Apps.” It covers web and mobile paths, edit methods, Memory history, and the settings you must turn on first. If you also use Connected Apps, the same Personal Intelligence area controls both.

## What Memory summary shows

Memory summary lists facts Gemini has learned from your chats when the Memory setting is on. Reports and the Help page describe categories such as The Essentials (core background, location, and key relationships), Career & Professional Projects, Travel & Daily Gear, Media & Entertainment, and Fitness & Lifestyle. Each category contains short bullet points.

The page is not a raw chat log. It is a readable summary you can edit. Google states that the feature helps keep Gemini Apps responses accurate and relevant for you. You can also ask in any chat: “What do you know about me?” Gemini answers from the saved summary.

## Requirements before you can open it

Official requirements (Gemini Apps Help):

- Sign in with a personal Google Account (not a work or school account).
- Be 18 or older.
- Have Keep Activity turned on.
- Have Memory turned on.

For now the feature is available to US users with an active Google AI plan, in English, and only in the Gemini mobile app and the web app at gemini.google.com. Some testers reported seeing it on free accounts via the browser; the official page still lists the Google AI plan requirement. Rollout is gradual, so the menu item may not appear immediately.

Turn Memory on or off under Settings → Personal Intelligence. Keep Activity lives in the same area or at myactivity.google.com/product/gemini.

## How to view Memory summary on the web

1. Open gemini.google.com and sign in.
2. Click Settings at the bottom left.
3. Select Personal Intelligence, then Memory summary.

A direct path some reports noted is gemini.google.com/personalization-settings. Once open, you see the categorized list.

## How to view it in the Gemini mobile app

1. Open the Gemini app.
2. Tap the menu icon on the left.
3. Tap Settings at the bottom left, then Personal Intelligence, then Memory summary.

If the option is missing on the mobile app, open gemini.google.com in the phone browser and follow the web steps. Early reports noted the web version appeared first.

## Edit or delete details

You control the contents. Two methods exist.

**Natural language prompts** (text box at the bottom of the summary page):

- To add: “Add to my memory that I speak Japanese.”
- To remove: “Remove my old phone number from your memory.”

Gemini may ask a follow-up question if the request is ambiguous, then updates the summary.

**Pencil icon** (top-right corner): opens broader direct editing of the listed points.

After any change, the summary refreshes. You can also turn the entire Memory feature off under Personal Intelligence if you prefer Gemini not to learn from past chats.

## Check Memory history

Memory history shows a chronological record of additions and modifications.

1. Open Memory summary.
2. Tap or click the three-dot menu (or Memory history button) at the top right.
3. Review the list of changes.
4. Tap Done when finished.

This helps you see when a specific detail was added or altered.

## Tips for accurate and useful memory

- Correct errors quickly. If Gemini stored a wrong city or outdated job title, remove it and add the current fact.
- Keep only durable preferences. Temporary one-off details clutter the summary.
- Pair Memory with Connected Apps when you want Gemini to pull from Gmail or Drive. See our guide on [how to connect apps to Gemini](/blog/connect-apps-to-gemini/).
- Review the summary after long projects so outdated task notes do not persist.
- If responses feel off, ask “What do you know about me?” and then edit.

Turning Memory off does not delete existing chat history. Manage chats separately in Gemini Apps Activity.

## Privacy and control notes

Memory summary only works when you have opted into Memory and Keep Activity. Google’s Privacy Hub and the Memory Help page explain that you can turn the setting off at any time. The feature is limited to personal accounts of users 18+. Official documentation does not list Memory summary for Workspace or supervised accounts.

If the menu item never appears, check region (US), language (English), plan status, age, and the two activity toggles. Clearing the Gemini app cache or signing out and back in sometimes surfaces gradual rollouts.

## Conclusion

Memory summary gives a single place to see, fix, and prune what Gemini Apps has learned about you. Follow the official path under Settings → Personal Intelligence, use plain-language prompts or the pencil icon to edit, and check Memory history when you want the audit trail. Combined with Connected Apps, it makes Gemini more consistent across chats without forcing you to re-explain the same facts.
