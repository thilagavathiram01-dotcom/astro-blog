Google Labs launched Tabletop on November 11, 2026 as an experiment for real-time group collaboration. Groups drop links, files, and ideas into a shared space, then prompt @tabletop to generate interactive tools such as trip itineraries, dinner polls, expense splitters, and tournament brackets. Everyone edits the same space at once through an invite link, similar to a Google Doc.

This guide shows how to join the U.S. waitlist, set up a space, and use the AI agent for practical group planning. Tabletop remains limited to adults 18 and older in the United States, with access expanding weekly via labs.google/tabletop.

## What Tabletop Does Differently

Most group chats bury decisions in message threads. Tabletop turns the conversation into working tools that the group can vote on, edit, and update live. Roman Nurik, Design & Engineering Lead at Google Labs, noted that coordinating becomes easier when everyone builds and decides in one place.

You start with a space. Add existing links, files, or rough notes. Prompt the built-in @tabletop agent or select a starter template. The agent produces an interactive component rather than a static document. Share the invite link in your group chat so everyone joins the same view.

## Join the Waitlist

1. Open labs.google/tabletop in a browser.
2. Confirm you are 18 or older and located in the United States.
3. Enter your email and submit the form.
4. Check your inbox for the access email as Google rolls out spots each week.

Once approved, you receive a link to create spaces. The official announcement states no pricing details and no timeline for expansion beyond the U.S. waitlist.

## Create Your First Space

After access arrives, create a space for your group. Gather the materials you already have: flight links, restaurant suggestions, shared photos, or a simple list of options.

- Upload or paste links and files into the space.
- Add a short note describing the goal, such as “plan a weekend trip for five people.”
- Choose a starter template if one matches, or type a prompt that starts with @tabletop.

Example prompts that match Google’s listed capabilities:

- @tabletop create an interactive itinerary for our three-day trip with these flight and hotel links.
- @tabletop build a dinner poll so we can vote on restaurants.
- @tabletop make an expense splitter that tracks who paid for each item.
- @tabletop generate a tournament bracket for our recreational league.

The agent builds the tool inside the shared space. You can refine it by sending another prompt that adjusts rules, adds a field, or changes the layout. Google demonstrated this with a seating chart where badges become draggable after a follow-up request.

## Share and Collaborate Live

Copy the invite link once the tool is ready. Paste it into your existing group chat. Recipients open the link and join the same space immediately. Multiple people can edit, vote, or request changes at the same time.

The experience mirrors Google Docs: no one holds a private version, and updates appear for everyone. Members can ask @tabletop to modify the tool without starting over. In one official example, a simple Pong game became Pickle Pong with a bouncing pickle and live scoreboard after a prompt.

For developers or teams already using Gemini features, this fits alongside other Google AI experiments. See our guide on the [Android intelligence system and intelligent apps](/blog/android-intelligence-system-intelligent-apps-guide/) for related on-device and agent workflows.

## Practical Tips for Better Results

Provide concrete inputs. The agent performs better when you supply the actual links, dates, or constraints rather than a vague request. Start with a template when available, then customize.

Keep prompts focused. Ask for one tool at a time, then iterate. Review the output before sharing the invite so the group sees a usable first version.

Test with a small group first. Because access is limited, confirm that every participant can open the link and interact with the components. Google has not published detailed error handling, so expect to refine prompts if a tool does not match expectations.

## Limitations and Next Steps

Tabletop is an experiment, not a finished product. Availability stays restricted to the U.S. waitlist for users 18+. No public API or export options appear in the launch materials. Groups outside the United States must wait for any future expansion.

Monitor the Google Labs page and the official blog post for updates on access and features. If you receive access, start with a low-stakes plan such as a potluck or weekend outing to learn the workflow before using it for larger events.

Tabletop shows one direction for AI-assisted group work: turn shared notes into live, editable tools instead of more chat messages. Join the waitlist at labs.google/tabletop if you qualify, then test it with your next group decision.
