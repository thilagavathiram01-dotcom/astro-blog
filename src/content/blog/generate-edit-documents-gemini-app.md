Google just made the Gemini app far more useful for everyday work. On October 29, 2026, the company added the ability to generate, preview, and edit files right inside a chat. You no longer need to download a document, open another app, and then copy changes back.

This update covers PDFs, Google Docs, Google Sheets, slide decks, Markdown files, plain text, and code. PDF editing works on both the web and the mobile apps. All other formats are available on the web for now.

If you already use Gemini for research or drafting, this change removes a common friction point. Here is exactly how to use it.

## What the New File Editing Feature Does

Gemini has been able to generate downloadable files since earlier in 2026. The new layer adds in-place preview and editing. Once a file appears in the chat, you can:

- Expand it to full screen and type changes yourself.
- Highlight a section and ask Gemini a question about that exact text.
- Ask Gemini to refine the whole file or a specific part.

The feature is available to all Gemini users in every language the app supports. It works with personal Google accounts as well as Google Workspace accounts. No separate admin toggle is required for Workspace.

Google’s own example starts with handwritten lecture notes. You upload them, ask for a PDF study guide, then edit the result manually or by highlighting sections for Gemini to improve.

## How to Generate a File in Gemini

Open the Gemini app on the web at gemini.google.com or on your phone. Start a new chat or continue an existing one.

Type a clear request that names the file type. Examples that work well:

- “Turn these notes into a one-page PDF study guide with clear headings.”
- “Create a Google Doc project brief for a two-week marketing campaign.”
- “Build a Google Sheet tracker for weekly team tasks with columns for owner, status, and due date.”
- “Draft a short slide outline for a client update presentation.”

If you have source material, upload it first. Gemini can read images of handwritten notes, existing documents, or spreadsheets.

The file appears as a preview card in the chat once generation finishes. You can scroll through it without leaving the conversation.

## How to Preview and Edit the File

Tap or click the preview to open it. On the web you can expand most formats to full screen. On mobile the full-screen editor is currently limited to PDFs.

Three practical ways to revise:

1. **Manual edits.** Expand the file and type directly. This is fastest for fixing typos, adjusting a sentence, or changing a number in a table.
2. **Highlight and ask.** Select a paragraph, table, or bullet list, then type a follow-up such as “Make this section more concise” or “Turn this table into a simple bar chart.”
3. **Whole-file prompt.** Stay in the chat and say “Refine the tone to be more professional” or “Add a short summary at the top.”

After Gemini updates the file, the preview refreshes. You can continue iterating. When you are satisfied, download the file or open it in the corresponding Google app (Docs, Sheets, or Slides).

## Supported Formats and Platform Differences

| Format              | Web (gemini.google.com) | Mobile app |
|---------------------|-------------------------|------------|
| PDF                 | Yes                     | Yes        |
| Google Docs         | Yes                     | No         |
| Google Sheets       | Yes                     | No         |
| Slide decks         | Yes                     | No         |
| Markdown / TXT      | Yes                     | No         |
| Code files          | Yes                     | No         |

PDF support on phones is the most useful part for mobile users. You can generate a study guide or report, edit it on the go, and share it without switching apps. For longer documents, spreadsheets, or presentations, switch to the web version.

You can also upload the finished file to Google Drive from within the flow on the web.

## Tips for Better Results

Give Gemini specific structure in the first prompt. Instead of “make a report,” say “create a two-page PDF with an executive summary, three key findings, and a recommended next step.”

Upload source material whenever possible. Handwritten notes, screenshots of tables, or existing drafts produce more accurate output than a pure text prompt.

Use highlighting for targeted changes. Asking Gemini to rewrite only the selected section is more reliable than requesting a full regeneration.

Check numbers and names carefully. The editor makes it easy to correct facts after generation, so review before you share.

On the web, you can generate and edit multiple file types in the same chat. Start with a Doc, then ask for a matching Sheet of data, and finally request a short slide summary.

## Conclusion

The ability to generate, preview, and edit files inside Gemini removes an extra step that used to slow people down. Students can turn notes into study guides, freelancers can draft proposals, and teams can build simple trackers without leaving the chat.

PDF editing on mobile is immediately practical. Full document, spreadsheet, and slide support on the web covers most professional use cases. The feature is already live for all users.

Open Gemini, upload any source material you have, and ask for the file type you need. Then edit it in place until it is ready to share.
