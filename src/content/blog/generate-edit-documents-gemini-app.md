Google’s Gemini app now lets you generate, preview, and edit documents, PDFs, presentations, spreadsheets, and code without leaving the chat. The update rolled out on 29 October 2026 and is available to every user in every language the Gemini app supports.

You can expand a file to full screen and type changes yourself, highlight a section and ask Gemini a question, or tell Gemini to refine the text or visuals. PDF preview and editing works on both the web and the mobile app. Google Docs, Google Sheets, slide decks, Markdown files, TXT files, and code are available on the web only for now.

This turns Gemini into a practical workspace for students, freelancers, and anyone who needs a finished file quickly. If you already use Gemini for research or note-taking, the new tools fit the same conversation.

## What formats you can create and edit

Google lists these supported formats:

- **PDF** — preview and edit on web and mobile.
- **Google Docs** — web only.
- **Google Sheets** — web only.
- **Slide decks** — web only (you can later open them in Google Slides or download as PPTX or PDF).
- **Markdown files and TXT files** — web only.
- **Code** — web only.

You can upload source material such as handwritten notes, photos, or existing documents and ask Gemini to turn them into one of these formats. Once the file appears, it stays inside the chat so you can refine it before exporting or saving it to Google Drive.

## Step-by-step: generate and edit a file

1. Open the Gemini app. Use gemini.google.com on a computer for the widest range of formats. The mobile app works well for PDFs.

2. Write a clear prompt that names the format and the content. Examples:
   - “Create a one-page PDF study guide from these handwritten lecture notes. Use one heading per topic and three bullet points under each.”
   - “Build a Google Sheet tracker for weekly expenses with columns for date, category, amount, and notes.”
   - “Draft a short slide outline for a team update, then generate the slide deck.”

3. Wait for the preview to appear in the chat. Read it carefully before you edit. Check headings, numbers, and names first.

4. Edit in one of three ways:
   - Expand the file to full screen and type your own changes.
   - Highlight a section of text or a visual and ask Gemini a question or request a specific change (“make this shorter,” “turn this table into a graph”).
   - Tell Gemini to refine the whole file or a part of it.

5. When the file looks right, use the export option to download it or save it to Google Drive. From Drive you can continue working in Docs, Sheets, or Slides if needed.

## Practical examples

**Study guide from notes**  
Upload photos of handwritten lecture notes. Ask for a PDF study guide with clear headings and bullet points. Expand the preview, fix any OCR mistakes by hand, then highlight a section and ask Gemini to add a short practice question.

**Weekly expense tracker**  
Prompt for a Google Sheet. Preview the columns and sample rows. Highlight the amount column and ask Gemini to add a running total. Open the finished sheet in Google Sheets for further formulas.

**Slide deck**  
Ask for an outline first, then request the full deck. Preview the layout in chat. Highlight a slide title and tell Gemini to make the language more concise before you export.

These examples work best on the web version because most formats beyond PDF are web-only.

## Tips for better results

- Name the exact format in your prompt. Gemini creates one file per request, so ask for the deck and the handout separately.
- Review numbers, names, and citations before you share the file. The preview lets you catch errors without regenerating everything.
- Use full-screen mode for longer documents so you can see the overall structure while you type.
- Highlight only the section you want changed. Smaller selections usually produce more precise edits.
- For mobile, stick to PDFs until other formats gain mobile support.
- Save important files to Google Drive so you keep a copy outside the chat.

If you already keep reading lists or textbooks in Gemini Notebook, you can pull those notes into a new chat and turn them into an editable study guide. See our earlier guide on [adding free textbooks to Gemini Notebook](/blog/add-free-textbooks-gemini-notebook/) for the setup steps.

## Limits and what to expect

The feature is free and available to personal Google accounts as well as Workspace users. It does not require a paid Gemini plan. Editing quality depends on the clarity of your prompt and the quality of any uploaded source material. Handwritten notes work, but very messy handwriting may need manual cleanup.

Other formats remain web-only for the moment. Google has not published a timeline for mobile support beyond PDFs. You can still generate the file on the web and open the exported version on your phone.

## Conclusion

The October 2026 update removes the old cycle of generate, download, edit elsewhere, and re-upload. You can now create a PDF study guide, a spreadsheet tracker, or a slide deck and refine it inside the same Gemini conversation. Start on the web for the full set of formats, use clear prompts, and review the preview before you export.

These tools are live for all users in every language the Gemini app supports. Try a simple PDF from your own notes first, then expand to other formats as needed.
