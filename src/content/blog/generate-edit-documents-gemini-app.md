Google added a practical update to the Gemini app on 29 October 2026. You can now generate files, see a preview inside the chat, and edit them without switching apps.

This works for PDFs, Google Docs, Sheets, slide decks, Markdown, plain text, and code. PDF editing works on both web and mobile. Other formats currently work on the web version only. The feature is available to all users in languages supported by the Gemini app.

The change builds on the file generation capability Google introduced in April 2026. Previously you could create a file and download it. Now you refine it in place.

## What you can do with the in-chat editor

Once Gemini creates a file, a preview appears in the conversation. You have three ways to work with it:

- Expand the preview to full screen and type changes yourself.
- Highlight text or a section and ask Gemini a question about that part, or request a specific change.
- Ask Gemini to refine the whole file.

Google highlighted one example: upload handwritten lecture notes and ask for a PDF study guide. Then edit the result by hand, highlight a section for Gemini to adjust text or visuals, or ask follow-up questions.

You can export most files to Google Drive or download them. Slide decks can open in Google Slides or download as PPTX or PDF. Sheets open in Google Sheets.

## Step-by-step: generate and edit a file

1. Open the Gemini app at gemini.google.com on a computer, or the mobile app if you need a PDF.

2. Upload source material if you have any. This can be notes, a photo of handwritten pages, a report, or other files.

3. Write a clear prompt that names the format and the content. Examples:
   - "Create a one-page PDF study guide from these lecture notes with a heading for each topic and three key points under each."
   - "Draft a project brief as a Google Doc covering goals, timeline, and next steps."
   - "Build a simple expense tracker spreadsheet from this list of costs."

4. Review the preview that appears in the chat. Check structure, numbers, and names first.

5. Edit in one of the three ways described above. For precise changes, highlight the relevant section and describe what you want.

6. When the file looks right, download it or export to Drive. For Docs and Sheets you can continue editing in the native Google apps.

The process takes a few minutes once you know the flow. Start with a short test file before using it on important work.

## Supported formats and where they work

Google listed the following:

- PDF: preview and edit on web and mobile.
- Google Docs: preview and edit on web.
- Google Sheets: preview and edit on web.
- Slide decks: preview and edit on web.
- Markdown, TXT, and code: preview and edit on web.

PDF is the most flexible option if you move between devices. For everything else, start on the web version of Gemini.

These capabilities are available to all users. No paid plan is required for the basic feature, according to Google’s announcement.

## Tips for better results

Be specific in the first prompt. Name the audience, the length, the tone, and the exact format. Mention key sections you want included.

Upload source material whenever possible. Handwritten notes, existing drafts, or data tables give Gemini concrete information to work from instead of inventing details.

Use highlighting for targeted edits. Asking Gemini to change one paragraph or turn a table into a graph is more reliable than requesting a full rewrite.

Review carefully before exporting. Check facts, calculations, and names. The model can still make mistakes.

For long documents, break the work into stages. Generate an outline first, then expand sections one by one.

## Practical examples

Students can turn lecture notes into a structured PDF study guide, then highlight a section and ask Gemini to add a simple graph or shorten a paragraph.

Small business owners can generate a one-page project brief or a basic tracker spreadsheet, preview it, make quick manual fixes, and export to Drive.

Anyone writing a report can draft sections in Markdown or a Google Doc, expand the view, type corrections, and ask Gemini to adjust tone on selected passages.

Developers can generate code snippets or documentation and refine them in the chat before copying to an editor.

## Conclusion

The ability to generate, preview, and edit files inside Gemini removes a common friction point. You no longer need to copy content into another app just to fix a heading or adjust a table.

PDF editing on mobile makes the feature useful on the go. Web users get the full range of formats. Start with a clear prompt, review the preview, and use highlighting for precise changes.

Try it on a small task today and see how much time it saves compared with the old generate-and-download workflow.
