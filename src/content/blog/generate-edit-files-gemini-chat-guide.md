Google rolled out a practical update to the Gemini app on October 29, 2026. You can now generate, preview, and edit documents, PDFs, presentations, spreadsheets, code, and more without leaving the chat window.

This change builds on the file generation feature launched in April 2026. Previously, you could create a file but had to download it or open it elsewhere to make changes. Now the file stays in the conversation for review and edits.

The feature is available to all users in every language where the Gemini app works, including free personal Google accounts. No paid plan is required.

## What Formats Work and Where

Support differs by platform.

- **PDF**: Preview and edit on both web (gemini.google.com) and the mobile Gemini app (Android and iOS).
- **Google Docs, Google Sheets, slide decks, Markdown files, TXT files, and code**: Preview and edit on the web only.

On a phone you can create and refine PDFs in the chat. For everything else, switch to the web version for full editing.

Google’s announcement notes you can expand a file to full screen to type edits directly, highlight text to ask questions or request changes (including to visuals), or ask Gemini to refine the whole file.

## How to Generate a File in Gemini

Open the Gemini app on the web or mobile. Upload any source material if needed—photos of handwritten notes, existing documents, or data.

Write a clear prompt that specifies the format and content. Examples:

- “Create a one-page PDF study guide from these lecture notes with headings and bullet points.”
- “Build a Google Sheet tracker for project tasks with columns for owner, deadline, and status.”
- “Generate a short slide deck outline for a team meeting summary.”

Gemini produces the file and shows a preview inside the chat. An Export option appears so you can download or send it to Drive when ready.

## How to Edit the File Inside the Chat

Once the preview appears:

1. Expand the file to full screen. Click or tap into the text and type your changes the same way you would in a basic editor.
2. Highlight a section, table, or visual. Ask a question about it or request a specific change, such as “make this paragraph shorter” or “show this as a graph instead.”
3. Send a follow-up message in the chat asking Gemini to refine the file overall.

These three methods let you iterate without regenerating the entire document from scratch.

## Practical Tips for Better Results

Start with a detailed prompt. Name the file type, desired length or structure, and any style notes. Upload relevant source material when possible so Gemini has concrete input.

On mobile, stick to PDFs for now. The full-screen editor and highlight tools work, but other formats stay web-only.

After edits, use the Export button to save a local copy or open the result in Google Docs, Sheets, or Slides for further work. Google has not detailed automatic Drive saving for every edit, so export when the file looks correct.

Review the output carefully. Generated files can contain factual or formatting issues that need a human pass.

## Limitations to Know

- Mobile editing is limited to PDFs.
- The feature is rolling out to all users, but device or account region can affect availability.
- Complex formatting or large files may need export and finishing in native apps.
- Always verify numbers, dates, and claims before sharing generated documents.

## Conclusion

The October 29 update turns the Gemini chat into a lighter workspace for drafting and refining common file types. Generate a PDF on your phone, expand it, highlight a section for a rewrite, then export. On the web you can do the same for Docs, Sheets, slides, and code.

Try it with a small real task first—notes into a study guide or a simple tracker—to see how the preview and edit flow fits your routine.
