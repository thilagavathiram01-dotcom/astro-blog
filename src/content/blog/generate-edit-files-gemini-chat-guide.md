Google rolled out in-chat file generation and editing for the Gemini app on October 29, 2026. You can now create documents, PDFs, presentations, spreadsheets, and code, then refine them without leaving the conversation. This turns Gemini into a practical workspace for quick drafts and refinements.

The feature builds on earlier file generation that let you download results. Now the preview lives inside the chat. You expand it, type changes, highlight sections, or ask Gemini to revise specific parts. PDF support works on both web and mobile. Other formats stay web-only for the moment.

## What the New File Tools Cover

Gemini generates these formats from a prompt:

- PDFs
- Google Docs
- Google Sheets
- Slide decks
- Markdown files
- Plain text (TXT)
- Code files

PDF preview and editing work in the mobile Gemini app and on the web. Docs, Sheets, slides, Markdown, TXT, and code editing require the web version at gemini.google.com. The capabilities are available to all users in every language where the Gemini app runs. No paid plan is required for the basic feature.

You can upload source material first. Handwritten notes, reports, or images become the base for a generated file. Google showed an example of turning lecture notes into an editable PDF study guide.

## How to Generate a File in Gemini

Open the Gemini app on your phone or go to gemini.google.com in a browser. Start a new chat or continue an existing one.

Type a clear request that names the format. Examples that work well:

- "Create a PDF study guide from the notes I uploaded."
- "Make a Google Sheet that tracks monthly expenses with categories and totals."
- "Generate a slide deck outline for a 10-minute product update."

If you have source files, attach them before or with the prompt. Gemini processes the content and returns a file preview inside the chat window. The preview appears as a card or expandable panel. Wait for it to finish loading. Larger files can take a short time.

Once the preview shows, you have three ways to work with it:

1. Expand to full screen and type edits directly.
2. Highlight text or a visual element and ask a question or request a change.
3. Tell Gemini in the chat to refine the whole file or a section.

The full-screen editor lets you click into text and change it like a basic document tool. Highlighting works for both text and visuals. Ask "show this as a graph instead" on a table and Gemini updates that part.

## Editing on Mobile Versus Web

On Android or iPhone, stick to PDFs for in-chat editing. Open the Gemini app, generate or open a PDF, expand the preview, and make changes. You can highlight sections and prompt refinements. Export the finished PDF or save it to Drive from the preview controls.

For Docs, Sheets, slides, Markdown, TXT, or code, switch to a computer and use gemini.google.com. The web editor gives the full set of controls. After editing, open the file in the matching Google app (Docs, Sheets, or Slides) or download it as PPTX, PDF, or other formats.

If a button or option is missing on your phone, the feature may still be rolling out to your account, or the format is web-only. Update the Gemini app and try again later.

## Practical Tips for Better Results

Be specific in the first prompt. Include length, tone, structure, or key sections you want. "Create a one-page PDF summary of this meeting transcript with action items highlighted" produces cleaner output than a vague request.

Review the preview before exporting. Use the full-screen view to catch formatting issues. Highlight problem areas and ask for targeted fixes rather than regenerating the entire file.

Upload clean source material when possible. Clear photos of handwritten notes or well-structured documents give Gemini better input. For code, specify the language and any constraints.

After you finish, save to Drive or download. The chat keeps the conversation history so you can return and refine later. Pair this with Gemini Skills for repeated workflows. ## Common Use Cases

Students turn lecture notes into study guides and edit sections for clarity. Professionals draft meeting summaries or expense trackers and adjust numbers or categories in the preview. Presenters build slide outlines and refine content before exporting to Google Slides.

Developers can generate code snippets or Markdown documentation and edit them inline on the web. The highlight-to-refine flow keeps the context of the chat so follow-up questions stay relevant.

## Limitations to Know

Mobile editing is limited to PDFs. Complex formatting may need a final pass in the native app after export. Generation quality depends on the prompt and source material. Always review important documents before sharing.

Availability follows the Gemini app's supported regions and languages. If the option does not appear, confirm you are signed in with a personal Google account and that the app is updated.

## Conclusion

Generating and editing files inside Gemini chat removes the copy-paste step between conversation and document. Start with a clear prompt, use the preview tools, and export when the result matches your needs. PDF work stays fully mobile-friendly. For everything else, the web version unlocks the full editor.

Try it on your next draft. The combination of generation and targeted editing makes short tasks faster while keeping you in one place.
