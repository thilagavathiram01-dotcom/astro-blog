Passports, spare keys, and tax folders rarely get a Bluetooth tag. The September 2026 Android Drop fills that gap: you tell Gemini where you put something, and Find Hub stores the note in a Remembered tab.

This is not live tracking. The phone records what you said (and an optional photo). If you move the item and skip an update, the old location stays on file. Used that way, it is a spoken inventory for objects you will never tag.

Google announced the feature on 1 September 2026. Find Hub 3.1.732-02 later added the Remembered tab in the Play Store. The walkthrough below uses those official details plus the app flow that rolled out mid-month.

## What you need before you start

You need all of the following:

- A phone on **Android 16 or later**
- Gemini and Find Hub available in your country
- Gemini set as the default digital assistant
- Find Hub updated to **3.1.732-02** or newer from Google Play

This landed in the Android Drop, not only on Pixel. OEM skins can lag. If the tab is missing, update Find Hub, Gemini, and the Google app, then wait for the server-side flag.

For the rest of the September Drop (Motion Assist, Guided vision, Messages themes), see our [September 2026 Android Drop guide](/blog/android-september-2026-drop-guide/).

## How remembered items work

Find Hub already lists phones, earbuds, and tracker tags under Devices, plus shared people locations. Remembered sits beside those tabs. Google describes it as a place for items you do not put a tracker on.

Official examples include a passport and a spare key. Useful categories:

- Travel and legal papers: passport, birth certificate, vehicle title
- House backups: spare house key, spare car key, remote that is not on a ring
- Tools and supplies: screwdriver set, spare batteries, first-aid kit
- Temporary spots: a parking space, a picnic blanket in a park, a book you lent out

Do not use it as theft recovery. A tag or Pixel Tag still beats a typed drawer name if someone walks off with the bag.

## Save a location with Gemini (voice)

Voice is the fastest path when your hands are full.

1. Say “Hey Google” or hold the power button if Gemini is your assistant.
2. Name the object and the storage spot in one sentence.
3. Confirm the save if Gemini asks.
4. Optionally attach a photo when the prompt appears.

Google’s sample line:

> “Hey Google, remember in Find Hub that I put my passport in my bedroom drawer.”

Other lines that match the same pattern:

- “Remember that I put my spare house key in the kitchen junk drawer.”
- “Remember in Find Hub that the car title is in the fireproof box.”
- “Remember I parked in level B2, row 14.”

Say **Find Hub** in the sentence if a first try does not save. Then check the Remembered tab so you know the write landed.

## Save a location by hand in Find Hub

Use manual entry when you want a photo, notes, and a named place without talking.

1. Open **Find Hub**.
2. Tap the **Remembered** tab (bookmark icon with the Gemini spark).
3. Tap the add control. Choose **Manual entry** if you also see **Ask Gemini**.
4. Fill **Name** and **Storage spot**.
5. Add a photo, a place such as Home, and notes if you need them.
6. Save.

The floating action button can open Gemini instead. That is useful when you want the same record without typing the storage spot.

## Find the item later

You have two recall paths.

**Ask Gemini.** “Where did I put my passport?” or “Where is the spare house key?” Gemini should read the Find Hub entry, not invent a new guess.

**Open Find Hub.** The Remembered tab lists every stored object. Open an item to see the storage spot, photo, place label, and notes.

If Gemini answers from general chat memory instead of Find Hub, open the app and confirm the row exists. Re-save with “remember in Find Hub…” so the two stay in sync.

## Habits that keep the list honest

Treat every move as a write. After you take the passport out of the drawer, update or delete the row. An stale entry is worse than no entry.

Prefer specific spots over rooms. “Top dresser drawer, left side” beats “bedroom.” Add a photo of the closed drawer or the box label when several similar containers sit together.

Keep tagged hardware in Devices. Remembered is for unlabeled objects. Mixing a tagged backpack into Remembered only duplicates work.

Limit the list to items you actually lose. A 40-row catalog you never maintain will rot. Start with five high-cost misses: passport, spare keys, vehicle papers, glasses case, medication box.

Grant Find Hub location access only if you want a place label such as Home. The feature still works as a text inventory without a map pin.

## What this feature is not

It does not ping a passport. It does not see inside a drawer. Guided vision in Gemini Live is a separate camera tool from the same drop; it describes what the lens sees and is not a finder for saved rows.

Google gates Gemini and Find Hub by country. Android 16 is the floor Google published for remembered items. Motion Assist in the same drop needs Android 17 and is unrelated to this tab.

## Troubleshooting

**No Remembered tab.** Update Find Hub to 3.1.732-02 or later. Reboot. Confirm you are on Android 16+ and in a supported country.

**Voice save fails.** Set Gemini as the default assistant. Repeat the command with “in Find Hub.” Save once by hand so you can compare.

**Photo missing.** Voice saves can skip the image step. Open the item and attach the photo from the detail screen.

**Wrong answer from Gemini.** Open the row and edit the storage spot. Ask again using the exact item name you stored.

**Duplicate rows.** Delete the extra entry in Remembered. Keep one name per object so recall stays unique.

## Conclusion

Find Hub Remembered items is a short loop: say where you put the unlabeled object, store a photo if the spot is easy to mix up, ask again when you forget. It will not replace a tracker on a bag you carry outside. It will replace the scrap of paper on the fridge for documents and spare keys.

Update Find Hub, save one real item today, and confirm it appears in the Remembered tab. That single check tells you whether the Drop has reached your phone.
