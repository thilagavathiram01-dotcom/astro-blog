Google added file support and sharing to Gemini Skills on November 16, 2026. Skills are reusable custom instructions that guide Gemini on specific tasks. You can now attach files from your device, Google Drive, Gemini Notebook, and Google Photos when you create or update a skill. You can also share skills with others and set View or Edit permissions.

This update arrives as Gems move toward deprecation for personal accounts. Skills replace Gems for tailoring how Gemini handles repeated work. File references update in real time from Drive and Notebooks, so the skill always uses the latest version. The changes roll out over the coming weeks to all Google Workspace customers and personal Google accounts.

## What the New Skill Features Include

When you create or upload a skill, you can add reference files up to 100 MB total. Gemini references those files every time the skill runs in chats or tasks. Drive files and Notebooks stay current without re-uploading. Photos can supply visual context for skills that need it.

Sharing works from the Skills page in the Gemini web app. You grant View or Edit access. Recipients get an email and can review the skill before they add it. Once added, Gemini can apply the skill automatically when it fits, or the user can mention it with @ in a chat. Sharing is currently available only on the web version of the Gemini app, not yet in the mobile app.

If a skill references Drive files, you must also share access to those files separately. The feature is available to all users with personal Google accounts and Workspace customers.

## How to Create a Skill with Files

Open the Gemini app on the web at gemini.google.com. Sign in with your Google account.

### Step 1: Go to Skills

Look for Customize or the Skills section in the sidebar or menu. Select Skills, then choose Create or the option to make a new skill.

### Step 2: Define the Skill

Give the skill a clear name and description. Write the custom instructions that tell Gemini exactly how to handle the task. You can let Gemini help draft the instructions or write them yourself.

### Step 3: Add Reference Files

Select the option to add files. Choose files from your device, Google Drive, a Gemini Notebook, or Google Photos. Stay under the 100 MB limit for the skill. Confirm the files appear in the skill setup.

### Step 4: Save and Test

Save the skill. Start a new chat and mention the skill or ask a question that should trigger it. Check that Gemini uses the attached files correctly. Edit the skill later if the instructions or files need changes.

Files from Drive and Notebooks update automatically, so you do not need to re-add them after edits.

## How to Share a Gemini Skill

Sharing is available on the web version.

1. Open the Skills page in the Gemini app on the web.
2. Find the skill you want to share.
3. Open the menu for that skill and select Share.
4. Enter the email addresses of the people who should receive it.
5. Choose View or Edit permission for each person.
6. Send the share. Recipients receive an email and can review the skill before adding it to their account.

After they add it, they can use it in chats. Remind recipients to share any linked Drive files if the skill depends on them.

## Practical Tips for Skills with Files and Sharing

- Keep total file size under 100 MB. Large files may cause the skill to drop content during creation.
- Share Drive file access separately. The skill share alone does not grant file access.
- Test the skill in a fresh chat after adding files. Confirm Gemini pulls the right details from the documents.
- Use clear names so teammates can find shared skills quickly.
- Update the Gemini app or refresh the web page if the new options do not appear yet. Rollout continues over the next weeks.
- For teams, create one skill that references a shared brand guidelines document in Drive. Everyone sees the latest version without manual updates.

## Why File Support and Sharing Help

Reusable instructions save time on repeated tasks. Adding live files means the skill stays accurate without constant editing. Sharing lets teams standardize how Gemini handles brand voice, onboarding, or lesson planning. A marketing group can share a skill that always references the current brand guidelines. A teacher can share a curriculum skill built on a Notebook.

Google designed skills to replace Gems over time. Personal accounts see Gems become read-only starting November 17, 2026, with full removal by December 17. Workspace timelines differ. Moving important Gems to skills now, and adding the new file options, keeps your custom workflows intact.
