Google released five new tools in Flow on November 12, 2026. Visual artists and filmmakers designed each one. The tools help you keep characters consistent, apply retro styles, simulate impossible light effects, and turn phone footage into multi-angle shots.

You can try them today at flow.google.com. They run as shared tools inside a project. No paid plan is required for basic access, though video generations still use Flow credits on free and paid accounts.

## Open Google Flow and Locate the Tools

Sign in with a Google account at flow.google.com. Create a new project or open an existing one. Look for the Tools section on the left side of the interface. The five new tools appear as shared items you can open, duplicate, or remix.

Each tool has its own page with example assets. You work with them the same way you use other Flow tools: upload or generate reference images, write a prompt, and generate. Results land in your project so you can edit them further or combine them with Omni video clips.

## Character Poster by James Gerde

James Gerde built Character Poster for consistent visual style across social posts. It turns a simple story concept into a polished poster. The tool keeps a signature look so series of images feel like they belong together.

Start by describing the story or scene in plain language. Upload one or more reference images if you already have a character or style in mind. Generate the poster. Review the result, then ask for changes such as different lighting or composition. The tool is useful for social thumbnails, episode art, or campaign visuals that need to match.

## Character Arc by Anurag Tiwari

Character Arc shows the same character at different ages and life stages. It keeps the core look recognizable so you can develop backstory without redrawing the face from scratch. Anurag Tiwari uses it on his documentary “Children of the Sun” to trace a protagonist from childhood to adulthood while reflecting on events from 1974.

Upload a clear reference photo of the character. Specify the ages or stages you need, such as child, teen, adult, and older adult. The tool generates a visual timeline. You can then use those images as ingredients in later video generations for consistent characters across a longer story. This speeds up pre-production character development.

## Pixel Machine by Anurag Tiwari

Pixel Machine converts images into bitmap, ASCII, CRT, pixel art, and glitch styles. It gives filmmakers a playground for retro digital aesthetics. Use it for title treatments, transitions, music video visuals, or stylized stills that break from polished AI looks.

Upload any image or generate one first in Flow. Select the style you want. Adjust parameters if the tool offers them, then generate. The output works well as overlays, end cards, or reference frames for video. It pairs with other tools when you need a specific look that standard generation does not deliver.

## Lucid Glass by Ezra Paulekas

Ezra Paulekas designed Lucid Glass to recreate how light passes through glass. It generates prisms, halos, refractions, and optical blooms. The tool acts like an “impossible lens,” producing effects that real glass in front of a camera cannot capture.

Start with a clean image or video frame. Describe the light effect you want, such as a prism across the subject or a halo around a light source. Generate and review. You can layer the result or use it as a reference for further generations. Photographers and filmmakers use it for stylized shots that would otherwise require complex practical setups.

## Pocket Studio by Ryan McCoy

Ryan McCoy built Pocket Studio from more than two decades of previsualization and visual effects work. It turns everyday phone footage into polished multi-angle shots. From a single take, the tool generates several camera angles and upgrades visual fidelity while keeping the actor’s original performance intact.

Upload a phone video clip. Specify the angles or framing you need. The tool produces new views of the same performance. This helps creators who shoot on phones and want options that would normally require a multi-camera setup. Results can feed into longer edits or Omni generations for further refinement.

## Tips for Better Results

Upload clear, well-lit reference images. The tools rely on them for consistency, especially Character Poster and Character Arc. Keep prompts specific about style, lighting, and what must stay the same. Generate at lower resolution first if credits are limited, then upscale the best takes.

Combine tools in one project. Use Character Arc for age variants, then feed those into Character Poster or video generation. For phone footage, run Pocket Studio before applying Lucid Glass or Pixel Machine styles. Check the History panel so you can return to earlier versions.

Flow still applies SynthID watermarks to generated content so viewers can identify AI output. Free accounts receive daily credits; paid Google AI plans unlock longer clips and higher limits. Features can vary by region and account age.
