Gemini Canvas turns the chat into an interactive workspace where you create documents, code, slides, and working apps side by side with the conversation. Google highlighted four practical uses on November 23, 2026: building web apps and mini-games, making custom study tools, designing office productivity boosters, and refining writing in place.

You stay signed in to Gemini Apps. Canvas is available on free and paid plans, with higher context windows and usage on Google AI Pro and Ultra. Changes save automatically. You can edit the canvas directly or ask Gemini to revise specific parts.

## Open Canvas and Start a Project

Go to gemini.google.com and sign in. Below the prompt box, click the + button (Upload and tools). Choose More tools, then Canvas. Type what you want to create and send the prompt. The canvas opens beside the chat.

On mobile, tap Add then Canvas. You can also go directly to gemini.google.com/canvas. Describe the format clearly: a quiz from these notes, a pricing calculator, a slide deck, or a simple HTML app.

Upload files or images with the prompt if they should guide the output. Gemini generates a first draft in the panel. You then iterate in the chat or by editing the canvas itself.

## Build Interactive Apps and Mini-Games

Ask Canvas to create a single-file HTML app or game. Examples include a 3D visualizer, a playable browser game, or a ROI calculator with sliders. Gemini writes the code and shows a live preview.

Switch between Code and Preview views. Edit the code yourself or select a section and ask Gemini to change only that part. Use Show recent changes to review what Gemini updated. Export the HTML or share a link so others can copy the canvas.

For more complex prototypes, describe the user flow, inputs, and desired result in the prompt. Test the preview and refine until it works as expected.

## Create Custom Study Tools

Turn notes, PDFs, or a Deep Research report into interactive quizzes, flashcards, or sandboxes. Upload the source material, open Canvas, and request a quiz that tests key concepts or flashcards for spaced review.

Once the document or report is in Canvas, click Create at the top right. Options include Quiz, Infographic, Audio Overview, web page, or slide show. The quiz generates questions you can answer inside the canvas. Audio Overview produces a podcast-style discussion of the content.

These tools help students and professionals convert passive reading into active practice without leaving Gemini.

## Design Office Productivity Boosters

Convert spreadsheets or data into sales trackers, pricing calculators, and task lists. Paste the data or describe the spreadsheet structure. Ask for an interactive tracker with filters or a calculator that updates totals as you change inputs.

Refine the layout and formulas through chat. Export the result to Google Sheets if needed, or keep it as a Canvas app for quick internal use. These small tools reduce repeated manual calculations.

## Refine Writing Side by Side

Highlight text in the canvas and ask Gemini to adjust tone, rephrase a section, or restructure a proposal. Quick tools change length or formality. Type directly in the panel; edits save on their own.

Export finished documents to Google Docs. For presentations, request a slide deck from the outline, then export to Google Slides, PDF, or PPTX. This keeps the conversation and the artifact in one view so you see changes immediately.

## Tips for Better Results

Name the exact format and audience in the first prompt. Specify constraints such as number of slides, question difficulty, or mobile-friendly layout. Iterate in small steps rather than rewriting the whole canvas at once.

Prefer newer models such as Gemini 4 Neon or Carbon when available for more complex apps and longer documents. Keep the Gemini app updated. Clear or start a new canvas if the conversation grows too long.

Share links carefully. Recipients can copy the canvas and continue from your version. Review generated code and calculations before relying on them for production or client work.

## Conclusion

Gemini Canvas lets you move from chat to editable documents, working apps, quizzes, and slides without switching tools. Open it from the tools menu, describe the outcome, edit in the panel or through prompts, and export when finished.

The November 2026 examples from Google show practical gains for study, office work, and quick prototypes. Check the Gemini Apps Help pages for the latest controls and export options.
