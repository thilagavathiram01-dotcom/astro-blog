Gemini Canvas turns ordinary chats into interactive workspaces. You can turn class notes into quizzes, build flashcards, or prototype a small web app without leaving the Gemini app.

This guide shows exactly how to start, what prompts work best, and how to export or share what you create. All steps come from Google’s current Canvas features as of November 2026.

## Open Canvas in the Gemini App

Open gemini.google.com or the Gemini mobile app and start a new chat. Tap or click the Tools menu in the prompt bar. Select Canvas.

Canvas opens a side panel or full workspace next to your chat. Everything Gemini generates after you enable it lands in that editable space. You can switch between Code and Preview views for apps, or stay in a document editor for text and study materials.

If you do not see the Canvas option, update the Gemini app or refresh the web page. The feature is available on free and paid accounts in regions where Gemini is supported.

## Create Interactive Study Tools from Notes

Paste your notes or upload a PDF, then ask Canvas to transform them.

Try this prompt:

“Turn these lecture notes into an interactive quiz with 10 multiple-choice questions. Include explanations for wrong answers and a final score.”

Canvas generates the quiz in the side panel. You can click through questions, see immediate feedback, and edit any question by highlighting text and asking for changes.

For flashcards, use:

“Create a set of flashcards from these biology notes. Show the term on the front and the definition on the back. Make them shuffleable.”

The result appears as a clickable deck you can practice with right away. You can also request an Audio Overview that turns the material into a short spoken summary you can listen to while reviewing.

These study formats help you test yourself actively instead of just rereading. Pair them with Gemini Tasks if you want the assistant to schedule review sessions later. See our guide on [using free Gemini Tasks for everyday jobs](/blog/how-to-use-free-gemini-tasks-for-everyday-jobs/).

## Build Mini-Apps and Simple Web Tools

Canvas can generate working HTML, CSS, and JavaScript from a plain-language description. This is useful for quick calculators, timers, or practice games.

Example prompt:

“Build a simple flashcard practice app. Users should be able to add their own cards, flip them, and track how many they get right.”

Switch to Preview to test the app. If something does not work, highlight the problem area and say “Fix the flip animation so the card rotates smoothly.”

You can also start from a sketch. Take a photo of a hand-drawn wireframe, upload it, and ask Canvas to code the layout. Google demonstrated this workflow in late 2026 for turning paper ideas into prototypes.

Once the app looks right, you can export it. Options include downloading the code or publishing a draft to Google Sites so you can share a live link with classmates.

## Refine Writing and Documents Side-by-Side

Canvas is not only for code. Highlight any paragraph in a document you are drafting and ask for specific changes.

Useful requests include:

- Make this section more concise.
- Change the tone to formal.
- Add a real-world example here.

The edit appears in the Canvas panel so you can accept or reject it. This works well for essays, lab reports, or presentation outlines.

## Tips for Better Results

Give clear, specific prompts. Mention the number of questions, the difficulty level, or the exact format you want. Canvas follows detailed instructions better than vague ones.

Test everything in Preview mode before sharing. Generated apps are prototypes; check that buttons, scoring, and navigation work as expected.

Keep source notes short when possible. Very long PDFs may need to be split so Canvas focuses on one section at a time.

Use the Code view if you want to learn or tweak the underlying HTML. You do not need programming knowledge to start, but the option is there.

## Conclusion

Gemini Canvas gives you a practical way to turn notes into active study materials and simple interactive tools. Enable it from the Tools menu, paste or upload your content, and describe the quiz, flashcards, or app you need. Edit in place, preview the result, and share or export when ready.
