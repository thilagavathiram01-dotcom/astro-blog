ChatGPT no longer replies only with walls of text. With Intelligent UI, powered by GPT-6, answers can include charts, forms, buttons, maps, and small working tools you interact with right in the conversation.

OpenAI rolled this out on 7 October 2026 for Plus, Pro, Business, and Enterprise users in the Chat tab. Free and Go users received it the next day. No special command is required. ChatGPT chooses the format based on your question.

This guide shows exactly how to use it for practical interactive tools.

## What Intelligent UI Actually Does

GPT-6 composes responses from text, visuals, and interactive elements. A comparison can appear side by side. An explanation can become a tappable diagram. A planning task can include a calculator or timeline.

When plain text works best, it still uses text. The model decides. OpenAI built a library of native components so the interface appears progressively as the response streams in.

It works from Instant through Extra High reasoning levels. The Pro reasoning option (GPT-6 Astra) does not support it. It is available only in the Chat tab, not Work or Voice. Connected plugins such as Gmail or Finance continue to work.

## How to Start Using Intelligent UI

Open ChatGPT on the web or in a supported updated app. Make sure you are in the Chat tab and using GPT-6 (Instant to Extra High).

Ask a question that benefits from interaction. Examples include:

- “Create a bill splitter for a dinner with 4 people. Let me enter the total and tip percentage.”
- “Show a savings calculator. Let me change monthly contribution and interest rate.”
- “Compare these three project management tools side by side.”

ChatGPT generates the interface. You can interact with sliders, buttons, or forms. Follow-up prompts refine it: “Add a chart for the monthly growth” or “Make the buttons larger.”

State is retained for some components (like checklists) within the same chat thread when you refresh. It does not carry across different chats.

## Step-by-Step: Build a Practical Tool

1. Open a new chat in the Chat tab with GPT-6 selected.
2. Describe the tool and the inputs. Example: “Build an interactive compound interest calculator. Inputs: starting amount, monthly addition, annual rate, years. Show the final value and a simple chart.”
3. Review the first version. Adjust numbers with the controls.
4. Ask for changes: “Add a toggle for compounding frequency” or “Highlight the total interest in green.”
5. Test edge cases by changing inputs to extremes.
6. If needed, set preferences in Custom Instructions: “Prefer interactive calculators and tables for numerical questions.”

You can also request a specific style, such as “make it look like a clipboard” for a checklist.

## Tips for Better Results

- Name the tool and list the exact inputs and outputs you want.
- For comparisons, ask for side-by-side or a table with a recommendation row.
- Verify numbers yourself. Interactive elements calculate locally after the initial response, but the starting values come from the model.
- On the web, you can reduce visuals via Personalization → Layout and Visuals → Simple. Some elements may still appear.
- Update your mobile app. Older desktop apps do not support Intelligent UI; use the web instead.

For reusable workflows, see our guide on [ChatGPT skills for reusable tasks](/blog/chatgpt-skills-reusable-workflows/).

## Limitations and Availability

Intelligent UI has no separate usage quota. Your normal model and plan limits apply. Availability depends on your plan and any workspace admin settings for Business or Enterprise.

It does not work in Voice mode or the Work tab. Free and Go users are limited to Instant reasoning. Paid plans get higher levels with Sol.

## Conclusion

Intelligent UI turns ChatGPT into a place where you can explore ideas and build small tools without leaving the conversation. Start with one practical request today—a calculator, a comparison, or a timeline—and refine it with follow-ups. The interface appears as the answer streams, so you can start using it immediately.
