Google rolled out in-chat file generation and editing for the Gemini app on October 29, 2026. You can now create a document, PDF, spreadsheet, or slide deck, preview it inside the conversation, and refine it without switching apps. PDF preview and editing works on both web and mobile. All other formats stay limited to the web version for now.

This change removes a common friction point. Previously, Gemini could generate files, but editing required downloading them or opening them in another tool. The new workflow keeps everything in one chat.

## What You Can Create and Edit

Gemini supports several file types with in-chat preview and editing:

- PDFs on both web and mobile
- Google Docs, Google Sheets, and slide decks on the web
- Markdown files, TXT files, and code on the web

You can expand any generated file to full screen, type changes yourself, highlight sections to ask questions, or prompt Gemini to refine the content. Files can be uploaded to Google Drive or opened in the native Google apps.

## Step-by-Step: Generate a File

1. Open the Gemini app at gemini.google.com or on your phone and sign in with your Google account.
2. Describe the file you need. Be specific about the format and content. For example: "Create a PDF study guide from these handwritten notes" and upload the image, or "Build a spreadsheet to track monthly expenses with columns for date, category, and amount."
3. Send the prompt. Gemini generates the file and shows a preview in the chat.
4. Review the preview. If it looks good, continue to editing or export.

The process works the same for personal Google accounts and Workspace accounts. No separate admin toggle is required.

## How to Edit the File Inside the Chat

Once the preview appears, you have three ways to make changes:

- Expand to full screen and type edits directly.
- Highlight text or a visual element and ask Gemini a question or request a specific change.
- Ask Gemini to refine the whole file, such as adjusting tone, adding a chart, or restructuring sections.

Google's example shows turning handwritten lecture notes into a PDF study guide, then highlighting sections for further edits or asking Gemini to convert a table into a graph.

On mobile, stick to PDFs for full in-app editing. For Docs, Sheets, or slides, use the web version.

## Exporting and Saving Your Files

After editing, you can:

- Open the file directly in Google Docs, Sheets, or Slides.
- Download it as a PDF, PPTX, or other format.
- Upload it to Google Drive.

Generated files integrate with existing Workspace tools, so you can continue editing in the native apps if needed. The in-chat editor handles the initial refinement.

## Tips for Better Results

Provide clear instructions about structure and purpose. Mention the exact file type in your prompt. For complex documents, generate a draft first, then use highlighting for targeted changes rather than regenerating the entire file.

Test with simple requests first if you are on mobile. PDF support is solid, but other formats require a desktop browser. If the preview loads slowly, wait a moment or refresh the chat.

Users who already use Gemini for research or drafting will find this reduces context switching. It pairs well with other Gemini features such as Connected Apps for pulling live data into generated documents.

## Availability and Limitations

The feature is available to all users in every language where the Gemini app is offered. It covers personal accounts and all Google Workspace customers. PDF editing works on Android and iOS apps as well as the web. Other formats are web-only at launch.

Google has not published detailed accuracy metrics for the editor. Results depend on the clarity of your prompts and the complexity of the content. Always review generated files before sharing or submitting them.

## Conclusion

In-chat file generation and editing makes Gemini more useful for everyday document work. You generate a file from a prompt, preview it immediately, and refine it with direct typing, highlighting, or further prompts. PDFs work across devices; other formats currently need the web version.

Try it with a small task today. Start with a simple PDF or spreadsheet, review the preview, and make one targeted edit. The workflow is straightforward and available now for all Gemini users.
