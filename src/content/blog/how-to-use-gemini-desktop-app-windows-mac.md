The Gemini desktop app puts Google’s AI assistant one keyboard shortcut away from any window on your computer. No more switching tabs or losing focus. On Windows it arrived in September 2026; the Mac version launched earlier. Both give you the full Gemini experience plus desktop-specific tools.

This guide covers installation, the main features, and practical ways to use them today. All steps come from Google’s official help pages and announcement posts.

## What you need before you start

The desktop app is free to download and runs on personal Google accounts or work/school accounts that have Gemini enabled. Requirements differ slightly by platform:

- **Windows**: Windows 10 or later (x64 or ARM64), 8 GB RAM, 200 MB free disk space, internet connection.
- **macOS**: macOS Sequoia (15.0) or later on Apple Silicon, 8 GB RAM, 200 MB free space.

Feature availability can vary by region and plan. Tasks (the agent formerly known as Spark) require a Google AI Pro or Ultra subscription plus Keep Activity and Personal Intelligence enabled. Some advanced options remain Mac-only for now.

## Install the Gemini desktop app

1. Open a browser and go to [gemini.google/desktop](https://gemini.google/desktop).
2. Choose Download for Windows or Download for Mac.
3. On Windows, run the GeminiSetup.exe file and follow the prompts. On Mac, open the .dmg and drag Gemini to the Applications folder.
4. Launch the app from the Start menu (Windows) or Applications folder (Mac) and sign in with your Google account.

Once signed in, the app sits in your taskbar or Dock and system tray. You can pin it for one-click access.

## Use the keyboard shortcut for instant access

The biggest productivity win is the global shortcut that summons Gemini over whatever you are doing:

- Windows: Alt + Space
- Mac: Option + Space for the mini chat; Option + Shift + Space for the full window

Press the combination, ask your question or paste text, get the answer, then close the window and return exactly where you left off. If the default shortcut conflicts with another tool (common on Windows with PowerToys or Copilot), right-click the Gemini icon in the system tray, open Settings, and change it under General.

This works while you edit a document, review a spreadsheet, or browse the web. You stay in your primary app the whole time.

## Switch between Chat and Task mode

Recent updates added a clear Chat / Task toggle right above the prompt box. Chat is for quick questions and brainstorming. Task mode (the renamed Spark agent) lets Gemini plan multi-step work, call connected apps, and continue in the background.

To start a task:

1. Open the desktop app.
2. Click or tap Task.
3. Describe the goal, any deadline, and relevant files or notebooks.
4. Submit. Check the thread if Gemini needs a confirmation for sensitive actions such as sending email.

You can also schedule recurring tasks from the Scheduled section in the sidebar. For deeper tips on Task mode, see our guide on [using Gemini Task mode with Argon](/blog/use-gemini-task-mode-argon/).

Pro and Ultra subscribers get the strongest models, including Gemini 4 Argon, for these longer runs. Free users stay on standard chat.

## Share screen context and use Speak to Window (Mac)

On Mac you can share a window so Gemini sees exactly what is on screen. Click the tools menu, choose Share window, and select the app you want. Ask questions about a chart, a design mockup, or an open document without taking screenshots.

Speak to Window is another Mac feature. Hold the Fn key and speak; Gemini inserts the dictated text or acts on the command in the currently focused window. It is useful for rapid note-taking or drafting while you stay in your editor. The feature is rolling out and may not appear on every account yet.

Windows users can still share files and pull context from connected Google apps such as Gmail and Drive, but native screen sharing and Speak to Window are currently Mac-first.

## Connect local folders and run tasks from your phone

On Mac the desktop app can access local folders. Grant permission in settings, then ask a Task to organize files, convert documents, or summarize a project directory. The computer must stay awake and the app open for local work.

You can also start cloud-based tasks from the Gemini mobile app and let them run on your desktop. Select the computer from the task options when you want local-file access.

Antigravity (Google’s agentic coding environment) is available as a one-click launch from the Mac app for users who want to move from chat into code generation and prototyping.

## Tips for better results

- Enable Keep Activity and Personal Intelligence if you want richer context and Task mode.
- Create Skills (reusable instruction sets) so common prompts are one slash-command away. Skills work in both chat and Task mode.
- Review outputs before acting on emails, file changes, or purchases. Gemini asks for confirmation on irreversible steps.
- Keep the app updated. Updates appear as notifications; restart to apply them.
- For Workspace accounts, confirm your admin has Gemini turned on.

## Conclusion

The Gemini desktop app removes the friction of browser tabs and gives you an always-available assistant that understands your current context. Install it, set the shortcut, and start with a simple Task such as summarizing recent emails or drafting a document outline. Mac users get extra power from screen sharing and Speak to Window; Windows users still gain the core shortcut and full chat experience.

Download it today at gemini.google/desktop and experiment with one workflow that currently takes you out of your main app.
