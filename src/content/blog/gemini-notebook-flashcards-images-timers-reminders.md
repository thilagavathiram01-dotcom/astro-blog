Gemini Notebook flashcards just became more useful for actual study. On 24 November 2026 Google added three updates: automatic images drawn from your uploaded sources, a built-in stopwatch for review sessions, and mobile reminders so you return to decks you already generated.<grok type="render_inline_citation" citation_id="234" />

These changes sit on top of the existing flashcard tool that turns selected notebook sources into interactive Q&A cards. The new pieces help with visual subjects, timed exam practice, and consistent revision without requiring a paid plan.<grok type="render_inline_citation" citation_id="197" />

![Student writing notes at a desk](https://images.unsplash.com/photo-1434030216411-0b793f4b4173?auto=format&fit=crop&w=800&q=80)

## What the three updates do

Images appear on the cards themselves. Gemini Notebook scans the PDFs, slides, or other files you added and places relevant diagrams, maps, or figures next to the text prompt. A biology card about heart chambers can show the diagram from your lecture notes instead of forcing you to recall a pure text description.<grok type="render_inline_citation" citation_id="197" />

The stopwatch is optional. Turn it on during a review session and it tracks how long you spend working through the deck. That lets you practice under time pressure the way many exams require, or simply measure whether your recall is getting faster across repeated passes.<grok type="render_inline_citation" citation_id="197" />

Mobile study reminders live in the Gemini Notebook app. After you generate a deck you can schedule notifications that prompt you to revisit it. The goal is a simple cadence so decks do not sit unused after the first session.<grok type="render_inline_citation" citation_id="197" />

All three are available to Google Workspace customers, Workspace Individual subscribers, and users with personal Google accounts. There is no admin control to enable them; they are on by default for eligible users.<grok type="render_inline_citation" citation_id="197" />

## How to generate flashcards with the new features

1. Open [Gemini Notebook](https://notebook.google.com/) and sign in with your personal or Workspace account.
2. Create or open a notebook that already contains the sources you want to study. Upload PDFs, slides, images, or notes if they are not there yet.
3. In the Studio panel choose Flashcards.
4. Select the sources the cards should use and set the number of cards, difficulty, and any steering prompt you prefer.
5. Generate the deck. Relevant images from your sources will be incorporated automatically where they match the card content.
6. Start a review session. Enable the stopwatch if you want to time the round.
7. On the mobile app, open the same notebook and set a study reminder for that deck so the notification arrives when you want to review again.<grok type="render_inline_citation" citation_id="197" />

You can still mark cards as “Got it” or “Missed it” while you flip through them. The images and timer do not change that basic flow.<grok type="render_inline_citation" citation_id="199" />

## Practical ways to use the updates

For visual subjects such as anatomy, geography, or engineering diagrams, upload the source that contains the figures first. The automatic image pull reduces the need to hunt for separate reference pictures. Keep the source selection tight so the cards stay focused on the material you actually need to learn.<grok type="render_inline_citation" citation_id="194" />

Use the stopwatch for exam simulation. Set a target time for a 20-card deck, then try to finish under that limit on later passes. Track whether your average time drops without sacrificing accuracy. This is most useful in the week before a timed test.<grok type="render_inline_citation" citation_id="194" />

Schedule the mobile reminder for the same time each day or on the days you already study. A short notification is easier to act on than remembering an unfinished deck. Pair it with the earlier voice chat and quiz tools in the same notebook for a closed study loop. See also [how to use Gemini Notebook voice chat and interactive study tools](/blog/gemini-notebook-study-tools/).

## Tips that keep the decks useful

Upload clean sources. A scanned PDF with clear diagrams works better for image extraction than a blurry photo of a whiteboard. Prefer the original lecture slides when they are available.<grok type="render_inline_citation" citation_id="197" />

Limit the number of cards per deck. Smaller sets are easier to finish with the stopwatch running and easier to revisit when a reminder arrives. You can always generate a second deck from the same sources with a different focus.<grok type="render_inline_citation" citation_id="199" />

Check the cited material after a session. Flashcards pull from your sources, but you should still open the original page if a card feels incomplete or the image is only partially relevant.

The features are available now on Rapid Release and Scheduled Release domains. Personal accounts see them through the web and the official Gemini Notebook mobile apps.<grok type="render_inline_citation" citation_id="197" />

## Conclusion

Gemini Notebook flashcards now combine text with relevant images from your own materials, give you a stopwatch for timed practice, and send mobile reminders so you actually return to the decks. The updates require no paid plan and work for both Workspace and personal accounts.<grok type="render_inline_citation" citation_id="197" />

Start by uploading the sources that contain the diagrams or figures you need, generate a focused deck, turn on the timer for one session, and set a reminder in the mobile app. That combination turns the existing flashcard tool into a tighter study habit.
