Gemini Canvas turns a regular chat into an interactive workspace. On November 23, 2026, Google highlighted four practical ways to use it: create web apps and mini-games, make custom study tools, design office productivity boosters, and refine writing side-by-side.

You do not need coding skills for most of these. Open gemini.google.com, turn on Canvas, describe what you want, and work with the live result that appears next to the chat. This guide covers setup, the four main uses, editing tips, and how to export or share what you build.

## Open Canvas and Start a Project

Sign in at gemini.google.com. Click the + button (Upload and tools) under the prompt box, choose More tools, then Canvas. A Canvas chip appears in the box so you know the mode is active. Type a clear request that names the format you want, such as a quiz, a simple web app, a slide deck, or a document. Send it. The canvas panel opens beside the chat.

On the mobile Gemini app the path is tap Add, then Canvas. Text formatting tools are fuller on the web version. You can upload files or photos to give Gemini a starting point. Once the panel is open you can edit the content directly or keep prompting in the chat.

## Create Web Apps and Mini-Games

Describe a small interactive tool and Gemini builds a working preview. Examples include a tic-tac-toe game, a 3D visualizer, a habit tracker, or a simple calculator. The canvas shows both the code and a live preview. Switch between Code and Preview views. Ask for changes in plain language: “Make the theme retro 8-bit” or “Add a score counter.”

You can also start from a sketch. Upload a photo of a hand-drawn mock-up and say “Code this app.” Gemini reads the drawing and produces a prototype you can test and refine. For Python code you can export to Colab. Share a public link so others can open the app without signing in.

## Make Custom Study Tools

Turn notes, PDFs, or a short outline into interactive materials. Prompt for a quiz, flashcards, or a sandbox that lets you practice a concept. Gemini creates the questions and the interface. Highlight a section in the canvas and ask it to rephrase or expand only that part. The Create menu (when available) can also turn an existing document into a quiz, infographic, or Audio Overview.

This is useful for exam prep or onboarding. Keep the source material in the same chat so follow-up questions stay grounded. You can export the finished quiz or flashcards and reuse them later.

## Design Office Productivity Boosters

Paste spreadsheet data or describe a workflow and ask for a sales tracker, pricing calculator, or task list. Gemini builds a simple interactive dashboard you can adjust. Request specific fields, filters, or calculations. Because the result lives in the canvas you can edit numbers or labels directly and ask for layout changes without starting over.

These tools stay inside Gemini unless you export them. For longer-term use, copy the content or share a link. Pair this with Gemini’s document editing features if you need to generate a PDF or slide deck from the same data.

## Refine Writing Side-by-Side

Write or paste a draft into the canvas. Highlight any sentence or paragraph, then type a short instruction in the chat such as “Make this more formal” or “Shorten and add a concrete example.” Gemini updates only the selected text. Use the formatting toolbar for headings, lists, and bold. Change length or tone with the quick tools that appear in the panel.

This keeps the full document visible while you iterate. When you are satisfied, export to Google Docs or copy the text. The same select-and-ask method works for slides and other formats once they are in the canvas.

## Tips for Better Results

Be specific in the first prompt: name the audience, the format, and the key sections you need. Iterate in small steps rather than asking for a complete rewrite. Check the preview yourself and verify any calculations or logic. Free accounts can use Canvas; paid plans unlock higher models and longer context if the project grows large.

Remember that Canvas projects are tied to your Gemini account. Review privacy settings if you plan to share sensitive material. See our guide on [controlling Gemini chat history and AI training](/blog/manage-gemini-chat-history-ai-training/) for the separate History and training toggles.
