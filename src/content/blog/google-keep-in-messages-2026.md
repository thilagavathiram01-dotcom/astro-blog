Group chats are where plans start. They are also where grocery items, packing lists, and trip notes get buried under stickers and side talk. Google’s September 2026 Android Drop puts Google Keep inside Google Messages so the list lives next to the conversation.

This guide walks through the official flow: attach a note from the + menu, send it into the thread, and let people in that chat view and edit it. Details come from Google’s Android Drop post and later rollout notes from Android coverage that confirmed the request-to-collaborate step.

## What Google shipped

On September 1, 2026, Google said you can share and update grocery lists or vacation notes inside chat. People in the thread can view, edit, and add ideas without switching apps. You start from the + icon in Google Messages.

Rollout began that day in Messages. It is not tied to a single Android version the way Motion Assist is. If the Keep tile is missing, update Messages from Play Store and wait for the server-side flag. Our overview of the full drop is in [How to Use Android’s September 2026 Drop](/blog/android-september-2026-drop-guide/).

## What you need first

You need the current Google Messages app and a Google account that already uses Keep. RCS chat features should be on for the conversation when possible. SMS-only threads may not get the live note card.

Install or update:

1. Google Messages
2. Google Keep
3. Google Play services if the phone is behind on system apps

Open Keep once and confirm you can create a note. The Messages sheet reads from the same Keep account that is signed in on the phone.

## Attach an existing Keep note

Open the chat where the plan actually lives. Family grocery thread, roommate group, or a two-person trip chat all work.

1. Tap the **+** icon at the bottom of the composer.
2. Choose **Google Keep** (some builds label it Keep Notes).
3. Pick an existing note or list from the sheet.
4. Edit the title or items if you need a cleaner version for the group.
5. Tap **Send**.

The note lands in the thread as a live preview, not a static screenshot. People can open it from the bubble instead of hunting through Keep separately.

If + only shows GIFs, stickers, and files, Messages is still on the old attachment sheet. Force-stop Messages, update again, and reopen one RCS conversation.

## Create a list without leaving the chat

You do not have to pre-build the note in Keep. Google’s drop post says you can create a new list or note from Messages.

1. Tap **+** then **Google Keep**.
2. Choose **Create a note**.
3. Start a checklist for groceries, packing, or errands.
4. Send it into the thread.

Suggested actions can also appear when someone types a pile of items. 9to5Google and Android Authority reported a “Create list” suggestion during rollout. Treat that as optional. The + menu is the reliable path.

## How collaboration actually starts

Google’s marketing line is that the whole crew can view and edit. Android Authority’s later how-to added an important gate: the recipient taps the note and **requests to collaborate**. You approve that request. Only then does the shared note open for them.

That matches how Keep already handles shared notes. Do not assume a sent card instantly writes to everyone else’s Keep account.

Practical rules:

- Send the note from the account that should own it.
- Approve only people who belong in that list.
- If a guest leaves the group chat, remove them from the Keep collaborators list as well.

Edits sync back to Keep. Checking off milk in Messages should show as checked in the Keep app on other devices signed into the same collaboration.

## Good uses, bad uses

Use a shared Keep card for short, living lists:

- Household groceries
- Packing for a weekend trip
- Who is bringing what to a dinner
- A one-page itinerary next to the group thread

Do not use it as a project tracker with dozens of nested tasks. Keep lists stay flat. Long specs belong in Docs. Sensitive data such as passport numbers, lock codes, or payment details should stay out of a group note.

If two people keep adding the same item, assign an owner in the title (“Alex buys produce”) instead of arguing in the thread.

## Pair it with chat themes

The same Android Drop added Chat theme in Google Messages. Each conversation can use its own wallpaper and bubble colors. Pick a photo or a preset. Bubbles can follow the theme or use colors you set.

Give the household list chat a distinct theme so you do not open the work thread by mistake. Theme is available now, per Google. Keep integration continued rolling out through early September.

## If Keep does not appear

Work through this list before filing a bug:

- Messages is updated from Play Store, not a sideloaded APK
- You opened an RCS / Chat features conversation, not a plain SMS thread
- Keep is installed and you can create notes in the standalone app
- You are signed into the same Google account in Messages and Keep
- You waited after the September 1 start date; 9to5Google still called the feature “rolling out” on September 7

Clear Messages cache only after an update. Do not clear Keep data if you have unbacked-up local notes.

## Tips that save a messy thread

Pin the Keep card in the chat if Messages offers pin for that bubble type. If it does not, star the note in Keep and keep the title unique (“Sat market list — Sept 27”).

One list per purpose. A single “life” note that mixes groceries, gifts, and flight times will fight you. Send a second card instead.

When the trip ends, archive the Keep note. The chat history still shows the old card, but the live list stops collecting junk items.

For Motion Assist, Guided vision, and Find Hub memory from the same drop, start with the [September 2026 Drop guide](/blog/android-september-2026-drop-guide/). Those features have different Android version floors than Messages + Keep.

## Conclusion

Keep inside Messages is a small attachment change with a clear job: stop rebuilding the same list in chat every week. Attach the note from +, send it, approve collaborators, and edit from the thread.

If the tile is not on your phone yet, update Messages and check an RCS conversation. When it lands, create one real household list the same day so the habit sticks.
