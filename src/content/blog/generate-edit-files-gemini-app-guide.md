Google rolled out in-chat file generation and editing for the Gemini app on 29 October 2026. You can now create a PDF study guide, a spreadsheet tracker, or a slide outline, then refine it without leaving the conversation. PDF editing works on both web and mobile. Other formats stay web-only for now.<grok type="render_inline_citation" citation_id="70" />

This change closes the loop between prompting and finishing work. Previously you exported a file, opened it elsewhere, then returned to Gemini for fixes. Now the preview lives inside the chat.

## What formats Gemini supports

Gemini generates and previews several file types. You can edit them by typing directly, highlighting a section, or prompting Gemini to revise it.

- **PDF**: Available on web and mobile. Export or save to Drive.
- **Google Docs**: Web only. Opens or saves in Docs.
- **Google Sheets**: Web only. Opens in Sheets.
- **Slide decks**: Web only. Opens in Slides or downloads as PPTX/PDF.
- **Markdown, TXT, LaTeX, and code**: Web only. Saves to Drive.

The feature is available to all users in every language where the Gemini app runs. No paid plan is required.<grok type="render_inline_citation" citation_id="71" />

## How to generate a file

1. Open gemini.google.com or the Gemini mobile app (PDF only on mobile).
2. Upload source material if needed—photos of notes, a report, or a table.
3. Prompt clearly. Example: “Create a PDF study guide from these lecture notes with key formulas and practice questions.”
4. Wait for the preview to appear in the chat.

Gemini keeps context from earlier messages, so follow-up prompts can adjust structure or tone without starting over.

## How to edit inside the chat

Once the preview loads you have three ways to change it.

**Expand to full screen and type.** Click or tap the expand control. Edit text the same way you would in a basic editor. Changes save back into the conversation.

**Highlight and ask.** Select a paragraph, table, or visual. Ask Gemini to rewrite it, turn a table into a chart, or explain a section. The update appears in the same preview.

**Prompt the whole file.** Say “Make the introduction shorter and add a summary section at the end.” Gemini revises the document and refreshes the preview.

## Practical examples

**Student study guide.** Upload photos of handwritten notes. Ask for a PDF that organises concepts, highlights formulas, and adds three practice questions per section. Expand the preview and correct any misread handwriting. Highlight a table and request a graph instead.

**Project tracker.** Prompt: “Build a Google Sheet that tracks weekly tasks with columns for owner, status, and due date.” Preview the sheet, add a formula column by highlighting the range, then open it in Sheets when ready.

**Slide outline.** Request a five-slide deck for a status update. Preview the layout, highlight the title slide, and ask Gemini to change the colour palette or shorten bullet points. Export to Slides or PPTX.

## Tips for better results

- Name the exact format in the prompt. “Create a PDF” produces a different result from “Create a Google Doc”.
- Upload clear source material. Poor photos of handwriting reduce accuracy.
- Edit in small steps. Large rewrites sometimes drop earlier structure.
- Check mobile limits. Only PDFs support preview and edit on the phone app right now.
- Save early. Export or open in the native Google app once you are happy, then continue there for advanced formatting.

## Limitations to know

PDF editing works on mobile, but Docs, Sheets, slides, Markdown, and code require the web version. The feature covers files Gemini itself generates; it does not yet let you upload an arbitrary existing PDF and edit it in the same way. Visual changes (turning a table into a chart) work when you highlight the element, yet complex layouts still benefit from a final pass in the native app.

## Conclusion

Generating and editing files inside Gemini removes the export-edit-reimport cycle. Start with a clear prompt, use the preview tools to refine, then move the finished file to Docs, Sheets, or Drive when you need full formatting controls. The capability is live for all users today.
