Google Labs published six new [Google Flow](https://flow.google.com/) tools on September 23, 2026. The tools come from working creatives in sound design, digital content, architecture, and film. You can open them, remix them, or describe a new workflow in plain language.

This guide explains what each tool does, who can use it, and how to run one of the new workflows without writing code.

## What Google Flow Tools are

Flow is Google’s AI creative studio. Tools inside Flow are reusable workflows you describe in natural language. Google says the Tool Builder uses Gemini to generate the workflow, then you iterate on the result.

Anyone can explore existing tools in Flow. Google AI subscribers can create custom tools from scratch or remix tools other people published. That split is stated in Google’s official Flow Tools videos and help copy.

The September 23 release is not a new product. It is a gallery drop: six partner-built tools you can test today at [flow.google.com](https://flow.google.com/).

## The six tools Google released

Google Labs named the tools, the makers, and the jobs they cover. Use this list as a map before you open the gallery.

**1. Mondo Sónico** — Ricardo Villavicencio and Sebastián Carvallo. Generates background ambiance, foley, and contextual sound effects. Tracks stay separate and editable so you can export stems for post-production.

**2. CaptionCast** — Jay Pirabakaran. Transcribes, styles, and animates multilingual captions in a single pass. Built to cut manual subtitling.

**3. ThumbnailForge** — also Jay Pirabakaran. Takes one image, a headline, and a prompt, then renders social thumbnails sized for multiple platforms.

**4. Surface** — Vojtek Morsztyn. Generates custom architectural textures and maps them onto 3D walls, ceilings, and floors during early material studies.

**5. CollageMotion Pro** — Hashem Al-Ghaili. Turns text prompts into animated mixed-media collages for documentary-style storytelling.

**6. SwissFlow Studio** — also Hashem Al-Ghaili. Converts scripts into Swiss-style motion graphics so you spend less time on traditional keyframing.

Google published a direct share link for each tool in the Labs post. Open the link, sign in, and run a sample before you remix anything.

## How to try a tool in five steps

Google’s own tutorial, *How to use Tools in Google Flow*, walks through the same path. Follow it with one of the new partner tools.

1. Go to [flow.google](https://flow.google/) and sign in with the Google account on your AI plan if you want remix access.
2. Open a project. Select **Tools** in the left navigation.
3. Browse the gallery or paste a partner share URL from the Labs article.
4. Run the tool with a small test: one clip, one still, or a short script.
5. If the output is close, duplicate the tool and edit the prompt, inputs, or export settings.

Keep the first run tiny. A 10-second clip or a single still shows whether captions land, stems split, or textures map the way you expect.

## How to remix or build your own

Google’s Labs post tells you to duplicate a published tool, then change it to match your setup. Subscribers can also start from a blank description.

Write the description like a brief, not a slogan. Name the input, the output, and the constraint. Example: “Take a 15-second product clip, add animated English and Spanish captions, export a 9:16 version and a 16:9 version.”

Stay specific about file types. Say “separate WAV stems” if you need Mondo Sónico-style audio. Say “1080x1920 PNG plus YouTube thumbnail crop” if you are remixing ThumbnailForge.

After Gemini drafts the tool, run it twice. Change one variable on the second pass so you can see which step actually moved the result.

If you publish a remixed tool, treat it like shared software. Label the expected input length, language, and aspect ratio so the next person does not guess.

## Practical uses for each category

**Sound.** Mondo Sónico is useful when a cut needs room tone and foley but you are not ready for a full sound design session. Export stems. Do not bounce a single mixed file if you still need to duck dialogue later.

**Captions and packaging.** CaptionCast and ThumbnailForge sit next to each other in a Shorts or Reels pipeline. Generate captions first, then lock a still for the cover. If you already research products on YouTube, pair this with our guide to [Ask YouTube product reviews](/blog/ask-youtube-product-reviews-shopping/).

**Spaces.** Surface is an ideation tool, not a construction document. Use it to compare tile, plaster, and pattern directions before you commission a render or a sample board.

**Motion.** CollageMotion Pro and SwissFlow Studio help when you need a title sequence or explainer graphic and you do not want to keyframe every layer by hand. Start from a written script so the motion follows the story instead of random cuts.

## Tips that keep the output usable

Feed the tool finished ingredients. A noisy phone clip will produce noisy stems and messy captions.

Name languages in the prompt. CaptionCast is built for multilingual work; “caption this” is weaker than “English source, Spanish and Hindi burned-in captions.”

Export more than you publish. Keep an uncaptioned master and isolated audio tracks.

Watch plan limits. Creating and remixing tools is a subscriber feature. Exploring the gallery is open to Flow users.

Check rights on every still and clip you upload. The tool does not clear licenses for you.

## What this release does not change

These six tools do not replace a full NLE, a DAW, or CAD software. Google presents them as custom workflows inside Flow, built with Gemini, Veo, and related models already in the studio.

Availability can vary by account, region, and Google AI plan. Confirm current access at [flow.google](https://flow.google/) and in your Google AI plan settings before you plan a client delivery around a gallery tool.

## Conclusion

The useful part of the September 23 drop is not the count of six. It is that working creatives published workflows you can run, duplicate, and rewrite.

Open one tool that matches a job you already do this week. Run a short test. Remix only after you know which input the tool actually needs.

When you want a tool that is not in the gallery, describe the job in Flow and keep the first version narrow. Tight briefs produce tools you can trust on the next project.
