Google published six new [Flow Tools](https://blog.google/innovation-and-ai/models-and-research/google-labs/six-new-tools-built-by-creatives/) on 23 September 2026. The set covers sound design, captions, thumbnails, architectural textures, animated collages, and Swiss-style motion graphics.

You do not write the interface from scratch. You open a shared tool link inside a Flow project, run it, then remix it if you hold a Google AI plan. This guide follows Google’s Labs post and the official [Create & manage Tools](https://support.google.com/flow/answer/17104535) help article.

## What Flow Tools are

Flow Tools are reusable mini-apps that sit inside a Google Flow project. Google says you describe the job in natural language and Flow writes the interface. Shared tools live in a gallery. Anyone with Flow can run a published tool. Google AI subscribers can create new tools and remix existing ones.

Help Center limits that matter on day one:

- Tools run on web and PC only.
- Generated media uses Flow credits. Flow shows a warning before a run that will spend credits.
- Outputs save into the project you have open.
- Building a tool does not spend credits, but there is a daily quota on how many tools you can create.

If you already generate stills in Workspace, keep that work in [Google Pics](/blog/google-pics-docs-slides-drive/). Flow Tools are for video, motion, and custom media pipelines, not Docs or Slides layouts.

## The six tools released on 23 September

Google built the set with working creatives in sound, architecture, and digital content. Each tool has a public Flow link.

**1. Mondo Sónico** — [Ricardo Villavicencio](https://ricardovillavicencio.com/) and [Sebastián Carvallo](https://www.c82.studio/). It generates background ambiance, foley, and contextual effects on separate, editable tracks so you can export stems for post-production.

**2. CaptionCast** — [Jay Pirabakaran](https://www.instagram.com/jayprints/). One pass transcribes, styles, and animates multilingual captions.

**3. ThumbnailForge** — also by Jay Pirabakaran. Feed one image, a headline, and a prompt. The tool returns social cover art sized for multiple platforms.

**4. Surface** — [Vojtek Morsztyn](https://vojtekmorsztyn.com/). It generates textures (Minimalist through Art Deco) and maps them onto 3D walls, ceilings, and floors during early material studies.

**5. CollageMotion Pro** — [Hashem Al-Ghaili](https://en.wikipedia.org/wiki/Hashem_Al-Ghaili). Text prompts become animated mixed-media collages for documentary-style sequences.

**6. SwissFlow Studio** — also by Hashem Al-Ghaili. It turns a script into Swiss-style motion graphics so the keyframing work is not the bottleneck.

Open any of those links only after a Flow project is already selected. Google’s help page is explicit: pick a project first, then open the shared tool URL.

## Open a shared tool

1. Go to [Google Flow](https://flow.google/).
2. Open an existing project or start a new one.
3. Open the shared tool link from the Labs post.
4. Run the tool against assets already in that project.

To find tools you already saved:

1. Open a project.
2. Select **Tools** in the left rail.
3. Open **My Tools** and pick the item.

Google Flow’s official account also lists the same path: project first, then the Tools icon in the left nav. All users can try gallery tools. Create and remix stay behind a Google AI subscription.

## Run each tool for a real job

Treat the six tools as starting points, not finished house style.

**Audio bed.** Drop a silent cut into the project. Open Mondo Sónico. Ask for room tone plus one foley layer that matches the scene. Export stems if you will mix in another editor.

**Captions.** Feed CaptionCast a finished clip and name the languages you need on screen. Review timing before you publish. Automated captions still need a pass for names and product terms.

**Thumbnails.** Give ThumbnailForge one still, one headline, and the platform crop you need. Do not expect one render to cover YouTube, Shorts, and a blog hero without a crop check.

**Materials.** Use Surface when you are comparing finishes, not when the construction set is locked. Generate two or three textures, map them, then discard the ones that fight the lighting.

**Collage and type.** CollageMotion Pro and SwissFlow Studio both start from text. Keep the prompt short: subject, era, motion, and duration. Long prompts tend to stack conflicting styles.

## Remix a tool instead of starting over

Google’s September post tells you to duplicate and remix. The help article names the control: **More → Remix tool**. Remix creates a personal copy you can edit in conversation.

1. Open the tool or its shared link inside a project.
2. Select **More → Remix tool**.
3. Choose **Edit**.
4. Describe the change in the right-hand panel. Example: “Add a 9:16 export preset and lock captions to the lower third.”
5. Click **Generate**, review the new UI, then **Save**.

Other edit actions from the same help page:

- **Edit icon** and **Edit description** under **More**.
- **Rename** under **More**.
- **Favorite** to use the tool across projects.
- **Pin** to keep it in the current project.

Share only when the tool is ready. **Share → Copy link** publishes the version that existed when you copied the URL. Later edits do not travel with that link. Anyone with the link can see the tool’s code, name, and thumbnail. To stop sharing, delete the tool.

## Build your own tool

If none of the six fit, build one. Google’s help example is: “Make an image filter app with a slider for grayscale and hue shift.”

1. Open a Flow project on web.
2. Select **Tools → Create Tool**.
3. Describe the interface and the output.
4. Click **Generate**.
5. Review the UI and **Save**.

Write the prompt like a spec, not a mood board. Name inputs (clip, still, script), outputs (stems, 1080p, 9:16), and one constraint (credit cost, language, duration). Vague tools waste the daily create quota.

## Limits and habits that keep credits in check

- Draft at a lower resolution when Flow offers it, then upscale the keeper. Google’s August 2026 Flow update documents 360p drafts and later 720p or 1080p / 4K exports for video work.
- Watch the credit banner before you batch-run CaptionCast or CollageMotion Pro.
- Keep one project per client so tool output does not land in the wrong library.
- Do not share a tool that embeds private brand files in its thumbnail.

## Conclusion

The September drop is a starter kit: six working tools from people who already ship sound, architecture, and motion work. Open a project, run the shared link, then remix the one that is closest to your pipeline. Build from scratch only after you know which slider or export you still lack.

Start at [flow.google](https://flow.google/) and the six links in Google’s Labs post. Keep stills work in Pics. Keep dashboard work in Sheets. Use Flow Tools when the job is media you will cut, caption, or motion-design.
